01絶対に崩さないもの

これだけは例外なし。

  • ハッシュタグを使わない208本中0本
  • 絵文字を使わない208本中3本型7の話者記号だけが例外
  • 本文に外部リンクを入れない。導線は必ず1stリプ

02話者のポジション

誰の目線で書くか。ここが崩れると型の説得力が消える。

  • 観察者であって主役ではない。自分を上げる投稿を書かない武勇伝0本
  • 自分が登場するときは、常に失敗している側か教わる側
  • 型2（面接官）だけは判断する側。ここで困る側に立つと型の権威が消える
  • 型7は登場人物の中に語り手がいない。心の声も第三者の頭の中
  • 型8・型7で一人称（こっち／自分）を使わない「こっち」と書いた瞬間、語り手が裁く側に立つ
  • 一次情報として書いた箇所を明示して渡す。「見たことがない」と言われたら伝聞に切り替える伝聞は逃げではなく手札。責任が相手側に移り、締めだけ本人の意見にできる

03具体性

この人の投稿で最も効いている要素。数字はすべて月内相対中央値。

  • 主語を具体化する若手社員 → 早稲田卒の25才 ／ メンタル弱い人 → 怒られたら3日引きずる人
  • 年齢を入れる3.3x学歴を入れる2.1x数字を入れる1.9x
  • 述語はセリフにする。要約された教訓は誰でも書けるが、セリフはその場にいた人しか書けない
  • 型4だけは人物を持ち込まない0.1x型4では行動だけを具体化する。読者が自分を当てはめる枠なので、他人が座っていると入れない
  • 数字は「具体的」の前に「現実的」か×230分→15分／3秒→1〜2秒。その場面で実際に時計を見たらその値になるか
  • 動作は頭の中で再生してから書く視線が「止まる」→「泳ぐ」。AIを読むなら視線は動く
  • 箇条書きは行動で書く。姿勢で書かない姿勢だと14x沈む
  • 箇条書きは3つまで4つ以上で0.3x
  • 分析的な語より状態の語×3確認は「その言葉を読者が自分について言うか」。「私は考えていた」とは言わないが「気を遣っていた」とは言う

04文体・語尾

  • 常体。敬体は使わない型2の「〜してますが」だけ例外
  • 一人称は「ワイ」（失敗談のとき）。地の文では省略が多い
  • 締めの既定は「〜よね。」76本 / 1.05「〜だよな。」12本0.80、「〜からね。」14本0.40が最弱
  • 「マジで」が2番目の口癖27回「本当に」「非常に」に置き換えると別人になる
  • 関西弁は型1の上司キャラ専用×2522万の上司の指紋。他の型に持ち込むと人物像が混ざる
  • 実務の説明に強い語を使わない逆算して → も参考に
  • 疑問形にしない議論系だけ例外
  • 接続語は「型」ではなく「決め台詞と箇条書きの関係」で決める決め台詞が3つの総括 → 「などあるが、総じて言うと、」／3つとは別の4つ目 → 「これだけでも◯◯が、とくに◯◯のは、…」

05削り方

Hideさんの修正から抽出した13項目。書いたあとにこれで削る。

  • 説明の行を足さない箇条書きから読者が埋められることは書かない
  • 抽象的な帰結より、具体的な原因帰結は読者が自分で想像できる
  • 2文を1文に圧縮する逆接の「が」でまとめる
  • 締めで決め台詞を言い換えない。一段広い主語に上げる
  • 名詞化して短くする箇条書きを受ける語は「など」
  • セリフに「！」を付けて温度を出す
  • 落としっぱなしにせず一言かばう例外2つ ─ 構造の説明のとき／議論を狙う回（かばうと争点が片付く）
  • 副詞を削る／1行目を改行しない
  • 悪い側は「自分」を主語にした語でそろえる自分で頑張る／自分が凹むだけ／自分の身を守る
  • 技巧的な対句をやめる。言い切りにする
  • 台詞のハードルは読者が今日できる高さに作ったか → 考えたか
  • 締めで誰も下げない。選択肢を渡す批判ではなく提案で閉じる
  • 依頼に書かれた要素を落とさない

06骨格グループ

飽き対策の本体。在庫の中でAと非Aを半々に保つ。

群型見た目
A型1・2・3・510〜14行。実績はここに集中
B型4 対比リスト『』も締めも無い
C型7 会話だけ地の文が無い
D型8 短文5〜7行
E型9 助詞切り一塊。本文に締めが無い
  • B・C・D にAの書式（『』・同意誘導）を持ち込まない
  • 型より先に主張の形を見る。「AだからB、BだからC」の連鎖は型7・型8に乗らない

07型ごとの書式

型1 上司の一言57本 / 中央値895 / 最大522万

  • 当たり外れが最大。在庫1本まで
  • 失敗を他人のセリフで見せる／物理的な場面を1行
  • 決め台詞を教訓にしない。教えると説教、笑わせると引用される
  • 決め台詞の中に対比か言い換えを入れる
  • 二段にするのは台詞と台詞の間にこちらの反応が挟まるときだけ

型2 面接官の暴露導線率1位 0.0508%

  • 1行目は必ず「ベンチャーで面接官してる〜」15本中15本
  • 「などあるが、実はよく落とすのが、」→『意外な一項目』→ 採用側の損得で締める
  • 意外性のために事実を曲げない。想像で書いた4本中3本却下
  • 人格ではなく行動を批評する

型3 人物観察58本 / 枚数の稼ぎ頭

  • 学歴・年齢を頭に置く。同じ人物を使い回してよい
  • 型3内で年齢5.7x・学歴4.1x
  • 「とくに◯◯のは、…」で折りたたませる

型4 対比リスト平常値1位 / 最大1272万 / 全クリックの53%

  • ラベルは「強い人／弱い人」を動かさない
  • 6項目は1つの主張の6回の言い換え
  • 左右は同じ軸の裏表（×2 外した）
  • 通し軸が最も濃い項目を1行目へ／数字は全角／方言を入れない
  • 人物を入れない。『』も同意誘導の締めも入れない
  • テーマは「頑張りすぎる人へのゆるし」が最大の当たり（転職テーマは1700分の1）

型5 新人観察

  • 箇条書きの3項目は、決め台詞の実例になっていること（×2 外した）
  • 実際に言う場面が浮かぶ言葉にする
  • 決め台詞の主語を語り手の視点に合わせる（出してる → 教えてくれる）

型7 会話だけ返信が最多になる型

  • 地の文なし・『』なし・締めなし・箇条書きなし
  • 地の文が無いぶん、前提はセリフに埋め込む（「来週までの例の件」）
  • 心の声は観察ではなく判断で終える

型9 助詞切り未検証・実験枠

  • 場面から入る／生セリフを要約しない／主語は評価する側
  • セリフに答えを入れない。セリフは事実、答えは原理
  • 答えはセリフの事実の原因になっていること。先に答えを決めてから事実を探す
  • 落とした場面より通した場面。一見マイナスの事実で通すと謎が立つ
  • 切る直前の名詞は平凡でよい（×2 凝りすぎて却下）
  • 自己リプにはいつもの同意誘導が要る／その回はアフィリンクを貼れない

断言-リスト

  • 1行目に引きを作らず結論を言い切る
  • 学歴・年齢を1行目に
  • 箇条書きの重複は言葉ではなく行動で見る
  • 締めに読者の得＋自覚できる語で名指し
使わない型：他人が登場しない断言。実測最下位の4万。

08議論系

議論を狙う回だけの例外ルール。いいね率を捨ててリーチを取る。

  • 「〜なのか、どうだろう…？」で終える。争点と質問を1文に
  • 締めの直前に争点を1行で並べる。これが無いとリプが散る
  • 同意を求める疑問（〜よね？）にしない語り手の答えが見えていると、読者は「うん」で終わる
  • 一言かばわない。「だって」「らしい」で距離を取るかばうと読者が納得して争点が片付く
  • テーマの条件 ─ 所属が瞬時に確定する／片側が不名誉（行動であって人格ではない）／答えるコストがゼロ
  • 性別・国籍・政治は避ける燃えずに黙られる。答えると自分の評判が下がるテーマは書き込まれない

09導線（1stリプ）

  • 本文が伸びてから貼る目安1〜2時間。同時に貼らない
  • 導線リプは1本だけ3ケースで確認
  • 本文の主役も読者も否定しない。損しているのは構造のせいという置き方
  • 型4にも貼る全クリックの53%「貼らない」は撤回済み
  • リプ到達率は元ポストの約6%53ペア
  • 詳細クリック率0.62%は書き方では動かない139本
  • 訴求は性格分析 0.116% > 年収診断 0.075% > その他 0.020%間口の広さ順
  • 元ポストを書く前に商材を決める。バズってからPRを考えると0.04%側に落ちる

10素材

  • 優先順位 ─ ネタ帳 → 過去投稿の焼き直し → スワイプ → 時事 → 実体験 → リプ欄 → 他SNS
  • ネタ帳は claims.md（C001〜C095）。/x-draft の既定ソース。番号で指定できる
  • 同じ骨格に乗るネタは束ねて1本にする求人票の建前4件 → 型2リスト1本
  • スワイプで借りるのは構造とテーマ。言い回しとエピソードは借りない
  • 時事は入口だけ。1行目で触れて2行目からいつもの型に戻る
  • 主張が重なることは問題にしない型と表現を変えて出し直すのが正しい。重複を理由に在庫を割り引かない
  • claims.md も debates.md も参考であって縛りではない

11運用

  • 日付も投稿枠も割り当てない
  • 「記録が無い＝投稿していない」と扱わない予約投稿が見えないため
  • テーマ指定の依頼には3案。骨格を変える言い回しの差では選ぶ意味がない。1本に絞らなくてよい
  • 投稿するなら朝6時台177 / 208本
  • 引用RTの狙いは引用元にリポストしてもらうこと。impで評価しない

12安全・制約

  • 会社名・部署名・製品名・個人名を出さないリクルートのみ2026-08-13に解禁
  • 検証されうる固有の数字を出さない売上・人数・自分の評価ランク
  • うちでは新卒採用していない動かせない事実
  • 自動投稿・自動リプはしない
  • スクレイピング／ブラウザ自動化はしない永久凍結リスク
  • APIキーをチャットに貼らない
  • アフィリンクと広告表記はHideさんが付ける

13私が繰り返した失敗

同じ理由で複数回直されたもの。書いたあとここで照合する。

  • 器を先に作って中身を流し込む×3型を決めてから主張を埋める／逆張りの形を先に作る／箇条書きを先に思いついて決め台詞を後からかぶせる → 言いたいことを先に固める
  • 1件の指摘を一般則に変換する×43案は1つだけ／重複を指摘する／主張を絞る／未経験は書かない → 頼まれたものだけ規定に入れる
  • 規定にあるのに下書きで守れない語尾「なんだよな」／学歴の入れ忘れ → 書いたあと規定と照合する
  • 左右の軸ズレ×2「◯◯ vs ◯◯」に抜き出して反対語か見る
  • 関西弁の混入×2
  • 数字を盛る×2
  • 接続と中身のズレ「とくに◯◯のは」と書いて中身が総括だった
打率について。2026-08-18〜20に出した下書きのうち、修正なしで通ったのは1本だけ（型2「求人票の建前」）。共通点は実測済みの骨格をそのまま使い、中身だけ入れ替えたこと。新しい構造を試したものは全部直されている（型9は4回、型5は3回、議論系は2回）。新しい骨格を試すときは、直しが数回入る前提で出す。
