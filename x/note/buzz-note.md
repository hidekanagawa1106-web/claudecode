# 【構成】どこで課金に繋げるか

## 結論: 「バズるポストの3要素」を読み終えた直後で切る

理由は3つあります。

**1. 無料部分が「考え方」で完結し、有料部分が「実数と手順」になるから**

①②③は**読んで納得できるが、明日すぐ数字が動くわけではない**話です。
一方この後に続くのは、307本の実測値と収益の内訳という**その場で使える情報**。
無料で「この人は考えて書いている」と分かり、有料で「この人しか持っていない
データがある」に変わります。**課金は"続きが気になる"ではなく"元が取れる"で
決まります。**

**2. 冒頭で仕込んだフックの回収位置がここだから**

原文の冒頭でこう書いています。

> ポストごとの収益金額は後半ですべて紹介しますので、ぜひ「どのポストが収益
> いくらか？」予想しながらこのあとの解説をご覧ください。

**読者は3要素を読みながら、ずっと収益の答え合わせを待っています。**
ここで切るのが一番引っぱりが効いています。

**3. いまの原文は③で失速して終わるから**

③の最後が「諸先輩方のnote、各種書籍でも多数紹介されているはずなので割愛しますね」
で終わっています。**無料部分の最後の一文がこれだと、読後感が「ふつうだった」に
なります。** ③に実数を入れて、そのまま有料への橋にします（下に原稿があります）。

# 【原稿】無料部分の補強

## ③読みやすい文構造（差し替え版）

𝕏のタイムラインをスクロールしていて、最後まで文章を読むポストって
せいぜい1-2割じゃないですか？
それだけ𝕏には文字・情報が溢れてる中で、「いかに最後まで読んでもらうか？」は
基本であり地味に大事なポイントです。

たとえば日本語の基本とも言えますが、

- だらだらと書くより、句読点を入れてリズム良く
- 漢字ばかりでなく、適度にひらがなも混ぜて
- 最初の1行で「おっ？」と思わせるキャッチーな文言を
- 同じ意味ならできるだけ短い言葉で

このへんは諸先輩方のnoteや書籍でも紹介されているので、私からは
**自分の投稿を全部数えて分かったこと**を3つだけ足しておきます。

**（1）1行は16字**

私の投稿の1行は中央値18字でした。
そして**とくに伸びた20本に限ると16字**です。
1行が40字を超える行の割合も、全体では9.3%あるのに、伸びた20本では3.6%。

**短いほうが伸びる、ではありません。** 順番が逆で、
**最後まで読まれる文章を書こうとすると、勝手にこの長さになる**という話です。

**（2）ただし、文の途中で改行しない**

これは私が一番やりがちなミスでした。「1行を短く」を意識しすぎると、

```
マネージャーになりたての頃、
部下に進捗を聞いただけなのに、
顔がこわばった。
```

こうなります。読みやすそうに見えて、実際は**1文を読むのに3回も目が
止まっています。** 正解はこうです。

```
マネージャーになりたての頃、部下に進捗を聞いただけなのに顔がこわばった。
```

**改行は文と文の間に入れるもので、文の中に入れるものではありません。**
「1行を短く」は「1文を短く」と読み替えてください。

**（3）箇条書きは「姿勢」ではなく「作業」で書く**

これが一番差が出ました。同じ「伸びる新人」というテーマでも、

```
×  ・素直に受け止める     ← 姿勢
　　・当事者意識がある
　　・成長意欲が高い

○  ・「ここまでは分かりました」と言える     ← 作業
　　・「あと30分で出します」と言える
```

**姿勢で書いた箇条書きは、作業で書いたものより桁で沈みました。**
理由は①と同じで、姿勢は誰にでも当てはまるからです。
**読者が明日やるかどうかを判断できる粒度まで下ろすこと。**

# 【原稿】第4章 3要素を、自分の307本で検証する

まず前提の共有です。

私は𝕏の公式アナリティクスから、2025年1月〜12月の全投稿をCSVで
書き出しました。他人へのリプライや引用リポストを除いた
**自分のオリジナル投稿は307本**です。

ここで1つ、分析上の注意があります。

**月をまたいで単純平均してはいけません。**
私のアカウントは月によってインプレッションの水準が10倍以上違います。
伸びていた月の投稿が多い型は、それだけで「強い型」に見えてしまいます。

なので以下ではすべて、**その月の中央値を1.0としたときの相対値**で出します。
「2.0倍」なら、同じ月の平均的な自分の投稿の2倍、という意味です。

## ①表現の具体性 —— 実測でも一番強い

まず、無料パートで書いた「具体的な主語」から。

| 入っているもの | 本数 | 同じ月の自分と比べて |
|---|---|---|
| **年齢（◯才）** | 25本 | **3.3倍** |
| **学歴** | 71本 | **2.1倍** |
| 数字（何でも） | 90本 | 1.9倍 |
| セリフ「」『』 | 139本 | 1.2倍 |

**「早稲田卒の25才」を擦っている理由が、数字でも出ました。**

セリフが1.2倍と控えめに見えますが、これは**私の投稿の7割にすでにセリフが
入っている**ためです。差がつくほど珍しくない、というだけで、
セリフを外すと1.0を割ります。

## ★①には例外があります。リスト型だけ逆になる

ここからが本題です。

私の投稿の中に、こういう形式があります。

```
【本当に強いのはこういう人】

←強い人　　　　　　弱い人→
・80点で十分　　　・100点を求める
・受け流す天才　　・抱え込む天才
・うまくサボれる　・常にマジメすぎる
```

このリスト形式は、私の**全投稿で1位（1272万インプレッション）**を取っています。
ところがこの型に限って、**具体的な人物を出すとインプレッションが
10分の1**になりました。

最初は意味が分かりませんでした。①と真逆だからです。

考えて出した答えはこうです。

**リスト型は、読者が自分を当てはめる"枠"だからです。**

「早稲田卒の25才」と書くと、読者はその人物を**観察する側**に回ります。
物語ならそれでいいのですが、リストは**自己採点表**です。
枠に他人が座っていると、読者は自分を入れられません。

**では、リスト型では具体性を捨てるのか。捨てません。載せる場所を変えます。**

```
×  ・怒られたら3日引きずる人が…    ← 人物に載せる
○  ・寝たら忘れる　　・3日引きずる  ← 行動に載せる
```

**主語は空のまま、述語だけを具体的にする。**
無料パートで挙げた「怒られたら3日引きずる人」から、
**人物の部分だけを落とした形**だと思ってください。

まとめるとこうです。

| 形式 | 具体性をどこに載せるか |
|---|---|
| ストーリー型・面接官型・観察型・短文型 | **人物**（◯◯卒の◯才、セリフ） |
| **リスト型** | **行動だけ**（人物は出さない） |

私はここを間違えて、リスト型に人物を入れた下書きを作ったことがあります。
出す前に数字で気づけたのは、全部エクスポートして数えていたからです。

## ②テーマの8:2 —— 測ろうとして、失敗しました

正直に書きます。**私はこれを検証できていません。**

やろうとしたことはこうです。「2割の反論」が起きているなら、
**返信が多いはず**。だから返信数の多い投稿ほど伸びているはずだ、と。

結果は逆でした。返信÷いいねで4つに分けると、こうなります。

| 返信の多さ | 本数 | 同じ月の自分と比べて |
|---|---|---|
| 返信が少ない | 51本 | **8.6倍** |
| やや少ない | 50本 | 1.2倍 |
| やや多い | 50本 | 0.8倍 |
| 返信が多い | 50本 | 0.5倍 |

一見「反論されないほうが伸びる」に見えます。**が、これは罠です。**

**伸びた投稿では、いいねが返信よりはるかに速く増えます。**
返信÷いいねの分母が勝手に膨らむので、伸びた投稿ほど比率が下がるのは
当たり前なんです。上位20本の返信/いいね比は0.011、全体は0.088。
**これは「反論の量」ではなく「バズの規模」を測ってしまっています。**

なので8:2説は、**私の手元のデータでは肯定も否定もできません。**

ただし、**1つだけ確実に言えることがあります。**

**返信数そのものを目的にしないでください。**
返信が多い群は実際に伸びていません。
「反論を生む」を「絡まれにいく」と取り違えると、逆効果になります。

狙うのは**「自分の場合は…」と言いたくなること**であって、
**「それは違う」と言い返されること**ではありません。
この2つは似て見えて、集まる人がまったく違います。

## ③読みやすさ —— 数字は無料パートに載せたとおり

1行は中央値18字、伸びた20本では16字。
文の途中で改行しない。箇条書きは姿勢ではなく作業で書く。

ここは無料パートで全部出しました。**隠すほどの話ではないからです。**

# 【原稿】第5章 PRポストの本当の数式 ★この章が本体

無料パートで、私はこう書きました。

> PRポストのインプ数 ＝ 元ポストのインプ数 × 元ポストの詳細クリック率

**すみません。この式は間違っています。**

自分のデータを全部数えて初めて気づきました。順番に説明します。

## まず、詳細クリック率を実際に測ってみた

「詳細クリック」は、140字を超えたポストで「さらに表示」を押したり、
リプ欄を開いたときに発生します。

500インプレッション以上の自分の投稿139本で測りました。

**詳細クリック率の中央値は 0.62% でした。**

そして驚いたのが、ここです。

| | 詳細クリック率 |
|---|---|
| 全体（139本） | 0.62% |
| **とくに伸びた上位20本** | **0.68%** |
| 伸びなかった下位50本 | 0.74% |

**ほとんど動きません。** 文字数で分けても同じでした。

| 本文の長さ | 詳細クリック率 |
|---|---|
| 〜100字 | 0.61% |
| 100〜140字 | 0.60% |
| 140〜200字 | 0.65% |

**書き方を変えても、詳細クリック率は0.6%前後から動かない。**
これが1つ目の発見です。

## 次に、PRポストが実際にどれだけ届いているかを測った

元ポストとPRポストのペアを53組つくって、
**PRポストのインプ ÷ 元ポストのインプ**を計算しました。

**中央値は 6.3% でした**（四分位で2.6%〜9.2%）。

**0.62%と6.3%。10倍ちがいます。**

つまり、**PRポストに届いているインプレッションのうち、
詳細クリック経由で説明できるのは1割だけ**ということです。

残り9割はどこから来ているのか。答えは単純で、
**𝕏がタイムライン上で、元ポストの下に自分の返信をそのまま表示するから**です。
読者は詳細を開いていません。**スクロールの途中で、勝手に目に入っています。**

## だから、正しい式はこうなります

```
PRポストのインプ ＝ 元ポストのインプ × 約6%
```

**この6%は、ほぼ固定です。** インプレッションの規模で分けても動きません。

| 元ポストのインプ | 本数 | 到達率 |
|---|---|---|
| 〜3万 | 2本 | 8.6% |
| 3〜20万 | 20本 | 5.4% |
| 20〜100万 | 15本 | 10.3% |
| 100万〜 | 16本 | 5.3% |

**ここから導かれる結論は、身も蓋もないものです。**

**PRポストの届く量は、元ポストのインプでほぼ決まります。**
詳細クリックを増やそうとする工夫（「続きはリプで」など）に時間を使うより、
**元ポストを1本でも大きくバズらせるほうが、10倍効きます。**

## ただし、クリック率は規模が大きいほど下がる

もう1つ、重要な数字があります。**PRポストのURLクリック率**です。

| 元ポストのインプ | PRポストのクリック率 |
|---|---|
| 3〜20万 | **0.26%** |
| 20〜100万 | 0.07% |
| 100万〜 | 0.04% |

**大きくバズるほど、クリック率は下がります。**

理由は想像がつくと思います。**バズが大きくなるほど、
自分のテーマに興味がない人にまで届くから**です。
100万インプの大半は「たまたま流れてきた人」で、
その人たちは転職サービスに登録しません。

**なので収益はこうなります。**

```
クリック数 ＝ 元ポストのインプ × 約6% × クリック率（0.04〜0.26%）
```

クリック率が下がるぶん、収益はインプに比例しては伸びません。
**それでも、超特大の1本は圧倒的です。**

私の8ヶ月ぶんの全URLクリックは5,314でした。
**そのうち2,820が、たった1本のポストから出ています。**

**全期間の53%が、1本です。**

その1本が何だったのか、いくらになったのかは、第7章で公開します。

## この章の結論

- **詳細クリック率は書き方でほとんど動かない（0.6%前後で固定）**
- **PRポストの到達率は元ポストの約6%。これも固定**
- **したがって、改善余地があるのは「元ポストのインプ」と
  「PRポストのクリック率」の2つだけ**
- **元ポストを大きくする**のが最優先。ただし大きくなるほど
  クリック率が落ちるので、**テーマは自分の商材とズラさない**

無料パートで「バズったので宣伝、は悪手」と書いたのは、
感覚ではなくこの数字が理由です。**大きくバズるほど、
関係ない人の割合が増える。** だから元ポストの時点で、
**商材に繋がるテーマを選んでおく必要があります。**

# 第6〜8章の骨子（原稿はこれから）

## 第6章 使っている型のカタログ

**noteに出すのは4〜5型に絞ってください。** 全部出すと薄くなります。

出す価値があるのは、実測が強い順に:

1. **リスト型**（1272万・全期間1位。かつ全クリックの53%）
2. **面接官型**（「実は落とすのが」の形。導線に一番近い）
3. **上司の一言型**（当たり外れが最大。最大522万）
4. **人物観察型**（「◯◯卒の◯才」。枚数の稼ぎ頭）

各型について、**構造・実測・失敗例**の3点セットで書くと厚みが出ます。
失敗例が入っているnoteは少ないので、ここが差別化になります。

## 第7章 ポストごとの収益、全部公開

**冒頭のフックの回収先です。ここが一番読まれます。**

- 収益上位のポストを、**インプ / クリック / 収益**の3列で並べる
- 22万円の1本が、第5章の「全クリックの53%」と同じ1本であることを見せる
- **意外な事実を1つ入れる**: 一番バズった投稿が一番稼いだ投稿とは限らない、など

## 第8章 続ける仕組み

ここは「再現性」を買った読者への回答です。

- ネタの調達元（本業・リプ欄・他SNS・過去投稿の焼き直し）
- **同じ型を続けると飽きられる**ので、型を交互に出す
- 下書きを在庫として持つ（その日に考えない）
