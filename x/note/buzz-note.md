# 【原稿】無料部分の補強

## ③読みやすい文構造（差し替え版）

𝕏のタイムラインをスクロールしていて、最後まで文章を読むポストって
せいぜい1-2割じゃないですか？
それだけ𝕏には文字・情報が溢れてる中で、「いかに最後まで読んでもらうか？」は
基本であり地味に大事なポイントです。

たとえば日本語の基本とも言えますが、

- だらだらと書くより、句読点を入れてリズム良く
- 漢字ばかりでなく、適度にひらがなも混ぜて
- 最初の1行で「おっ？」と思わせるキャッチーな文言を
- 同じ意味ならできるだけ短い言葉で

このへんは諸先輩方のnoteや書籍でも紹介されているので、私からは
**自分の投稿を全部数えて分かったこと**を3つだけ足しておきます。

**（1）1行は16字**

私の投稿の1行は中央値18字でした。
そして**とくに伸びた20本に限ると16字**です。
1行が40字を超える行の割合も、全体では9.3%あるのに、伸びた20本では3.6%。

**短いほうが伸びる、ではありません。** 順番が逆で、
**最後まで読まれる文章を書こうとすると、勝手にこの長さになる**という話です。

**（2）ただし、文の途中で改行しない**

これは私が一番やりがちなミスでした。「1行を短く」を意識しすぎると、

```
マネージャーになりたての頃、
部下に進捗を聞いただけなのに、
顔がこわばった。
```

こうなります。読みやすそうに見えて、実際は**1文を読むのに3回も目が
止まっています。** 正解はこうです。

```
マネージャーになりたての頃、部下に進捗を聞いただけなのに顔がこわばった。
```

**改行は文と文の間に入れるもので、文の中に入れるものではありません。**
「1行を短く」は「1文を短く」と読み替えてください。

**（3）箇条書きは「姿勢」ではなく「作業」で書く**

これが一番差が出ました。同じ「伸びる新人」というテーマでも、

```
×  ・素直に受け止める     ← 姿勢
　　・当事者意識がある
　　・成長意欲が高い

○  ・「ここまでは分かりました」と言える     ← 作業
　　・「あと30分で出します」と言える
```

**姿勢で書いた箇条書きは、作業で書いたものより桁で沈みました。**
理由は①と同じで、姿勢は誰にでも当てはまるからです。
**読者が明日やるかどうかを判断できる粒度まで下ろすこと。**

# 【原稿】第4章 3要素を、自分の307本で検証する

まず前提の共有です。

私は𝕏の公式アナリティクスから、2025年1月〜12月の全投稿をCSVで
書き出しました。他人へのリプライや引用リポストを除いた
**自分のオリジナル投稿は307本**です。

ここで1つ、分析上の注意があります。

**月をまたいで単純平均してはいけません。**
私のアカウントは月によってインプレッションの水準が10倍以上違います。
伸びていた月の投稿が多い型は、それだけで「強い型」に見えてしまいます。

なので以下ではすべて、**その月の中央値を1.0としたときの相対値**で出します。
「2.0倍」なら、同じ月の平均的な自分の投稿の2倍、という意味です。

## ①表現の具体性 —— 実測でも一番強い

まず、無料パートで書いた「具体的な主語」から。

| 入っているもの | 本数 | 同じ月の自分と比べて |
|---|---|---|
| **年齢（◯才）** | 25本 | **3.3倍** |
| **学歴** | 71本 | **2.1倍** |
| 数字（何でも） | 90本 | 1.9倍 |
| セリフ「」『』 | 139本 | 1.2倍 |

**「早稲田卒の25才」を擦っている理由が、数字でも出ました。**

セリフが1.2倍と控えめに見えますが、これは**私の投稿の7割にすでにセリフが
入っている**ためです。差がつくほど珍しくない、というだけで、
セリフを外すと1.0を割ります。

## ★①には例外があります。リスト型だけ逆になる

ここからが本題です。

私の投稿の中に、こういう形式があります。

```
【本当に強いのはこういう人】

←強い人　　　　　　弱い人→
・80点で十分　　　・100点を求める
・受け流す天才　　・抱え込む天才
・うまくサボれる　・常にマジメすぎる
```

このリスト形式は、私の**全投稿で1位（1272万インプレッション）**を取っています。
ところがこの型に限って、**具体的な人物を出すとインプレッションが
10分の1**になりました。

最初は意味が分かりませんでした。①と真逆だからです。

考えて出した答えはこうです。

**リスト型は、読者が自分を当てはめる"枠"だからです。**

「早稲田卒の25才」と書くと、読者はその人物を**観察する側**に回ります。
物語ならそれでいいのですが、リストは**自己採点表**です。
枠に他人が座っていると、読者は自分を入れられません。

**では、リスト型では具体性を捨てるのか。捨てません。載せる場所を変えます。**

```
×  ・怒られたら3日引きずる人が…    ← 人物に載せる
○  ・寝たら忘れる　　・3日引きずる  ← 行動に載せる
```

**主語は空のまま、述語だけを具体的にする。**
無料パートで挙げた「怒られたら3日引きずる人」から、
**人物の部分だけを落とした形**だと思ってください。

まとめるとこうです。

| 形式 | 具体性をどこに載せるか |
|---|---|
| ストーリー型・面接官型・観察型・短文型 | **人物**（◯◯卒の◯才、セリフ） |
| **リスト型** | **行動だけ**（人物は出さない） |

私はここを間違えて、リスト型に人物を入れた下書きを作ったことがあります。
出す前に数字で気づけたのは、全部エクスポートして数えていたからです。

## ②テーマの8:2 —— 測ろうとして、失敗しました

正直に書きます。**私はこれを検証できていません。**

やろうとしたことはこうです。「2割の反論」が起きているなら、
**返信が多いはず**。だから返信数の多い投稿ほど伸びているはずだ、と。

結果は逆でした。返信÷いいねで4つに分けると、こうなります。

| 返信の多さ | 本数 | 同じ月の自分と比べて |
|---|---|---|
| 返信が少ない | 51本 | **8.6倍** |
| やや少ない | 50本 | 1.2倍 |
| やや多い | 50本 | 0.8倍 |
| 返信が多い | 50本 | 0.5倍 |

一見「反論されないほうが伸びる」に見えます。**が、これは罠です。**

**伸びた投稿では、いいねが返信よりはるかに速く増えます。**
返信÷いいねの分母が勝手に膨らむので、伸びた投稿ほど比率が下がるのは
当たり前なんです。上位20本の返信/いいね比は0.011、全体は0.088。
**これは「反論の量」ではなく「バズの規模」を測ってしまっています。**

なので8:2説は、**私の手元のデータでは肯定も否定もできません。**

ただし、**1つだけ確実に言えることがあります。**

**返信数そのものを目的にしないでください。**
返信が多い群は実際に伸びていません。
「反論を生む」を「絡まれにいく」と取り違えると、逆効果になります。

狙うのは**「自分の場合は…」と言いたくなること**であって、
**「それは違う」と言い返されること**ではありません。
この2つは似て見えて、集まる人がまったく違います。

## ③読みやすさ —— 数字は無料パートに載せたとおり

1行は中央値18字、伸びた20本では16字。
文の途中で改行しない。箇条書きは姿勢ではなく作業で書く。

ここは無料パートで全部出しました。**隠すほどの話ではないからです。**

# 【原稿】第5章 収益を増やすために、実際に変えられるのは2つだけ ★本体

この章のゴールは1つです。

**あなたが明日から何をやめて、何を変えるかを決めること。**

そのために、まず**変えても無駄なもの**から潰します。
やることを増やす前に、やらなくていいことを捨てたほうが早いからです。

## 収益の数式を、分解しなおす

アフィ収益はこう決まります。

```
収益 ＝ PRポストのインプ × クリック率 × 登録率 × 単価
```

そしてPRポストのインプは、無料パートでこう説明しました。

```
PRポストのインプ ＝ 元ポストのインプ × 詳細クリック率
```

**この後半、実は間違っています。** 自分のデータを全部数えて気づきました。
そして**間違いだと分かったこと自体が、時間の節約になります。**

## 【変えても無駄①】詳細クリック率は、書き方でほぼ動かない

「詳細クリック」は、140字超のポストで「さらに表示」を押したり、
リプ欄を開いたときに発生します。

500インプ以上の自分の投稿139本で測りました。

| | 詳細クリック率 |
|---|---|
| 全体（139本） | **0.62%** |
| とくに伸びた上位20本 | 0.68% |
| 伸びなかった下位50本 | 0.74% |

**伸びても伸びなくても0.6〜0.7%。** 文字数で分けても同じでした。

| 本文の長さ | 詳細クリック率 |
|---|---|
| 〜100字 | 0.61% |
| 100〜140字 | 0.60% |
| 140〜200字 | 0.65% |

**書き方をどういじっても、0.6%から動きません。**

### だから、以下は今日やめていいです

- **「続きはリプ欄で」で引っぱる** —— 詳細クリックは増えません
- **わざと140字を超えさせて「さらに表示」を押させる** —— 効きません
- **リプ欄を伸ばすために自分で連投する** —— 詳細クリック率は動きません

**𝕏界隈でよく言われる施策ですが、少なくとも私のアカウントでは
1年ぶんのデータで効果が確認できませんでした。**

## 【変えても無駄②】PRポストの到達率も、ほぼ固定

じゃあPRポストにはどれだけ届いているのか。
元ポストとPRポストのペアを53組つくって測りました。

**PRポストのインプ ÷ 元ポストのインプ ＝ 6.3%**（四分位2.6〜9.2%）

**0.62%と6.3%。10倍ちがいます。**

つまり、**PRポストに届いたインプのうち、詳細クリックで説明できるのは
1割だけ。** 残り9割は、**𝕏がタイムライン上で元ポストの下に自分の返信を
そのまま表示している**ぶんです。読者は詳細を開いていません。
**スクロールの途中で、勝手に目に入っています。**

そしてこの6%も、規模を変えても動きません。

| 元ポストのインプ | 本数 | 到達率 |
|---|---|---|
| 5千〜5万 | 10本 | 8.6% |
| 5〜20万 | 12本 | 5.4% |
| 20〜100万 | 15本 | 10.3% |
| 100万〜 | 16本 | 5.3% |

**PRポストの届く量は、元ポストのインプで決まります。それだけです。**

## ということは、変えられるのは2つだけ

```
収益 ＝ 元ポストのインプ × 6%（固定） × クリック率 × 登録率 × 単価
　　　　　　　↑これ                        ↑これ
```

**① 元ポストのインプ**と、**② PRポストのクリック率**。この2つです。

以下、それぞれ「どれだけ動くのか」を実数で見ます。

## 【変えられる①】元ポストのインプ —— ただし、効率は落ちます

ここで多くの人が誤解します。**インプが10倍になれば収益も10倍、
ではありません。**

| 元ポストのインプ | 本数 | クリック率 | **10万インプあたりのクリック** |
|---|---|---|---|
| 5千〜5万 | 10本 | 0.28% | **11.4** |
| 5〜20万 | 12本 | 0.20% | 5.8 |
| 20〜100万 | 15本 | 0.07% | 6.0 |
| 100万〜 | 16本 | 0.04% | **0.7** |

**同じ10万インプでも、小さいポストのほうが16倍効率がいい。**

理由は想像がつくと思います。**バズが大きくなるほど、自分のテーマに
興味がない人にまで届くから**です。100万インプの大半は
「たまたま流れてきた人」で、その人たちは登録しません。

**では中規模を量産すればいいのか。それも違います。**

100万超えの16本が生んだクリックは合計4,543。
5千〜5万の10本は合計70です。**効率は16倍悪くても、絶対量では
桁がちがいます。**

**結論はこうです。**

> **元ポストのインプは、大きいほうがいい。ただし「インプを増やせば
> 比例して稼げる」と思って大バズだけを追うと、効率が落ちた状態で
> 消耗します。**

そして**もっと大事なのは、次の②です。**

## 【変えられる②】クリック率 —— ここが本当の勝負どころ

上の表を見ると、クリック率は規模で決まってしまうように見えます。
100万超えでは0.04%が普通です。

**ところが、1本だけ例外があります。**

私の8ヶ月ぶんの全URLクリックは5,314。
**そのうち2,820が、たった1本から出ています。全体の53%です。**

そのポストのPRポストは、**96.9万インプで2,820クリック。
クリック率は0.29%**でした。**同じ100万規模の平均（0.04%）の7倍**です。

規模は同じ。何が違ったのか。

**元ポストのテーマと、商材が一致していたことです。**

その元ポストは、こういう内容のリスト型でした。

```
【本当に強いのはこういう人】
・80点で十分　　　・100点を求める
・受け流す天才　　・抱え込む天才
・うまくサボれる　・常にマジメすぎる
```

**完璧主義・抱え込み・マジメすぎ —— つまり性格の話です。**
そこに繋いだPRポストが、**性格分析ツール**でした。

```
実際、性格次第で向いてる仕事や環境は変わるよね。

ちなみに◯◯の性格分析なら自分の特徴をこんなに詳しく
教えてくれるから超オススメ。しかも無料だからもはやバグ… pr
```

**元ポストで性格の話をして、リプで性格診断に繋いでいる。**
読者からすると宣伝ではなく、**話の続き**です。

### これは1本の偶然ではありません

規模を揃えて（元ポスト5万〜100万）、訴求ごとにクリック率を比べました。

| PRポストの訴求 | 本数 | クリック率 |
|---|---|---|
| **性格分析** | 11本 | **0.116%** |
| 年収診断 | 13本 | 0.075% |
| その他 | 3本 | 0.020% |

**性格分析が年収診断の1.5倍、その他の6倍です。**

理由ははっきりしています。無料パートで「ターゲットになる人数」の話を
しましたが、**まさにそれが数字に出ています。**

- 転職エージェント …… **転職を考えている人**だけが対象
- 年収診断 …… **年収に不満がある人**が対象
- 性格分析 …… **働いている人全員**が対象

**間口が広い商材ほど、クリック率が高い。**
そして私の元ポストは、大半が「働く人あるある」です。
**元ポストの読者層と、商材の対象がそのまま重なっています。**

### 逆に、効いていなかったもの

私が良かれと思ってやっていて、**数字が付いてこなかった**ものも書きます。

| やっていたこと | あり | なし |
|---|---|---|
| **▼や↓の矢印装飾** | 0.079%（44本） | **0.218%（9本）** |
| 画像を貼る | 0.087%（51本） | 0.150%（2本） |

**矢印を付けたほうがクリック率が低い**という結果でした。

ただし**これは鵜呑みにしないでください。** 矢印なしの9本は
規模が小さいものに偏っていて、上の「規模が小さいほど効率がいい」が
そのまま出ている可能性があります。画像に至ってはサンプルが2本です。

**言えるのは「矢印と画像を足したからクリック率が上がる、という証拠は
私のデータには無い」までです。** ここは今後ちゃんと検証します。
**装飾を工夫する時間があるなら、次の節に使ってください。**

## で、明日から何をするか

ここまでを、やることの順に並べ替えます。

**1. 元ポストを書く前に、商材を決める**

一番効くのがこれです。**バズってからPRを考えると、
その時点でクリック率0.04%の側に落ちます。**

私の最高収益ポストは、**性格の話を書いてから性格診断に繋いだ**のではなく、
**性格診断に繋ぐつもりで性格の話を書いています。** 順番が逆です。

**2. 商材は「間口の広さ」で選ぶ**

同じ転職系でも、**転職エージェント < 年収診断 < 性格分析**の順に
対象者が広く、実測でもクリック率がその順でした。
**単価が高くても、対象が狭い商材は元が取れません。**

**3. PRポストは「話の続き」として書く**

書き出しを**「ちなみに」「実際、」で始めて、元ポストの結論を
1行だけ引き取る**。これだけで宣伝感が消えます。

```
×  【PR】あなたの市場価値、知っていますか？
○  実際、性格次第で向いてる仕事や環境は変わるよね。
　　ちなみに◯◯の性格分析なら〜
```

**4. 元ポストのインプを上げる（第4章の3要素）**

ここでようやくバズの話です。**1〜3を無視してインプだけ上げても、
効率が落ちた状態で人数を増やすだけ**になります。

**5. やめること**

- 「続きはリプで」などの詳細クリック狙い（0.6%から動きません）
- 矢印や画像の装飾を詰めること（効果を確認できていません）
- **バズった後にPR商材を探すこと**（一番もったいない）

## この章のまとめ

```
収益 ＝ 元ポストのインプ × 6%（動かない） × クリック率 × 登録率 × 単価
                ↑                             ↑
          第4章の3要素で上げる          テーマと商材の一致で7倍動く
```

**私の全クリックの53%を生んだ1本がやっていたのは、
「元ポストのテーマと商材を一致させる」ただそれだけです。**

どのポストだったか、いくらになったかは第7章で公開します。

# 第6〜8章の骨子（原稿はこれから）

## 第6章 使っている型のカタログ

**noteに出すのは4〜5型に絞ってください。** 全部出すと薄くなります。

出す価値があるのは、実測が強い順に:

1. **リスト型**（1272万・全期間1位。かつ全クリックの53%）
2. **面接官型**（「実は落とすのが」の形。導線に一番近い）
3. **上司の一言型**（当たり外れが最大。最大522万）
4. **人物観察型**（「◯◯卒の◯才」。枚数の稼ぎ頭）

各型について、**構造・実測・失敗例**の3点セットで書くと厚みが出ます。
失敗例が入っているnoteは少ないので、ここが差別化になります。

## 第7章 ポストごとの収益、全部公開

**冒頭のフックの回収先です。ここが一番読まれます。**

- 収益上位のポストを、**インプ / クリック / 収益**の3列で並べる
- 22万円の1本が、第5章の「全クリックの53%」と同じ1本であることを見せる
- **意外な事実を1つ入れる**: 一番バズった投稿が一番稼いだ投稿とは限らない、など

## 第8章 続ける仕組み

ここは「再現性」を買った読者への回答です。

- ネタの調達元（本業・リプ欄・他SNS・過去投稿の焼き直し）
- **同じ型を続けると飽きられる**ので、型を交互に出す
- 下書きを在庫として持つ（その日に考えない）
