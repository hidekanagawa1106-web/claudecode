# 下書き在庫

**日付も投稿枠も割り当てません。** Hideさんが好きなときに好きな順で使います
（自分で思いついた投稿も混ざるため、こちらで日程を管理しても意味がないので）。

`/x-draft` は**在庫に2本追加**します。何日ぶんかは考えません。

## 在庫の目標構成

**A と 非A が半々**になるように補充します。Hideさんがどれを選んでも、
非Aが混ざる余地が残るようにするためです（`formats.md` の骨格グループ）。

| グループ | 型 |
|---|---|
| A | 型1・型2・型3・型5 |
| B | 型4 対比リスト |
| C | 型7 会話だけ |
| D | 型8 短文 |

使ったら「使用済み」へ移し、`/x-review` で `posts.csv` に記録します。

## 承認済み（そのまま使えます）

### 型2 面接官・裁量（A）／ T001 お盆・期限8/20

```
盆休みに入ると、毎年キャリアを考え始める人が増える。

ベンチャーで面接官してますが、志望動機でよくNGにするのは
・年収を上げたい
・今の会社に将来性がない
・成長できる環境がいい
などあるが、実はよく落とすのが、

『裁量のある環境で働きたい』

と言う人。
裁量って渡すものじゃなくて、空いてる穴を勝手に埋めた人に後から付いてくるからね。
渡されるまで待つ人に任せると、結局こっちが見に行く手間が増えるんだよな。
```

**1stリプ**: 「ただ、志望動機を完璧に作っても、年収はその会社の相場で決まるんだよな…
自分が本当はいくらで売れるのか、先に知らないと交渉にすらならない。」

**T001の期限が 8/20。** これだけは早めに。

### 型2 面接官・一人で乗り越えた（A）

```
ベンチャーで面接官してますが、見送りの理由でよくあるのは
・スキルが足りない
・経験が合っていない
・転職回数が多い
などあるが、実はけっこう引っかかるのが、

『努力して、一人で乗り越えてきました』

と言う人。
一人で抱えて成果を出す人は、詰まったときに誰にも見えないからね。
入ってから困るのは、本人より周りなんだよな。
```

**1stリプ**: 「ただ、落ちる理由が分かっても、自分がいくらで売れるかを
知らないと交渉できないんだよな…」

出典: [doda人事ジャーナル](https://www.dodadsj.com/content/230915_answers_that_require_attention/)

### 型1-二段 後輩に異動希望（A）

```
新卒3年目、はじめて後輩をつけてもらったのに、
半年で「異動させてほしい」と言われた。

上司に報告したら、怒られると思っていたのに、

『あいつ、何が得意やった？』

と聞かれた。

答えられなかった。
苦手なところなら、いくらでも言えたのに。

『できひんとこばっかり見てたら、そら逃げるわ』

指導してるつもりで、
減点する係をやってただけだったんだよな。
```

**1stリプ**: 「ただ、こういうことを指摘してくれる上司に当たるかは運なんだよな…
誰の下で育つかで、その後の年収まで変わるのがしんどいところ。」

**記録時の `--format` は `型1-二段`。** 通常の型1と混ぜると検証が壊れます。

### 型7 会話だけ（C）★型7の初回

```
面接官「これまでで一番大変だった仕事は？」

候補者「特に困難と感じたことはないです」

面接官「本当に一度も？」

候補者「はい。どんな仕事も前向きに捉えるタイプなので」

面接官（詰まったときの話が、一つも出てこないな）
```

**1stリプ**: 「ただ、答え方を直したところで、提示される年収はその会社の相場なんだよな…
先に自分の相場を知っておかないと、直した意味がなくなる。」

- 素材は型2と同じバンクなので、**中身ではなく骨格だけの比較**になります
- **記録時の `--format` は `型7`**
