# 下書き在庫

**日付も投稿枠も割り当てません。** Hideさんが好きなときに好きな順で使います
（自分で思いついた投稿も混ざるため、こちらで日程を管理しても意味がないので）。

`/x-draft` は**在庫に2本追加**します。何日ぶんかは考えません。

**予約投稿ぶんは、こちらからは見えません。** Hideさんが先の日付で予約している
投稿があっても、レビューを出してもらうまでこちらは知りようがないので、
**「記録が無い＝投稿していない」とは扱いません。**
予約したものは下の「予約済み」に移してもらえると在庫の数が合いますが、
移し忘れても壊れないようにしてあります。

## 在庫の目標構成

**A と 非A が半々**になるように補充します。Hideさんがどれを選んでも、
非Aが混ざる余地が残るようにするためです（`formats.md` の骨格グループ）。

| グループ | 型 |
|---|---|
| A | 型1・型2・型3・型5 |
| B | 型4 対比リスト |
| C | 型7 会話だけ |
| D | 型8 短文 |

数えるのは**承認済み＋要レビュー**だけです。予約済みはもう出る先が決まっているので
在庫としては数えません。

状態は4つ。**承認済み → （予約したら）予約済み → 投稿 → 使用済み。**
`/x-review` で `posts.csv` に記録した時点で「使用済み」へ移します。
