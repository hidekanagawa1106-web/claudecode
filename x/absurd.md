# 上司の理不尽一覧（素材帳）

**あるある系の上流の素材帳です。** ここから型12（会話劇）・型11（箇条書きリスト）・
型1（上司の一言）・型8（短文）が生えます。
**ネタ単位ではなく"理不尽そのもの"を貯める場所**なので、セリフや場面はまだ付けません。

**印の意味**

| 印 | 向いている型 | 条件 |
|---|---|---|
| **◆** | **型12 会話劇** | 上司の2文で矛盾が完結する（`images.md`） |
| ■ | 型11 箇条書きリスト | 一項目として短く言い切れる（`lists.md`） |
| ● | 型1 上司の一言／型8 短文 | 場面と決め台詞が立つ |

**⚠ 入れないもの**

- **暴言・人格否定・ハラスメント。** 笑いにならず、炎上します
- **特定の会社や個人が割れるもの**
- **自分の職場でしか起きないこと。** 「どこにでもある理不尽」がこの帳面の線です

## 使い方

1. **◆から型12を作る**。上司の2文に落とし、`images.md` の3条件で検品する
   （同じ息で続くか／1枚の絵で起きるか／返しは短く素直か）
2. **■を7〜11個まとめて型11にする**。字数階段と毒の位置は `lists.md` の規定どおり
3. **●は場面と決め台詞がある**ので、型1（上司の一言）か型8（短文）に回す
4. **使ったものには印を付けず、`images.md` / `lists.md` の「使用済み」に移す**

**⚠ 全部を上司批判にしないこと。** このアカウントは元リクのマネージャーで、
いまも面接官です。**理不尽を並べるだけだと、ただの愚痴アカウント**になります。
**3〜4本に1本は「判定する側」の投稿**（型2・型11-判定）を挟んでください
（`SKILL.md` の配分）。
