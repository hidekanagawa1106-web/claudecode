## 集め方

### 一番速い方法: X公式検索の `min_faves:`

**Hideさんのブラウザで叩いてください。** ログインが要るので Claude Code からは
実行できませんが、**バズった投稿だけが一覧で並びます。**

アカウント指定で、上のリストの人を狙い撃ちする:

```
from:sayu5632j min_faves:3000
from:mei3_biz min_faves:5000
from:kei__tenshoku min_faves:3000
```

テーマで横断的に探す:

```
面接官 min_faves:5000 -filter:replies lang:ja
転職 上司 min_faves:10000 -filter:links lang:ja
新卒 言われた min_faves:5000 lang:ja
部下 マネジメント min_faves:5000 lang:ja
```

期間を切る:

```
面接官 min_faves:3000 since:2026-08-01 until:2026-08-31
```

**結果をスクショで投げれば `/x-scout` が構造分解して `swipe.csv` に入れます。**

### Claude Code 側でできること

- **新しい監視対象の発掘** —— Web検索の `site:x.com` で掘れます。このリストもそれで作りました
- **キーワード監視** —— Yahoo!リアルタイム検索なら本文・アカウント・いいね数まで取れます。
  ただし**新着順しかなく**、返ってくるのは数分前の投稿ばかりでヒット率は低いです

### やらないこと

**スクレイピング・ブラウザ自動化はX規約違反**（永久凍結対象）です。
迂回路として検討しません。

## 運用

**週1回、5本ほど持ち込む**のが想定です。`min_faves:` で探せば数分で終わります。

見るときの優先順位:

1. **Aのアカウントで、うちと同じ型が伸びているか** —— `winners.md` の仮説
   （失敗ドラマ40倍／作業か姿勢かで14倍）が他人のデータでも成立するかの検証
2. **うちに無い構造**（会話形式など）が伸びていないか
3. テーマの発見

**リストは固定ではありません。** 稼働していないアカウントは消し、
`/x-scout` で良い構造が見つかったアカウントは足してください。
