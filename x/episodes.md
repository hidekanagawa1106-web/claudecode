## 種類A: 言われた一言（→ 型1／最強）

**実測521万・426万を叩き出した型の素材。** 過去11本の1位と2位。

**「一言」だけでは素材になりません。** その前の**自分の失敗**が必須です。
失敗のドラマを省いた「質問したら良い答えが返ってきた」形は17万・6.4万まで落ちます
（30分の1）。

必要な4点:

- **自分の失敗** — 何をやらかしたか。言い訳なしで
- **そのあとの状況** — 移動中、呼び出された、など物理的な描写。緊張・恐怖
- **言われた一言** — そのままの言い回し。予想外であること
- **今の解釈** — 当時は分からなかったが今なら分かること

```
### A001 客先への道中
- 自分の失敗: 新卒1年目、◯◯の失態で顧客が「上司も連れて謝りにこい」とブチギレ
- 状況: 客先への道中、緊張MAX
- 一言: 「いい歳したオッサンが本気で怒る様子なんて滅多に見れへんで。楽しみやな。」
- 誰: 当時の上司
- 今の解釈: 今でも感謝してる
- 使用: 2025-11-05（521万）
```

## 種類B: 観察した人の行動（→ 型3・型5）

**学歴と年齢が引きの装置**として毎回機能しています。ここは必ず取ってください。

- **属性** — ◯◯卒／職種／年齢（「慶應卒のさわやか営業（29才）」）
- **具体的な行動を3つ** — **真似できる作業で書く**
- **核心の一つ** — 3つの中で特に効いているもの

**行動で書く。姿勢で書かない。** 実測: 箇条書きが作業（議事録の作り方）だった投稿は
333万、姿勢（深夜でも最速対応）だった投稿は23万。**14倍の差**がここで出ています。

```
### B001 議事録が会議中に完成している
- 属性: 慶應卒のさわやか営業（29才）
- 行動: 会議の前に共有 / 論点と決定事項を分ける / 次アクションを当事者で括弧つけ
- 核心: 『会議中に議事録が完成してる』
- 使用: 2025-11-17（333万）
```

## 種類C: 面接官として見たもの（→ 型2／転職導線の本命）

**実測155万。転職検討層に最も直撃し、プロフィールに来る動機が一番強い型です。**
過去11本で1本しかなく、**意識的に増やすべき素材**。

- **よくあるNG理由を3つ** — 読者が予想できる、ありきたりなもの
- **意外な1つ** — 実はこれで落とす、というもの
- **採用側の損得** — なぜそれがNGなのかをコストで説明できること

人格の否定にしないこと。落とす理由は必ず「採用側のコスト」に落とします。

```
### C001 「◯◯スキルを身に付けたい」
- よくあるNG: 明らかな他責 / 定時で帰りたい / 嫌な上司から逃げたい
- 意外なNG: 『◯◯スキルを身に付けたい』と言う人
- 採用側の損得: 事業ではなく自分のキャリアが大事な人は、マネジメントコストがかかる
- 使用: 2025-10-12（155万）
```

## 書き方のルール

**一次情報だけ。** Hideさん本人が見た・言われた・やったこと。エージェントは
**素材を創作しません**。足りなければ空欄のまま `/x-mine` で聞き返します。

**「具体的な一言」を必ず含める。** 刺さるかどうかはここだけで決まります。

- 弱い: 上司が励ましてくれた
- 強い: 「いい歳したオッサンが本気で怒る様子なんて滅多に見れへんで。楽しみやな。」

**自分を上げる話を入れない。** 過去11本に武勇伝は1本もありません。
Hideさんが登場するときは、常に**失敗している側か教わる側**です。

## 特定リスク

会社名・部署名・製品名・個人名は、素材帳の中にも書かない。
業種と規模だけ残す（「ベンチャー」「顧客」）。学歴と年齢は出してよい（引きの装置）。

事実と評価を分けて書く。「言われた内容」は事実、「最低な上司だった」は評価。
