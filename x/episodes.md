# 素材帳（一次素材）

**このファイルがこの仕組みの燃料タンクです。** ここが空だと、下書きは全部
「よくある転職あるある」になって伸びません。

体験談・暴露系で伸びない投稿の原因は、ほぼ100%ここの枯渇です。文章力ではありません。
`/x-mine` を週1回15分回して、常に10本以上の未使用素材を保っておいてください。

## 書き方のルール

**必ず一次情報だけを入れる。** Hideさん本人が見た・言われた・やった事実。
伝聞は「誰から聞いたか」を明記する。エージェントは**素材を創作しない**。
足りなければ空欄のままにして `/x-mine` で聞き返します。

**「具体的な一言」を必ず含める。** 体験談が刺さるかどうかは、ここだけで決まります。

- 弱い: 上司から理不尽なことを言われた
- 強い: 「君のためを思って言ってるんだよ」と、22時のオフィスで言われた

数字・時刻・固有の言い回し・その場の物理的な状況。この4つのどれかが入っていない
素材は、まだ素材になっていません。

## 特定リスクの扱い

前職・取引先・個人が特定できる形は避けてください。アカウントを失うリスクと、
実害が出たときの責任が釣り合いません。

- 会社名・部署名・製品名は書かない（素材帳の中でもです。流出したら同じことなので）
- 業種と規模だけ残す（例: 「SIer・従業員1000人規模」）
- 時期はぼかす（「数年前」）
- **事実と評価を分けて書く。** 「言われた内容」は事実、「最低な上司だった」は評価。
  投稿にするとき、断定的な評価は事実に落とす

## 書式

```
### E001 22時の「君のためを思って」
- 状況: SIer / 1000人規模 / 数年前 / 入社3年目
- 事実: 22時、定時後の作業を頼まれ、断ったら「君のためを思って言ってるんだよ」と言われた
- 一言: 「君のためを思って言ってるんだよ」
- 感情: 断る側が悪いことになる構造への気づき
- 転職文脈: この一言が出る組織は、個人の判断を組織の都合に読み替える癖がある
- 使用: 未使用
```

`使用` は投稿に使ったら `2026-08-11 朝 / posts.csv 参照` のように書き換えます。
一度使った素材も、**別の型で切り直せば再利用できます**（同じ素材を「暴露」で出して
伸びなかったなら「気づき」で出し直す）。捨てないでください。
