# X運用（@nekosukexx）の使い方

元リクルートのマネージャー／現ベンチャー面接官という立場から、
**他人の一言と行動を語る**投稿を1日3本、手動で投稿する運用。
型・文体・素材の要件はすべて**過去11本（2025/07〜11）の実測**から作られています。

## 全体像

```
週1  /x-mine    記憶から一次素材を掘る  → episodes.md（燃料タンク）
週1  /x-scout   競合の構造を分解する    → formats.md（型）
毎朝 /x-draft   素材 × 型 → 3本の下書き → コピペで手動投稿
毎晩 /x-review  アナリティクスを記録    → posts.csv / winners.md（勝ち筋）
                                              ↑
                        winners.md が翌朝の /x-draft に効く（これがループ）
```

**このループが閉じていることが全部です。** `/x-review` を飛ばすと winners.md が
育たず、`/x-draft` は毎朝ゼロから当てずっぽうを出すだけの機械になります。

## いま最優先でやること

**1stリプ側のインプレッションとリンククリックを毎回記録する。**

過去11本はこれが全部未計測です。つまり「どの型が拡散するか」は分かっていますが、
**「どの型が実際にクリックされるか」は一度も測られていません。**
インプレッションと導線は別物で、実測でも連動していませんでした
（333万インプレッションの投稿のエンゲージ率は0.28%）。

```
本文インプレッション → リプに降りた人 → リンクを踏んだ人
          リプ到達率        リプCTR
          └────────── 総合導線率 ──────────┘
```

10本溜まるまで、導線に関する判断は保留です。

## 1. 毎日

**朝** — `/x-draft` で3本。コピペで投稿。

**投稿1〜2時間後** — **バズを確認してから**1stリプに導線を追加。
下書きに1stリプ案が付いています。伸びていない投稿には貼らず、捨ててかまいません。
橋渡しの公式は `docs/funnel.md`。

**リプが付いたら本人が返す。** ここは自動化しません。返信のある会話は評価が
大きく変わるうえ、Xの規約上もAIリプライは事前承認が要ります。

**夜** — アナリティクスのスクショを投げて `/x-review`。

## 2. 毎週

```
/x-mine     素材の在庫が種類ごとに3本を切っていたら
/x-scout    伸びていた競合投稿を5本ほど持ち込む
```

## コマンド

```
python x/x_review.py              # 集計レポート
python x/x_review.py --last 20    # 直近20本
python x/x_review.py --add ...    # 1件記録（通常は /x-review 経由）
```

未指定の数値は 0 ではなく「未計測」として扱われ、率の集計から外れます。

## ファイルの役割

| ファイル | 役割 | 誰が更新するか |
|---|---|---|
| `episodes.md` | 一次素材。**燃料タンク**。種類A/B/C | `/x-mine` |
| `docs/voice.md` | 文体規定。過去11本から抽出済み | `/x-mine`（四半期） |
| `docs/formats.md` | 型ライブラリ。実測付き | `/x-scout` |
| `docs/funnel.md` | 1stリプの橋渡し。型ごとの入口 | 手動 |
| `docs/winners.md` | 何が効いたか。**この仕組みの本体** | `/x-review` |
| `posts.csv` | 全投稿の実績台帳（過去11本を投入済み） | `x_review.py` |
| `swipe.csv` | 競合の勝ち投稿 | `/x-scout` |

## 過去11本から確定していること

詳細は `docs/winners.md`。要点だけ:

- **「失敗ドラマ」の有無が40倍の差を生む。** 上司の一言型でも、自分の失敗から
  始まる2本は521万・426万、質問から始まる2本は17万・6.4万
- **箇条書きは「作業」で書くと333万、「姿勢」で書くと23万。** 14倍
- **他人が登場しない投稿は拡散しない。** 11本中の最下位（4万）がこれ
- **拡散とエンゲージ率は連動しない。** インプレッションだけ見ると判断を誤る

## 気をつけること

- **本文に外部リンクを貼らない。** リーチが30〜50%落ちます。導線は1stリプかプロフ
- **会社名・部署名・製品名は出さない。** 業種と規模だけ。学歴と年齢は出してよい
  （引きの装置として実際に機能しています）
- **広告表記（`pr`）を必ず入れる。** 現状は文末に小さく置いていますが、
  景表法のステマ規制での明瞭性に議論の余地があります。契約先の規約を一度
  確認してください（`docs/funnel.md`）
- **自動投稿・自動リプはしません。** アカウントを失うリスクに見合いません
