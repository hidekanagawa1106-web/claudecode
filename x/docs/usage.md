# X運用（@nekosukexx）の使い方

体験談・暴露系の投稿を1日3本、手動で投稿する運用。
下書き・実績分析・型の蓄積をエージェント側に寄せています。

## 全体像

```
週1  /x-mine    記憶から一次素材を掘る  → episodes.md（燃料タンク）
週1  /x-scout   競合の構造を分解する    → formats.md（型）
毎朝 /x-draft   素材 × 型 → 3本の下書き → コピペで手動投稿
毎晩 /x-review  アナリティクスを記録    → posts.csv / winners.md（勝ち筋）
                                              ↑
                        winners.md が翌朝の /x-draft に効く（これがループ）
```

**このループが閉じていることが全部です。** `/x-review` を飛ばすと winners.md が
育たず、`/x-draft` は毎朝ゼロから当てずっぽうを出すだけの機械になります。

## 1. 最初にやること（初回のみ）

```
/x-mine
```

2つ片付きます。

1. **文体の学習** — 既存投稿を10本ほど貼ってください（伸びたものを優先、スクショ可）。
   `docs/voice.md` の `<!-- -->` が埋まります
2. **素材の掘り出し** — インタビュー形式で15分。目標は未使用10本

**ここを飛ばして `/x-draft` を叩いても、一般論の投稿しか出ません。**

## 2. 毎日

**朝（自動）** — Routine が `/x-draft` を叩いて3本届きます。コピペで投稿。

**投稿1〜2時間後** — 反応が付いてきたら1stリプに導線を追加。
下書きに1stリプ案が付いています。**本文と同時に貼らないでください**
（伸びていない投稿にリンクを足しても意味が無く、リプ欄の1本目が広告だと
会話が始まりません）。

**リプが付いたら本人が返す。** ここは自動化しません。返信のある会話は評価が
大きく変わるうえ、Xの規約上もAIリプライは事前承認が要ります。

**夜** — アナリティクスのスクショを投げる。

```
/x-review
```

## 3. 毎週

```
/x-mine     素材の在庫が10本を切っていたら
/x-scout    伸びていた競合投稿を5本ほど持ち込む
```

## コマンド（スクリプト直叩き）

```
python x/x_review.py              # 集計レポート
python x/x_review.py --last 20    # 直近20本
python x/x_review.py --add ...    # 1件記録（通常は /x-review 経由）
```

## ファイルの役割

| ファイル | 役割 | 誰が更新するか |
|---|---|---|
| `episodes.md` | 一次素材。**燃料タンク** | `/x-mine` |
| `docs/voice.md` | 文体規定。AI臭を消す | `/x-mine`（初回と四半期） |
| `docs/formats.md` | 型ライブラリ | `/x-scout` |
| `docs/winners.md` | 何が効いたか。**この仕組みの本体** | `/x-review` |
| `posts.csv` | 全投稿の実績台帳 | `x_review.py` |
| `swipe.csv` | 競合の勝ち投稿 | `/x-scout` |

## 見る指標の順番

インプレッションを最初に見ないでください。目的が転職アフィリへの導線である以上、
本命はこの順です。

1. **プロフクリック率** — 導線の入口
2. フォロー増
3. エンゲージ率
4. インプレッション

`x_review.py` が出す「伸びたのにプロフィールに来ていない投稿」は、**数字が
大きくても失敗**として扱います。

## 気をつけること

- **本文に外部リンクを貼らない。** リーチが30〜50%落ちます。導線は1stリプかプロフ
- **前職・取引先・個人が特定できる形にしない。** 業種と規模だけ残す。
  事実と評価を分けて書く
- **ASPによってはX直リンクが規約違反です。** noteかLPを1枚挟む形にしてください
- **自動投稿・自動リプはしません。** アカウントを失うリスクに見合いません

## 期待値について

型ごとに3本、合計で30〜50本投稿するまでは、何が効くかは分かりません。
それまでは**当てにいくより、型のサンプルを均等に溜めるほうが早く前に進みます。**
この仕組みが買っているのは「試行回数 × 反復速度 × 何が効いたかの記憶」であって、
1本目からバズる保証ではありません。
