# X運用（@nekosukexx）の使い方

元リクルートのマネージャー／現ベンチャー面接官という立場から、
**他人の一言と行動を語る**投稿を手動で出す運用。

**1日の構成（2026-08-15以降）**

| | 本数 | 目的 | 見る指標 |
|---|---|---|---|
| **オリジナル** | 朝・晩の**2本** | 拡散と導線 | インプレッション・導線率 |
| **引用リポスト** | **3〜5本** | **引用元に拾ってもらい、相手のフォロワーに届く** | **リポスト数・フォロワー増** |

**引用RTをインプレッションで評価しないでください。** 狙いが違います
（`formats.md` の引用リポストの節）。在庫（`stock.md`）で管理するのは
オリジナルの2本だけです。

型・文体・素材の要件はすべて**実測**から作られています
（公式エクスポート208本。2025/05〜12の全投稿）。

**常設ページ（Artifact）**: 型カタログと運用ルールをブラウザで開ける形にしてあります。
URLと開き方は `x/note/pages.md`。

## 全体像

```
日次 /x-trend   今日の話題を拾う（ほぼ捨てる）→ topics.md
週1  /x-scout   競合の構造とテーマを分解      → swipe.csv / formats.md
随時 /x-mine    実体験を掘る（型1の補充用）   → episodes.md
毎朝 /x-draft   4ソース × 型 → 在庫に2本追加  → stock.md
                                                   ↓
                              Hideさんが好きなときに好きな順で投稿
                                                   ↓
毎晩 /x-review  アナリティクスを記録          → posts.csv / winners.md
                                                   ↑
                        winners.md が翌朝の /x-draft に効く（これがループ）
```

**このループが閉じていることが全部です。** `/x-review` を飛ばすと winners.md が
育たず、`/x-draft` は毎朝ゼロから当てずっぽうを出すだけの機械になります。

## 日付は管理しません

**下書きに「何日の朝ぶん」という札は付きません。** Hideさんは自分で思いついた
投稿も混ぜて出すので、こちらで日程を組んでも、そのとおりには進まないからです。

`/x-draft` がやるのは**在庫（`x/stock.md`）への2本の追加**だけ。
使う順番とタイミングはHideさんが決めます。

例外は**賞味期限のある時事ネタ**だけで、これは在庫に期限が明記されます。

### 予約投稿ぶんは見えない前提で組んであります

Xの予約投稿を先の日付に仕込んだ場合、それは**アナリティクスを渡すまで
こちらからは一切見えません。** そのため:

- **`posts.csv` の日付の空白は「投稿していない」ことを意味しません。**
  `/x-draft` も `/x-review` も、記録の途切れから投稿の有無を推測しません
- **在庫の数え方**は「承認済み」だけ。予約済みも未承認の下書きも数えません
- 予約したものを `stock.md` の「**予約済み**」へ移してもらえると在庫の数が
  合いますが、**移し忘れても壊れません**（多めに補充されるだけです）

## ネタはどこから来るか

実体験の掘り出しには限界があるので、**素材帳が空でも下書きが作れる**構成です。
優先順位は `docs/sources.md`。

1. **過去投稿の焼き直し** — 伸びたテーマを別の型で出し直す。最も確実
2. **スワイプ** — 他アカウントの構造とテーマを借りる（言い回しとエピソードは借りない）
3. **時事** — `topics.md` の在庫から。多くて1日1本
4. **実体験** — あれば最強。ただし枯れても止まらない

**型1（上司の一言）は当たり外れが最大です。** 57本の実測で中央値895、最大522万。
10万を超えたのは3本だけで、残りは数百〜数千。**宝くじなので在庫に1本まで。**

## 飽きさせないための骨格ローテーション

**型が5つあっても、型1・2・3・5 は骨格が同じ**でした（前振り→『決め台詞』→
同意誘導）。月2本のときは見えませんが、**1日2本＝月60本では並んで見えます。**

| グループ | 型 | 見た目 |
|---|---|---|
| **A** | 型1・2・3・5 | 10〜14行。実績はここに集中 |
| **B** | 型4 対比リスト | リスト。『』も締めも無い |
| ~~C~~ | ~~型7 会話だけ~~ | **廃止（2026-08-31）** |
| **D** | 型8 短文 | 5〜7行 |

**投稿の順番は管理できないので、在庫の構成で担保します。**

- **在庫の中で A と 非A を半々に保つ。** どこから取っても非Aが混ざります
- **在庫が0本のグループを作らない**
- **型4（B）を切らさない**（拡散でも導線でも最大なのに在庫0本）

**⚠ 「型7は中央値48,776で全型1位」は誤りでした**（2026-08-31）。4本のうち3本が
型5・型2・断言の誤判定で、本物の型7は1本・1,219impだけです。**型7は廃止しました。**
本数が少ないので確定ではありませんが、**導線率も2位**なので優先して試す価値があります。
型8は**未検証**なので、1本試して数字を見てから本数を決めます。

## 設定の一貫性が最大の弱点

外部ソースからネタを作る運用では、投稿単体の質より、**100本並べたときの一貫性**が
先に破綻します。在籍年数・上司の人数・経歴のズレを突かれるのが一番多い失敗です。

`docs/persona.md` に確定事項を固定してあります。**未確定の欄を先に埋めてください。**
空のまま投稿を作ると、そのつど違う設定が生まれます。

## 時事について

**生のXトレンドはほぼ使えません。** 実測（2026/08/11）の上位30語は
「打ち上げ成功／山の日／モンスト13周年／台風15号」で、橋が架かる語はゼロでした。
採用率は1割以下と考えてください。

使えるのは**仕事・キャリア系の時事**（賃上げ・人手不足・転職市場・AIと雇用）と、
**カレンダー要因**（4月の新人、6月の賞与、お盆のキャリア見直し、9月の転職活況）。
カレンダーは予測できるので事前に仕込めます。

時事は**入口にだけ**使います。1行目で触れて、2行目以降はいつもの型に戻る。

## 数字の見方（2026-08-15 に土台が変わりました）

公式エクスポート8ヶ月ぶん（自発208本）が揃い、推移が見えました。

| 月 | 本数 | 中央値 | 最大 |
|---|---|---|---|
| 2025-05 | 32 | 190 | 1,857 |
| 2025-07 | 41 | 182 | 426万 |
| 2025-08 | 34 | 2,320 | 16.9万 |
| **2025-09** | **53** | **31,347** | **1272万** |
| 2025-10 | 41 | 5,012 | 155万 |
| 2025-11 | 56 | 11,206 | 522万 |
| 2025-12 | 16 | 1,774 | 171万 |

**9〜11月は月41〜56本（ほぼ毎日1本以上）。12月は12日で止まっています。**
落ちた原因は型でも内容でもなく、**本数**です。
**戻す目標は9〜11月の水準**（中央値5,000〜31,000）です。

### 導線は全段つながりました（19ケース）

```
本文 100万 imp → リプ 10万 imp（到達率およそ10%）→ クリック 100〜400
```

**リプ到達率は5〜18%、中央値およそ10%。** 見込みはこれで計算できます。

**型ごとの総合導線率は、拡散の順位と一致しません。**

| 型 | 総合導線率 |
|---|---|
| **型2 面接官** | **0.0508%** |
| ~~型7 会話だけ~~ | ~~0.0402%~~ **誤判定（09/07は型5）。廃止** |
| 型4 対比リスト | 0.0162% |
| 型1 上司の一言 | 0.0141% |
| 型3 人物観察 | 0.0123% |

**型2で確実に拾い、型4で当てにいく。型3は拡散の土台。**（型7は廃止）
ただし絶対数は拡散が支配します（8ヶ月の全5,314クリックの53%が型4の1本）。

## 1. 毎日

**朝** — `/x-draft` で在庫に2本追加。投稿は `stock.md` から好きなものを選ぶ
（自分で思いついたものを出す日は、在庫をそのまま残しておけば構いません）。

**投稿1〜2時間後** — **バズを確認してから**1stリプに導線を追加。
伸びていない投稿には貼らず、捨ててかまいません。橋渡しの公式は `docs/funnel.md`。

**リプが付いたら本人が返す。** ここは自動化しません。返信のある会話は評価が
大きく変わるうえ、Xの規約上もAIリプライは事前承認が要ります。

**引用リポストを3〜5本。** その場で書きます。在庫では管理しません。

**毎朝6:00** — Routineが3日前の実績を自動取得して `winners.md` まで更新します。
スクショを投げる `/x-review` は、Routineが動かないときの手動代替です。

## 2. 随時

```
/x-trend    朝の下書き前。時事の在庫が3本を切っていたら
/x-scout    伸びていた競合投稿を5本ほど持ち込む（週1）
            探し方は accounts.md の min_faves: クエリ
/x-mine     型1の在庫が切れたら。他の型では不要
```

## コマンド

```
python x/x_review.py              # 集計レポート（手動記録の台帳）
python x/x_review.py --last 20    # 直近20本
python x/x_review.py --add ...    # 1件記録（通常は /x-review 経由）

python x/analytics.py             # 公式エクスポートのベースライン
python x/analytics.py --month 2025-12
python x/analytics.py --formats   # 型の自動分類を全件表示

python x/x_metrics.py             # X APIで3日前の1日ぶんを取得（要セットアップ）
python x/x_metrics.py --dry-run   # 書き込まずに確認
python x/x_match.py               # 投稿と在庫（stock.md）を照合
```

未指定の数値は 0 ではなく「未計測」として扱われ、率の集計から外れます。

## 公式エクスポート（月イチでこれをやる価値があります）

X のアナリティクスから月ごとのCSVをダウンロードして `x/data/raw/` に置き、
`python x/analytics.py` を叩くと、**全投稿の平常値と導線が一気に出ます。**

スクショから起こす `/x-review` と違い、**取りこぼしがありません。**
URLクリック数も入っているので、導線の実測がそのまま取れます。

| | `posts.csv`（`/x-review`） | `analytics.py`（エクスポート） |
|---|---|---|
| 入るもの | レビューを通した投稿だけ | **全投稿** |
| 分かること | 狙いと結果の対応 | **平常値・導線・時刻** |
| 手間 | 1本ずつ | 月1回、ファイルを置くだけ |

**両方要ります。** エクスポートには「何を狙って出したか」が入らないので、
型の検証には `posts.csv` 側が必要です。

## 実測から確定していること

詳細は `docs/winners.md`。要点だけ:

- **型4（対比リスト）が拡散でも導線でも最大。** 1272万imp・2,820クリック。
  ただし**テーマで1700倍**ちがう（「頑張りすぎへのゆるし」＞「転職」）
- **型2は導線率が型3の3〜4倍**（面接の文脈だから）。型7の同等値は誤判定でした
- **型1は当たり外れが最大。** 57本で中央値895、最大522万。在庫は1本まで
- **導線リプは1本だけ。** 2本目以降はCTRが1桁落ちる（3ケースで確認）
- **箇条書きは「作業」で書く。** 姿勢で書くと沈む
- **他人が登場しない投稿は拡散しない**
- **決め台詞の中に "〜" を2つ入れる。** ただし最大の1本は教訓ですらなく、
  上司が関西弁で笑わせているだけだった
- **決め台詞は折りたたみの下に置く。** 上位投稿はすべて接続の行で「…」と切れる

## 気をつけること

- **本文に外部リンクを貼らない。** リーチが30〜50%落ちます。導線は1stリプかプロフ
- **リクルート（前職）だけは出してよい。** 2026-08-13にプロフィールで公開済み。
  制度の話は書けるが、検証されうる固有の数字は不可（`content.md` テーマM）
- **それ以外の会社名・部署名・製品名は出さない。** 業種と規模だけ。学歴と年齢は可
- **後から縛りになる確定事実を増やさない**（部下の人数・売上・表彰歴）
- **他アカウントの言い回しとエピソードは借りない。** 構造とテーマだけ
- **リンク・広告表記・ASPまわりはHideさんの担当**（`docs/funnel.md`）
- **自動投稿・自動リプはしません。** アカウントを失うリスクに見合いません
