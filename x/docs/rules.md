# ルール一覧（2026-08-21 時点）

各ルールの根拠と実例は元のファイルにあります。ここは索引です。

## 1. 絶対に崩さないもの（3つだけ）

- ハッシュタグを使わない（208本中0本）
- 絵文字を使わない（208本中3本。型7の話者記号のみ）
- 本文に外部リンクを入れない（導線は必ず1stリプ）

## 2. 話者のポジション

- 観察者であって主役ではない。**自分を上げる投稿を書かない**（208本に武勇伝ゼロ）
- 自分が登場するときは、常に**失敗している側か教わる側**
- **型2（面接官）だけは判断する側**。ここで困る側に立つと型の権威が消える
- 型7は**登場人物の中に語り手がいない**（心の声も第三者の頭の中）
- 型8・型7で**一人称（こっち／自分）を使わない**。三人称にすると観察者のままでいられる
- **一次情報として書いた箇所を明示して渡す。** 「見たことがない」と言われたら伝聞に切り替える
- **伝聞は手札**。責任が相手側に移り、締めだけHideさんの意見にできる

## 3. 具体性

- **主語を具体化する**（若手社員 → 早稲田卒の25才）。年齢3.3倍・学歴2.1倍・数字1.9倍
- **述語はセリフにする。** 要約された教訓は誰でも書けるが、セリフはその場にいた人しか書けない
- **★例外: 型4には人物を持ち込まない**（0.1倍）。型4では**行動だけ**を具体化する
- **数字は「具体的」の前に「現実的」か。** 30分→15分／3秒→1〜2秒（2回外した）
- **動作は頭の中で再生してから書く。** 視線が「止まる」→「泳ぐ」（物理の間違い）
- **箇条書きは行動で書く。姿勢で書かない**（姿勢だと14倍沈む）
- **箇条書きは3つまで**（型3で4つ以上は0.3倍）
- **分析的な語より状態の語。** 確認は「**その言葉を読者が自分について言うか**」
  （「私は考えていた」とは言わないが「気を遣っていた」とは言う）

## 4. 文体・語尾

- 常体。敬体は使わない（型2の「〜してますが」だけ例外）
- 一人称は「ワイ」（失敗談のとき）。地の文では省略が多い
- **締めの既定は「〜よね。」**（76本・月内相対1.05）。「〜だよな。」12本0.80、**「〜からね。」14本0.40が最弱**
- **「マジで」が2番目の口癖**（27回）。「本当に」「非常に」に置き換えない
- **関西弁は型1の上司キャラ専用**（2回外した）
- **実務の説明に強い語を使わない**（逆算して → も参考に）
- **分析的な語より状態の語**（上がり幅が小さい → 低いまま）
- 疑問形にしない（**議論系だけ例外**）
- **接続語は「型」ではなく「決め台詞と箇条書きの関係」で決める**
  - 決め台詞が3つの総括 → 「などあるが、**総じて言うと、**」
  - 決め台詞が3つとは別の4つ目 → 「これだけでも◯◯が、**とくに◯◯のは、…**」
- **決め台詞は読者が自分について言う言葉で**（考える → **気を遣う**）。**3回外した**

## 5. 削り方（Hideさんの修正から10項目）

1. **説明の行を足さない。** 箇条書きから読者が埋められることは書かない
2. **抽象的な帰結より具体的な原因。** 帰結は読者が想像できる
3. **2文を1文に圧縮する。** 逆接の「が」でまとめる
4. **締めで決め台詞を言い換えない。一段広い主語に上げる**
5. **名詞化して短くする。** 箇条書きを受ける語は「など」
6. **セリフに「！」を付けて温度を出す**
7. **落としっぱなしにせず一言かばう** ── ★例外2つ:
   構造の説明のとき／**議論を狙う回**（かばうと争点が片付く）
8. **副詞を削る／1行目を改行しない**
9. **悪い側は「自分」を主語にした語でそろえる**（自分の身を守る／自分が凹むだけ）
10. **技巧的な対句をやめる。** 言い切りにする
11. **台詞のハードルは読者が今日できる高さに**（作ったか → 考えたか）
12. **締めで誰も下げない。選択肢を渡す。** 批判ではなく提案で閉じる
13. **依頼に書かれた要素を落とさない**

- **B・C・D にAの書式（『』・同意誘導）を持ち込まない**
- **型より先に主張の形を見る。** 「AだからB、BだからC」の連鎖は型7・型8に乗らない

## 7. 型ごとの書式

**型1 上司の一言**（57本・中央値895・最大522万。**当たり外れ最大。在庫1本まで**）
- 失敗を他人のセリフで見せる／物理的な場面を1行／**決め台詞を教訓にしない**
- 決め台詞の中に対比か言い換えを入れる
- **二段にするのは、台詞と台詞の間にこちらの反応が挟まるときだけ**

**型2 面接官**（15本・中央値6,294・**総合導線率1位0.0508%**）
- 1行目は必ず「ベンチャーで面接官してる〜」（15本中15本）
- 「などあるが、実はよく落とすのが、」→『意外な一項目』→ 採用側の損得で締める
- **意外性のために事実を曲げない。** 想像で書いた4本中3本却下。**素材バンクか出典から書く**
- 人格ではなく行動を批評する

**型3 人物観察**（58本・中央値3,676・**枚数の稼ぎ頭**）
- 学歴・年齢を頭に置く。同じ人物を使い回してよい
- 「これだけでも◯◯が、とくに◯◯のは、…」で折りたたませる
- 型3内で年齢5.7倍・学歴4.1倍

**型4 対比リスト**（12本・**平常値1位・最大1272万・全クリックの53%**）
- **6原則**: ラベルは「強い人／弱い人」を動かさない／6項目は1つの主張の6回の言い換え／
  左右は同じ軸の裏表／**通し軸が最も濃い項目を1行目へ**／数字は全角／方言を入れない
- **人物を入れない**（0.1倍）。『』も同意誘導の締めも入れない
- テーマは「頑張りすぎる人へのゆるし」が最大の当たり（転職テーマは1700分の1）

**型5 新人観察**
- **箇条書きの3項目は、決め台詞の実例になっていること**（2回外した）
- 実際に言う場面が浮かぶ言葉にする
- 決め台詞の主語を語り手の視点に合わせる（「出してる」→「教えてくれる」）

**型7 会話だけ**（1,219・返信が最多になる型）
- 地の文なし・『』なし・締めなし・箇条書きなし
- **地の文が無いぶん、前提はセリフに埋め込む**（「来週までの例の件」）
- **心の声は観察ではなく判断で終える**

**型8 短文**
- セリフ → 場面 → かばう → 締め

**型9 助詞切り**（@papazo2245・未検証）
- 場面から入る／生セリフを要約しない／主語は評価する側／対象を絞らない／
  **切る直前の名詞は平凡でよい**／助詞「は、」「とは、」で切る
- **セリフに答えを入れない。** セリフは事実、答えは原理
- **答えはセリフの事実の原因になっていること**（先に答えを決めてから事実を探す）
- **落とした場面より通した場面。** 一見マイナスの事実で通すと謎が立つ
- **自己リプにはいつもの同意誘導が要る**（締めが無いのは本文だけ）
- **その回はアフィリンクを貼れない**

**断言-リスト**
- 1行目に引きを作らず結論を言い切る／学歴・年齢を1行目に／
  **箇条書きの重複は言葉ではなく行動で見る**／締めに読者の得＋自覚できる語で名指し

**使わない型**: 他人が登場しない断言（実測最下位4万）

## 8. 議論系（2026-08-18 追加）

- **「？？」ではなく「〜なのか、どうだろう…？」。** 争点と質問を1文にまとめる
- **★締めの直前に争点を1行で並べる。** これが無いとリプが散る
- **同意を求める疑問（〜よね？）にしない。** 判定を委譲する形にする
- **一言かばわない。** 代わりに「だって」「らしい」で距離を取る
- テーマの条件: **読者が瞬時に自分の所属を確定できる／片側が不名誉（人格ではなく行動）／
  答えるコストがゼロ**
- **性別・国籍・政治は避ける。** 燃えずに黙られる
- `--format` は `議論系`（型ではなく狙いで括る）

## 9. 導線（1stリプ）

- **本文が伸びてから貼る**（目安1〜2時間）。同時に貼らない
- **導線リプは1本だけ**（3ケースで確認）
- 本文の主役も読者も否定しない。**損しているのは構造のせい**という置き方
- 本文と同じ独白の語尾で引き継ぐ。宣伝文にしない
- **型4にも貼る**（「貼らない」は撤回。全クリックの53%）
- リプ到達率は元ポストの**約6%**（53ペアの実測）
- **詳細クリック率は0.62%で書き方では動かない**
- 訴求は**性格分析0.116% > 年収診断0.075% > その他0.020%**（間口の広さ順）
- **元ポストを書く前に商材を決める。** バズってからPRを考えると0.04%側に落ちる

## 10. 素材

- 優先順位: 過去投稿の焼き直し → スワイプ → 時事 → 実体験 → **自分の投稿へのリプ → 他SNS**
- スワイプで借りていいのは**構造とテーマ**。言い回しとエピソードは借りない
- 時事は**入口だけ**。1行目で触れて2行目からいつもの型に戻る
- 賞味期限のある素材は在庫に寝かせられない
- **主張が重なることは問題にしない。** 型と表現を変えて出し直すのが正しい
- **ネタ帳は `claims.md`（C001〜C095）。** `/x-draft` の既定ソース。番号で指定される。
- **同じ骨格に乗るネタは束ねて1本にする**（求人票の建前4件 → 型2リスト1本）
  出どころも投稿済みかも区別しない（同じネタを型と表現を変えて何度も出す前提）
- `claims.md` `debates.md` は**参考リストであって縛りではない**

## 11. 運用

- **日付も投稿枠も割り当てない。** Hideさんが好きな順で使う
- **「記録が無い＝投稿していない」と扱わない**（予約投稿が見えないため）
- **在庫に書くのは承認されたものだけ**（2026-08-21 変更）。下書きはチャットに出す。
  却下は下書きを残さず**理由だけ**ドキュメントへ（「要レビュー」は廃止）
- **型11（箇条書きリスト）のテーマは `x/lists.md` から取る**（2026-08-31）。
  **反転の要素とセットで貯める。** 反転が無いテーマは書かない。1回の依頼で1本まで
- **下書きの1行目に「どのテーマか」を書く**（2026-08-28）。番号＋主張の文。
  ネタ帳に無ければ `新規` と書いて `claims.md` に登録し、その場で番号を採る
- **「箇条書き＋総括」は依頼1回につき1本まで／在庫の1/3まで**（2026-08-21）。
  型2・3・5は読者から見ると同じ形。**飽きは証明できないので前提として扱う**。
  `python x/stock_looks.py` で数える
- **テーマ指定の依頼には3案出す。骨格を変える**（言い回しの差では意味がない）
- **3案は1本に絞らなくてよい。** ただし在庫に残るのは承認されたものだけ
- 投稿するなら**朝6時台**（208本中177本）
- 引用RTの狙いは**引用元にリポストしてもらうこと**。impで評価しない

## 12. 安全・制約

- **会社名・部署名・製品名・個人名を出さない**（リクルートのみ2026-08-13に解禁）
- **検証されうる固有の数字を出さない**（売上・人数・自分の評価ランク）
- **うちでは新卒採用していない**（Hideさん・確定事実）
- 自動投稿・自動リプはしない
- Xのスクレイピングやブラウザ自動化はしない（永久凍結リスク）
- APIキーをチャットに貼らない
- アフィリンクと広告表記はHideさんが付ける

## 13. 私が繰り返した失敗（チェック項目）

- **器を先に作って中身を流し込む**（型を決めてから主張を埋める／逆張りの形を先に作る／
  箇条書きを先に思いついて決め台詞を後からかぶせる）→ **言いたいことを先に固める**
- **1件の指摘を一般則に変換する** → **明示的にルール化を頼まれたものだけ規定に入れる**
- **規定に書いてあるのに下書きで守れない**（語尾「なんだよな」／学歴の入れ忘れ）
  → **書いたあとに規定と照合する**
- **左右の軸ズレ**（型4で2回）→ 「◯◯ vs ◯◯」に抜き出して反対語か見る
- **接続と中身のズレ**（「とくに◯◯のは」と書いて中身が総括）
  → 決め台詞が総括か、新しい1つかを見る
- **関西弁の混入**（2回）→ 型1以外に混ざっていないか見る
- **数字を盛る**（2回）→ 実際に測ったらその値になるか
