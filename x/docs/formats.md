# 型ライブラリ

体験談・暴露系の投稿構造。`/x-draft` はここから型を選んで素材を流し込みます。
`/x-scout` が競合の勝ち投稿を分析して、ここに型を追加していきます。

実績が溜まったら `x_review.py` の「型ごと」の表を見て、**プロフクリック率の低い型は
捨ててください**。インプレッションではなくプロフクリック率で判断します。理由は
`winners.md` の冒頭に書いてあります。

---

## 全型に共通する制約

**本文に外部リンクを貼らない。** 2026年時点で、本文にリンクがあるとリーチが30〜50%
落ちるという報告が複数あります。リンクは1stリプライかプロフィールに置きます。

**末尾に問いかけを1行置く。** リプライはいいねより遥かに重い評価シグナルで、しかも
本人が返信した会話はさらに重く扱われます。問いかけ1行の有無でエンゲージスコアが
変わるので、**全型で必須**にしています。

**リプライには本人が返す。** ここを省略すると問いかけを置く意味が半減します。
自動化しないのはこの理由です（Xの規約上もAIリプライは事前承認が要ります）。

**冒頭1行で全部決まる。** タイムラインで見えるのは最初の1〜2行だけです。
1行目に「一言」か「異常な事実」を置けない素材は、まだ素材になっていません。

---

## 型1: 一言直撃

**構造**

```
1行目: 言われた一言を、状況の説明抜きでいきなり置く
2〜4行目: いつ・どこで・誰にの最小限の状況
5〜7行目: そのとき自分が何を考えたか
締め:   その一言が示していた構造（1〜2行）
問い:   「これ言われたことある人います？」
```

**効く理由**: 説明から入らないので1行目で止まる。読者が自分の記憶を検索し始める。

**注意**: 状況説明を1行目に置いた瞬間に死にます。「前職で上司から言われた話なんですが」
で始めない。

---

## 型2: 数字の暴露

**構造**

```
1行目: 異常な数字を単体で置く（残業時間・離職率・年収差・面接社数）
2〜4行目: その数字がどう出てきたか
5〜7行目: 当時それを異常だと思っていなかったこと
締め:   外に出て初めて分かったこと
問い:   「みなさんの業界だとどれくらいですか？」
```

**効く理由**: 数字は引用RTで比較されやすく、他人が自分の数字を持って参加してくる。

**注意**: 盛らない。検証されます。**素材帳にある数字をそのまま使う**こと。

---

## 型3: 分岐点

**構造**

```
1行目: 「〜した日に辞めると決めた」形式の断言
2〜5行目: その日に起きたことを時系列で。淡々と
6〜8行目: 決めた瞬間の描写
締め:   いま振り返ってどう思うか（1行、短く）
問い:   「決め手になった瞬間ってありました？」
```

**効く理由**: 転職検討層が最も自己投影する型。プロフクリック率が高く出やすい。

**注意**: 締めを長く書かない。教訓を語り始めると急に説教くさくなって離脱します。

---

## 型4: 反転

**構造**

```
1行目: 一般的に良いとされることを肯定する形で置く
2〜3行目: 自分もそう思っていた
4〜7行目: 実際に起きたこと（一般論が通用しなかった事実）
締め:   だから今はこう考えている
問い:   「これ逆の経験した人います？」
```

**効く理由**: 前半で同意させてから裏切るので、最後まで読ませやすい。

**注意**: 「みんな間違ってる」の形にしない。読者を否定した瞬間にリプ欄が荒れます。
否定するのは過去の自分だけにする。

---

## 型5: 静かな観察

**構造**

```
1行目: 辞めていく人に共通していた、細かい兆候を1つ
2〜5行目: 具体的にどう見えたか
6〜7行目: それに気づいたときには遅かったこと
締め:   なし（言い切って終わる）
問い:   「他にもこういう兆候ありますか？」
```

**効く理由**: 感情を煽らないぶん保存されやすく、フォロワーの質が上がる。

**注意**: 伸びは他の型より小さく出ます。**インプレッションで評価しないでください。**
プロフクリック率とフォロー増で見ます。

---

## 1stリプライ（導線）

本文が伸びてから、リプライに導線を置きます。**投稿と同時に貼らないでください** —
伸びていない投稿にリンクをぶら下げても意味がなく、リプ欄の1本目が広告だと
会話が始まりません。

- 本文投稿 → 反応が付き始めてから（目安1〜2時間）1stリプを追加
- 1stリプの中身は宣伝文にしない。**本文の続き**にして、その末尾に置く
- ASPによってはX直リンクが規約違反です。note か LP を1枚挟む形にしてください
