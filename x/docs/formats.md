# 型ライブラリ

**すべて @nekosukexx の実測から作っています。** 一般論のテンプレではありません。

数字は2種類あり、**混ぜて比べないでください**（`winners.md` の2026-08-15の節）。

| 出どころ | 中身 | レンジ |
|---|---|---|
| 過去11本（ハイライト） | アカウントの**最高記録**。上澄み | 17万〜522万 |
| **公式エクスポート208本** | **全投稿（2025/05〜12）** | 27〜1272万（中央値2,110） |

**型の良し悪しは中央値で比べます。** 最高記録どうしの比較は
運の大きさを比べているだけになります。**全11本はエクスポートと照合済みです。**

### ⚠ ただし、型はインプレッションをほとんど説明しません

月をそろえて測り直すと、**型1・型2・型3は横並び**（相対中央値 1.07 / 1.02 / 1.35）。
型による差は2倍程度で、**月による差は300倍**でした（`winners.md`）。

**このライブラリは「書き方の引き出し」であって、当てる装置ではありません。**

**効く要素は型ごとに違います。** 全型に共通のチェックリストは作れません
（「他人が登場」ですら型4では0.1倍）。診断は `python x/x_diag.py` が
型ごとに行います。

`/x-draft` はここから型を選びます。`/x-scout` が競合を分析して型を追加します。

## 骨格グループ —— 飽きを防ぐための分類

**型が5つあっても、骨格は実質1つでした。** 型1・2・3・5 はどれも
「前振り → 箇条書きか状況 → 『などあるが』 → 『決め台詞』 → 同意誘導」で同じです。

月2本のときは反復が見えませんでしたが、**1日2本＝月60本では並んで見えます。**
そこで骨格でグループ分けし、日をまたいで散らします。

| グループ | 型 | 骨格 | 見た目 |
|---|---|---|---|
| **A** | 型1・型2・型3・型5 | 前振り→『決め台詞』→同意誘導 | 10〜14行。実績はここに集中 |
| **B** | 型4 | 見出し＋2列リスト | リスト。『』も締めも無い |
| **C** | 型7 | セリフの応酬だけ | 5〜8行。地の文が無い |
| **D** | 型8 | 短文 | 5〜7行。箇条書きも『』も無い |
| **E** | 型9 助詞切り | 場面→セリフ→助詞で切る | 改行なしの一塊。**締めが無い** |

**グループEは2026-08-18に追加した実験枠です**（@papazo2245 の分析から）。
**うちでは未検証。在庫は1本まで、月1〜2本まで。**
他の型と違って**本文に締めが無く、答えを自己リプに置く**ので、
**その回はアフィリンクを貼れません。**
**ただし自己リプにはいつもの同意誘導（〜からね。〜よね。）が要ります**
（2026-08-18の訂正。締めが無いのは本文だけです）。

**在庫（`stock.md`）の中で A と 非A を半々に保つ。** 投稿の順番はHideさんが
決めるので「今日はA、明日は非A」という組み方はできません。在庫が半々なら、
どこから取っても非Aが混ざります。Aが実測最強なので、Aを捨てるのではなく
**必ず非Aを混ぜる**形にしています。

## グループAの書式（型1・2・3・5）

**『』で囲んだ決め台詞を、独立した1行に置く。** 前後に空行。
投稿の重心はここで、読者が引用RTするのもここです。

**締めは「同意誘導」であって「問いかけ」ではない。**

- 「〜よね。」「〜なんだよな。」「〜からね。」で終える
- 疑問形にしない。**この人の型では同意誘導のほうが返信が付いています**
  （521万の投稿で215返信、426万の投稿で77返信）

**箇条書きは「・」で3〜4項目。** 体験談型では使わない。観察型でのみ使う。

**B・C・D には当てはまりません。** 型4には『』も同意誘導の締めも無く、
それで いいね7.6万 を取っています。**以前このファイルに「過去11本すべてに例外なく」と
書いていましたが、事実誤認でした。** 型4が最初から例外です。

## 型1: 上司の一言 —— **当たり外れが最大の型**

**実測57本。中央値895、最大522万。**

| | 型1 | 型3 |
|---|---|---|
| 本数 | 57 | 58 |
| 中央値 | **895** | 3,676 |
| 最大 | **522万** | 333万 |

**同じ本数で、中央値は4分の1なのに天井は上。** 57本のうち10万を超えたのは
3本だけで、残りは数百〜数千で終わっています。**宝くじ型です。**

「★最強」と書いていたのは誤りでしたが、その後「最弱」と書いたのも誤りでした。
**外れが多いので在庫に1本まで**、というルールで扱ってください。

### 522万と1,009本を分けたもの（同じ「自分の失敗＋上司の一言」で5,000倍差）

```
新卒１年目、ワイの失態により顧客が「上司も連れて謝りにこい！」とブチギレ。
客先への道中で緊張MAXの中、上司は「今後は気をつけろ」と怒るのではなく、

「いい歳したオッサンが本気で怒る様子なんて滅多に見れへんで。楽しみやな。」

と言って和ませてくれたのを、今でも感謝してる。
```

**1. 失敗を他人のセリフで見せる。**「怒られた」ではなく顧客の言葉をそのまま引く
**2. 物理的な場面を1行入れる。**「客先への道中」「緊張MAX」
**3. 決め台詞を教訓にしない。** この上司はジョークを言っているだけで何も
教えていません。**教えると説教になり、笑わせると引用されます**

関西弁が入るのもこの上司の特徴です（12月の5,972本も「聞きたいねん」）。

### 「質問から始まる形は出すな」は撤回

その形の**169,468は57本中3位**でした。禁止する根拠がありません。

```
新卒２年目で「どうすれば早く昇進できますか？」と聞いたら早稲田卒に、
「"お前を使うと楽になる"と俺に思わせてくれ」
と笑って言われたのを覚えてる。
```

### 決め台詞は、中に対比か言い換えを入れる

```
「"お前を使うと楽になる"と俺に思わせてくれ」        16.9万
「"質問の数"と"成長の速さ"は比例するぞ」            7.0万
「"自分がいないと回らない状態" のうちは半人前だな」    3.4万
「"上司に怒られたくない"で動くな。"顧客に喜ばれたい"で動け」 1.1万
```

**単なる格言にしないでください。** 対比も言い換えも無い決め台詞は数千止まりです。

**構造**（522万の実測から）

```
1行目: 新卒[N]年目 + 自分の失敗を、**他人のセリフ**で見せる
2行目: 物理的な場面（移動中、呼び出された、緊張MAX）
3行目: 上司は「[凡庸な予想]」と◯◯するのではなく、

『[予想外の一言。教訓ではなく、笑わせる]』

と言って[くれた/言われた]。
締め:   今でも感謝してる。／今なら分かる。
```

**効く理由**: 1〜3行目で読者に予測を作らせ、決め台詞で裏切る。
予測のつくり方は**自分の失敗でなくてよい**（質問・場面・他人の失敗でも成立）。

**この型で失敗する形**

**教訓を語るだけ**にすると落ちます（733でその月の最下位）。
「昔◯◯と言われた。大事だと思う」は、予測も裏切りも無いので何も起きません。

**誰かの具体的な場面から始まっていない投稿は、この型ではありません。**

## 型2: 面接官の暴露 ★転職導線に最適

**実測15本。中央値6,294、最大155万。総合導線率が全型で1位（0.0508%）。**

**拡散は3位でも、クリックは型3の4倍**生みます。読者が面接の文脈にいる状態で
リプに降りてくるからです。**導線を伸ばしたいならこの型を増やしてください。**

**1行目は必ず「ベンチャーで面接官してる[が/けど/ますが/のだが]、」**（15本中15本）。

### 実測で一番強かった型2は、決め台詞が無い「リスト形式」でした

```
ベンチャーで面接官してるけど、これ履歴書に書いてると正直キツイ…

・MOS
・簿記3級
・教員免許
・秘書検定3級
・TOEIC 650点
・中小企業診断士
・ビジネス実務マナー検定
```

**194,747インプレッション・返信32（9月の最多）。** 『』も締めもありません。
**具体名を並べるだけ**で、読者が自分の履歴書を見に行きます。

返信が伸びる＝荒れやすい形でもあります。**人格ではなく「並び」を批評する**
形にしてください（関連実測: 「TOEIC850＋簿記3級」と「MOS＋秘書検定3級＋簿記3級」
では人事の読み方が違う、という8/12の投稿）。

**構造**

```
1行目: 「ベンチャーで面接官してますが、」＋ 判断の話だと宣言する
2〜5行目: ・箇条書きで「よくあるNG理由」を3つ（読者が予想できるもの）
6行目:  などあるが、実はよく落とすのが、

『[意外な一項目]』

と言う人。
締め:   なぜそれがNGなのかを、採用側の損得で1〜2行
```

**効く理由**: 「元リクルート／現面接官」という立場でしか言えない内部情報。
読者が自分の面接を思い返すので、**プロフィールに来る動機が最も強い型**です。

**転職アフィリの導線としては、この型が本命です。**
15本ぶんの実測で**総合導線率1位（0.0508%）**が裏づけになりました。

**注意**: 断定的に人を否定すると荒れます。落とす理由は「採用側のコスト」として
説明する（実例では「無駄なマネジメントコストがかかる」）。人格の話にしない。

**もう1つの注意 —— 意外性のために事実を曲げないこと。**
「ベンチャーでビジョン共感を落とす」という案を出して却下されました。
ベンチャーはむしろミッションフィットを重視するので、業界の人が読むと明確に
間違いです。**Hideさんは実際の面接官なので、事実誤認は意外性の価値を上回って
信用を削ります。** 「意外で、かつ本当」を両方満たすものだけを使ってください。

### 素材バンク（出典つき）

**型2はリサーチしてから書くほうが確実です。** 打率の実績:

| 書き方 | 結果 |
|---|---|
| 想像で書く | **4本中3本却下**（事実誤認 / ポジション崩し / 論理が繋がらない） |
| 出典を取ってから書く | 1本中1本通過 |

想像でも通ることはあります（「裁量のある環境で働きたい」は出典なしで通過）。
ただし**外したときの損害が大きい**——Hideさんは実際の面接官なので、
事実誤認は意外性の価値を上回って信用を削ります。**迷ったら調べてください。**

**最終判定はHideさんです。** 業界の現実に照らせるのは本人だけなので、
出典があっても違和感を言われたら差し替えます。

**NG例3つに使えるもの**（読者が予想できる、一般的な見送り理由）

・スキルが足りない ・経験が合っていない ・転職回数が多い
・在職期間が短い ・コミュニケーション能力

**「意外な1つ」に使えるもの**（一見好印象だが採用側は警戒する。
出典: [doda人事ジャーナル](https://www.dodadsj.com/content/230915_answers_that_require_attention/)）

| 候補者の答え | 採用側の懸念 |
|---|---|
| 『努力して、一人で乗り越えてきました』 | 協調性・チームプレイの意欲が不明。職場適応に不安 |
| 『困難と感じたことはありません』 | 自己分析不足。問題対処能力が測れない |
| 『誰にも負けない熱意があります』 | 具体性が無く、実務スキルの説明になっていない |
| 『この場の誰よりリーダーシップがあります』 | 自己中心的に見え、入社後チーム内で反感を招く |
| 『成長させてもらえると思ったからです』 | 受け身。主体性への不安 |
| 『経営理念に共感したからです』 | 汎用的で具体性が無く、企業研究不足に見える |
| 『どのような研修制度がありますか』（逆質問） | HPで分かる情報。受け身で早期離職リスク |

**注意**: 「経営理念に共感」は**共感すること自体が悪いのではありません。**
懸念されるのは「具体性が無い共感」です。ここを取り違えて
「ベンチャーでビジョン共感を落とす」と書き、却下されました。
**出典の懸念点をそのまま使ってください。言い換えると意味が変わります。**

## 型3: 人物観察（学歴・年齢つき）★平常値の稼ぎ頭

**実測58本。中央値3,676、最大333万。全型で最多の本数。**

**拡散の土台です。** 全体の中央値2,110を上回り、外れが少ない。
ただし**総合導線率は0.0123%で全型の最下位** —— 枚数はここで稼ぎ、
クリックは型2・型7で取る、という役割分担になります。

**年齢・職種・学歴を必ず頭に置きます。** 青学卒の営業（28才）は9月だけで
4回登場していて、**同じ人物を使い回して構いません。**

**構造**（9月の実測4本から。**接続の言い回しが毎回違います**）

```
1行目: [学歴]卒の[修飾]営業（28才）、[何]が[評価]で、
2〜4行目: ・箇条書きで具体的な作業を3つ
5行目:  これだけでも[偉いが/優秀だが/助かるが/安心感あるが/信頼されるが]、
        とくに[良かった/印象的だった/驚いた/光っていた]のは、…
          ↑ ここで本文が折りたたまれる

『[核心の一行]』

という点。
締め:   一般化して「〜よね」「〜からね」
```

**「これだけでも◯◯が、とくに◯◯のは、」が9月の勝ちパターンです。**
`voice.md` の「などあるが、とくに良いのは、」より、こちらのほうが実測が上。
**◯◯の中身は毎回変えてください**（同じだと連投で見飽きます）。

**決め台詞は折りたたみの下に置く。** 上位投稿はすべて接続の行で「…」と切れて
いて、読者に「もっと見る」を踏ませています（＝詳細クリックが稼げる）。

**効く理由**: 学歴と年齢が引きの装置として働いている。**この2つを外さないこと。**
「優秀な後輩が」では引きが消えます。

**333万と23万を分けたもの**: 333万の投稿（議事録）は、箇条書き3つが全部
「読者が真似できる具体的な作業」でした。23万の投稿（炎上対応）は箇条書きが
「深夜でも最速対応」など**姿勢**の話で、真似できません。

**箇条書きは行動で書く。姿勢で書かない。**

### ⚠ 箇条書きは3つまで（2026-08-16の実測）

型3の58本を月内相対値で測ると、**箇条書きが4つ以上ある投稿は0.3倍**でした。

| | 本数 | 相対中央値 |
|---|---|---|
| 箇条書き3つ以下 | 34 | **2.02** |
| 箇条書き4つ以上 | 24 | **0.68** |

**多く挙げるほど良い、ではありません。** 3つに絞ってください。
4つ目以降は読者の集中を切るだけのようです。

### 型3の中で効く要素（型を統制しても効きます）

| 要素 | 型3内での差 |
|---|---|
| **年齢**（28才など） | **5.7倍** |
| **学歴**（青学卒など） | **4.1倍** |
| 他人が登場 | 2.2倍 |

**これは「型3であること」の言い換えではありません。** 年齢ありの25本のうち
型3は11本だけで、残りは型1・型2・断言に散っています。型3の中だけで測っても
5.7倍・4.1倍なので、**同じ人物観察をするなら入れたほうが効きます。**

### Hideさんの修正から（2026-08-13・2122imp）

下書きを6箇所直されました。**型3を書くときはここを最初に見てください。**

| 出した案 | 直された形 | 学び |
|---|---|---|
| クロージングが妙にうまくて | **売れてるには理由があって** | 手段ではなく**結果**から入る。「妙にうまい」は評価者目線で上から |
| 提案の前に決裁者と決裁時期を確認 | **決裁時期を必ず確認** | **箇条書きは1項目1要素。** 2つ詰めない |
| 次のアポを通話が切れる前に取る | **商談中に次の日程を抑える** | 同上。短く |
| 保留されたら | **「検討する」と言われたら** | **抽象語を、相手が実際に言う言葉に置き換える** |
| などあるが | **など基本だが** | 箇条書きを「当たり前」と明示すると、次の決め台詞が立つ |
| 26才 | **29才** | その練度に達する年齢のリアリティ |

**締めの直しが一番大きい。**

- 出した案: 「断られたあとに動ける人が、結局いちばん数字を持ってくるんだよな。」

**語り手が一般化して閉じるのではなく、本人にもう一度喋らせている。**
決め台詞が2つある構造で、しかも最後は「強い。」の2文字。
詳細は `voice.md` の「締めの型」。

## 型4: 対比リスト ★平常値で1位

**テーマで1700倍ちがいます。**

| | テーマ | imp |
|---|---|---|

**「頑張りすぎる人へのゆるし」がこの人の最大の当たりテーマです。**

### 型4の3原則（2026-08-16・Hideさんの修正から）

私が書いた型4をHideさんが全項目書き直しました。差分から3つ出ています。

**1. ラベルは「強い人／弱い人」を動かさない。**

すべて**頑張りすぎなくていい**の言い換えです。

**3. 左右は同じ軸の裏表にする。**

**対比が成立していません**。Hideさんは「正しく原因を把握／自分が凹むだけ」に直し、
**原因に向かうか自分に向かうか**という軸を立てました。

**4. 通し軸が最も濃い項目を、1行目に置く（2026-08-18 追加）。**

Hide ・頼るのが早い　　　　　 ← 1行目に移動
```

**「頼るのが早い／限界まで一人で持つ」はこのアカウントの持論
（ベクトルが自分に向いている人は伸びない）に直結する項目**です。
1行目が一番読まれるので、**6つの言い換えのうち最も濃いものを先頭に置きます。**

**5. 数字は全角にする。**

「7割」→「**７割**」。半角数字は幅が半分なので、左列の整列が崩れます。
**全角に統一すれば揃います**（Hideさんの版は全項目が左列12文字幅ぴったり）。

**6. 方言を持ち込まない。**

### ⚠ 「左右は同じ軸の裏表」を2回続けて外しました

3原則その3として自分で書いた直後に、同じミスをしています。

```
✕ ・「わからん」と言う　　・調べてるフリをする   ← 表明 vs 行動。軸が違う
○ ・「わからない」と言う　・知ってるフリ         ← わからない vs 知ってる
```

**確認のしかた**: 左右の語を「◯◯ vs ◯◯」の形に抜き出して、
**同じ言葉の反対語になっているか**を見る。
「わからない vs 調べてる」は反対語ではありません。

**項目は全部「行動」で書く。** 私の版には時間（1時間で仕切り直す）、道具
（紙に書く）、ルール（同じ指摘は2回まで）が混ざっていました。粒度が揃わないと
読者は自分に当てはめられません。**「寝たら忘れる」のように気質で書くのは可**で、
これは行動と同じく観測できます。

**温度のある語を1つ入れる。** Hideさんは「神の速さで報告」「思考がフリーズ」を
入れました。全項目が整った説明文だと、正しいけれど読み飛ばされます。

**骨格が唯一違う（グループB）ので飽き対策になります。**
**主張が重なることは気にしません**（2026-08-18・Hideさんの指示）。
ただし**対比リストが続くと見た目が同じ**なので、
**型としての間隔**だけは意識してください（主張ではなく見た目の話です）。

**実例（7,433）の構成** —— 転職というテーマで、9項目・2列。

```
【転職がうまくいく人】
←うまくいく　　　　　うまくいかない→
・企業を選ぶ　　　　・選ばれるのに必死
・転職軸が明確　　　・大手ならどこでも...

**右側（うまくいかない側）に具体的なセリフを混ぜている**のが効いています。

## 型6候補: 二段の引き（@sayu5632j から。**部分的にだけ借りる**）

## 型9候補: 助詞切り（@papazo2245 から。**未検証・実験枠**）

### ★書き方（依頼が来たらこれを埋める）

```
[場面]で、[人]が[具体的な行動や発言をした]、というシーンがあります。

（または）[対象を具体的なラベルで名指し]を[観察すると]、[謎]にぶつかります。

「[その場の人の生セリフ。20〜40字。要約しない]」

[転換]、[上／評価する側]が[動詞している]『[平凡で具体的な名詞]』とは、
```

**自己リプ（答え）**

```
「[答えを一文で]」です。[なぜそうなるかの説明を1〜2文]。
[明日できる1つの動作]から始めるべきです。
```

**埋めるときのルール6つ。**

| # | ルール | 外すとどうなるか |
|---|---|---|
| 1 | **場面から入る**（いつ・どこで・誰が） | 分類から入ると0.94倍（うちの実測） |
| 2 | **生セリフを1つ入れる。要約しない** | 「〜と思っています」は弱い |
| 3 | **主語は「上」「役員」「人事」＝評価する側** | 当事者目線だと暴露にならない |
| 4 | **対象を絞らない**（40代の主任だけ、にしない） | 母数が上限になる |
| 5 | **切る直前は平凡で具体的な名詞でよい。凝らない** | 造語にすると読めなくなる |
| 6 | **助詞「は、」「とは、」で切る。体言止めにしない** | 文が閉じると引きが消える |

### ★★ セリフに答えを入れないこと（2026-08-18・最重要）

**初回の下書きをここで却下されました。**

```
✕ 候補者が「部下の資料はほぼ自分で直してます。そのほうが早いので」と言ったので、
　 その場で見送りが決まった
```

**Hideさんの指摘は2つ。**

**1. そんなことを面接で胸を張って言う人はいない**（現実性。過去に3本つぶしている
のと同じミスです）

**2. 読んだ時点で何が悪いか分かるので、続きを読む理由が消える**

**これが型9の急所です。** 切っても、答えが先に見えていたら引きになりません。

| | セリフの役割 | 切った先の役割 |
|---|---|---|
| **正** | **観察された事実**（何が起きたか） | **原理**（それが何を意味するか） |
| 誤 | 原理をそのまま言う | 言い換えるだけ |

papazoのセリフを見ると、この分担が守られています。

```
セリフ 「彼の報告や提案は、事実と主観が明確に分かれていて判断しやすい」  ← 事実
答え   「主観ではなく、客観で組織を動かせるか」                    ← 原理
```

**判定のしかた**: セリフだけを読んで**「で、何が言いたいの？」が残るか**。
「あー、そういうことね」で終わるなら、答えが漏れています。

### ★ 落とした場面より、通した場面

**見送りの理由をセリフにすると「なぜダメか」が自明になります。**
通した理由のセリフは「**なぜそれが良いの？**」が残ります。

**さらに強いのは、一見マイナスに聞こえる事実で通す形**です。

```
「この2年、自分で作った資料が1枚もないんです」  ← 減点に聞こえる
　→ でも、その場で通した                    ← 反転して謎が立つ
```

### ★ 切る直前の名詞は、勝負どころではありません（2026-08-18 訂正）

**ここを2回作り直して、2回とも却下されました。**

| 版 | 置いた名詞 | Hideさんの反応 |
|---|---|---|
| 1 | 『指示の最後の一行』 | — |
| 2 | 『任せ方の一行』 | **「それって何？」**（造語で読めない） |
| 3 | 『渡す前のひと言』 | **「誰に何を渡す話か分からない」** |
| **正** | **『部下への任せ方』** | **平凡で具体的でよい** |

**結論: ここは凝らないでください。**

> **そのフレーズはそんなに大事ではないので、
> 「部下への任せ方」ぐらい具体的かつ平凡で良い。**（Hideさん・2026-08-18）

**引きを作っているのは場面とセリフです。** 名詞ではありません。
「決定的な理由」のような**無内容な語だけ避ければ十分**で、
それ以上は**何の話かが一読で分かる平凡な名詞**にします。

```
✕ 決定的な理由 / 重要なポイント          ← 無内容
✕ 任せ方の一行 / 渡す前のひと言          ← 造語・指示対象が不明
○ 部下への任せ方 / 通す人の口ぐせ / 評価のモノサシ
```

### ★★ 答えは、セリフの事実を説明していること（2026-08-18・最重要）

**「セリフは事実、答えは原理」だけでは足りませんでした。**
**答えは、そのセリフで述べた事実の"原因"になっていなければなりません。**

却下された組み合わせ:

```
セリフ 「この2年、自分で作った資料が1枚もないんです」
答え   「どこまで決めていいかを、渡す前に言ってるか」
```

**繋がっていません。** 資料を作っていないのは「任せている」という事実で、
**「どう渡しているか」を何も説明していない**からです。

papazoは噛み合っています。

```
セリフ 「彼の報告や提案は、事実と主観が明確に分かれていて判断しやすい」
答え   「主観ではなく、客観で組織を動かせるか」
　　　  ↑ セリフの事実が、この原理がそのまま現れた一例になっている
```

**直した版:**

```
セリフ 「部下から"これでいいですか"って聞かれること、ほとんどないんです」
答え   「どこまで決めていいかを、渡す前に言ってるか」
　　　  ↑ 先に範囲を渡しているから、途中で確認が要らない。原因になっている
```

**手順**: 先に**答え（原理）を決めて**から、
**その原理が働いている職場で観測できる事実**を1つ探し、それをセリフにします。
**セリフを先に思いつくと、今回のようにズレます。**

**自己リプに"回収の一文"を必ず入れる。**
「**だから途中で確認が要らない**」のように、
**答え → セリフの事実、を明示的に繋ぐ1文**です。
これが無いと、読者はセリフを何のために読んだのか分かりません。

### ★ 自己リプの締めは、うちの同意誘導に戻す（2026-08-18 訂正）

**ここに「明日できる1つの動作で終える」と書いていました。うちには合いません。**

Hideさんが最終版で**行動指示を丸ごと削っています。**

```
✕ 次に何か頼むときは、指示の最後に「決めていい範囲」の一行を足してみるといい。
○ 出てきたものを後から自分好みに直す人は、部下が育たないし信頼も得られないからね。
```

**papazoは丁寧語の啓蒙アカウントなので「〜すべきです」が成立します。**
**うちは独白なので、行動指示は説教になります**（`voice.md` の話者のポジション）。

**「型9は締めが無い」と書いたのも不正確でした。**
締めが無いのは**本文**です。**自己リプにはいつもの同意誘導（〜からね。〜よね。）が要ります。**

**移植のとき、語尾だけ入れ替えるのでは足りません。読者への態度まで戻すこと。**

### ★ 回収の一文は要りません（2026-08-18 訂正）

**「答え → セリフの事実 を明示的に繋ぐ1文を必ず入れる」と書きました。誤りです。**
Hideさんが最終版で削っています。

```
✕ …「ここは決めていい、ここだけ相談して」を先に伝えていた。だから途中で確認が要らない。
○ …「ここは決めていい、ここだけ相談して」を先に伝えていた。
```

**「聞かれない」と「先に伝えていた」は、すでに因果で繋がっています。**
繋がっていれば読者が自分で繋ぐので、書くと説明過多になります
（`voice.md` の削り方1「読者が自分で埋められることは書かない」）。

**必要なのは"因果を作ること"であって、"因果を説明すること"ではありません。**
上の「答えはセリフの事実を説明していること」は**設計時のチェック項目**であって、
**本文に書く指示ではない**、と読み替えてください。

### 型の骨格（2本に共通する部分）

```
【1】導入 —— 上の視点が見える場所を提示する
【2】中身 —— 上が何を見ているかを書く
【3】転換 —— 「ですが、」「どれだけ〜していても、」
【4】★助詞のまま切る★ —— 「〜とは、」「〜理由は、」
────────────────────────────
【自己リプ】答え → 一般化 → 明日できる1つの行動
```

**書式も2本で共通しています。**

- **改行なし・空行なし。** 画面を一塊で埋める（うちは1〜2文ごとに改行）
- **1文が長い。** 本文は2〜3文だけ（うちの1行中央値は18字）
- **主語は必ず「上」。** 「上に引き上げても」「上が最後に見ている」
  「上が引き上げを諦める」。**評価する側を主語にした暴露**です
- **切るのは必ず【名詞 ＋ は、／とは、】。** 体言止めにすらしない

**構文が閉じていないので、脳が補完を求めます。**
答えを見るには**詳細クリックかリプ欄を開くしかありません。**

### ★2本の差 —— 何が6倍を分けたか

| | **A（9.9万）** | **B（1.6万）** |
|---|---|---|
| 導入 | **評価会議で役員が話す場面** | 40代で主任のままの人という分類 |
| 中身 | **役員の生セリフを長く引用** | 「〜と思っています」と地の文で要約 |
| 対象 | **出世したい人ぜんぶ** | 40代で主任の人だけ |
| 切る直前の名詞 | **『評価のモノサシ』** | 「決定的な理由」 |
| 立ち位置 | 昇格が決まる若手（なりたい側） | 上がれない40代（なりたくない側） |
| 自己リプの締め | **形容詞を1つ消して数字を1つ入れる** | 新しい課題への挑戦と若手の後押し |

**差は4つに整理できます。**

**1. 場面から入るか、分類から入るか（うちの実測でも出ています）**

Aは「評価会議で、ある若手の昇格が議題に上がった際」——**読者が入れない密室**。
Bは「40代になっても主任のまま上がれない人」——**人のカテゴリ**。

うちの208本で測っても同じ傾向でした。

| 1行目 | 本数 | 月内相対中央値 |
|---|---|---|
| **場面から入る** | 72 | **1.27倍** |
| 分類・一般論から入る | 136 | 0.94倍 |

**「いつ・どこで・誰が」がある1行目のほうが強い。**

**2. セリフがあるか**

Aは役員に**生で喋らせています**。

```
「彼の報告や提案は、事実と主観が明確に分かれていて非常に判断しやすい。
　上に引き上げても意思決定を誤らないね」
```

Bは「言われた仕事をミスなく長年続け（継続性）」と**要約**しています。
**Hideさん自身がnoteで書いた「述語はセリフにする」がそのまま出ています。**

**3. 間口の広さ**

Aの対象は**出世したい人ぜんぶ**。Bは**40代で主任の人だけ**。

**noteの第5章で測った「間口が広い商材ほどクリック率が高い」と同じ構造**です
（性格分析 > 年収診断 > 転職エージェント）。
**読者の母数を自分で絞ると、その時点で上限が決まります。**

**4. 切る直前の名詞**

```
A  上が最後に見ている『評価のモノサシ』とは、   ← 比喩・具体物のイメージ
B  上が引き上げを諦める決定的な理由は、        ← 抽象的で凡庸
```

**引きの強さは、切る直前の名詞で決まります。**
「理由」「ポイント」「秘訣」のような一般名詞では引きになりません。
**ただし凝らないこと。** 『部下への任せ方』程度の平凡な名詞で十分です（上の訂正）。

**検証できなかった仮説を1つ**: 「Aはなりたい側、Bはなりたくない側を
描いている」から差がついた、とも読めます。**うちのデータでは測れませんでした**
（該当が10本と4本しかなく、差も0.72対0.63で小さい）。
**上の4つと違って、これは根拠がありません。**

### ★それでも検証する価値がある理由（導線）

## 断言-リスト（断言 → たとえば、→ 箇条書き → 締め）

Hideさんが2本続けて採用している形です（「新卒ベンチャーは勧めない」
「着手が速いだけ」）。**どちらも私の下書きをHideさんが直しています。**

```
【1行目】結論を言い切る。人物を1人入れる

たとえば、

・作業（4項目）

【締め】読者の得 ＋ 遅い側の名指し
```

### 1行目に引きを作らないこと（2026-08-16）

私は毎回、1行目に「誤解 → 訂正」の二段を作って直されています。

```
私   同期に一人、いつも先に仕事を終わらせてるやつがいた。
　　 手が速いのかと思ってたけど、違った。着手が速いだけだった。（3文）
　　　　　　↓
Hide 東大卒の同僚、いつも仕事が速かったのは、着手が速いだけだった。（1文）
```

**断言型の1行目は主張そのものです。** 引きを作る型（型1の失敗ドラマ、
型6の二段）と混同しないこと。**「◯◯かと思ってたけど、違った」は要りません。**

### 学歴・年齢を1行目に入れる

上の例で**私は学歴を入れ忘れ、Hideさんが「東大卒の」を足しました。**
断言型では**他人3.8倍・年齢3.5倍・学歴3.2倍**（`voice.md`）。
**規定に書いてあるのに下書きで抜けます。書いたあとに必ず確認してください。**

### 箇条書きの重複は「言葉」ではなく「行動」で見る

Hideさんの指摘で気づいた点です。私の4項目のうち2つが重複していました。

```
・まとまった時間が空くのを待たない
・完成させてから見せない        ← 言葉は違うが、同じ「遅らせない」
```

**型4の「1つの主張を6回言い換える」とは別物です。**
型4は**主張が同じで行動が違う**。ここでやったのは**行動そのものが同じ**。

判定方法: **各項目を「明日やること」に読み替えて、同じ動作にならないか見る。**
Hideさんの直した4項目は、骨組みを作る／確認する／分解する／迷わない、と
**全部ちがう動作**になっています。

### 締めは「読者の得」＋「遅い側の名指し」

```
私   これをやると、方向がズレてても初日で気づける。
　　 遅い人って丁寧なんじゃなくて、間違いに気づくのが最後になってるだけ〜
　　　　　　↓
Hide これをやると、方向がズレてても初日で気づけて最速で動ける。
　　 仕事が遅い人って、着手が遅くて迷う時間が長いだけなんだよね。
```

3つ直されています。

- **「最速で動ける」を追加**。私は「気づける」で止めていて、**読者の得**が
  書かれていませんでした
- **「間違いに気づくのが最後」→「迷う時間が長い」。**
  気づきの遅さは結果の説明で、読者は自分を検出できません。
  **「迷ってる」は本人が自覚している状態**です（型4の「自分の身を守る」と同じ操作）
- **「遅い人」→「仕事が遅い人」。** 1行目の「仕事が速かった」と対になり、
  **冒頭と締めで同じ語を回収**しています

**改行も削られています。** 私は「これをやると〜」と「遅い人って〜」を
別段落にしていましたが、1段落に繋がれました。
