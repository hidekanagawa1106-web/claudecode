# 型ライブラリ

**すべて @nekosukexx の実測から作っています。** 一般論のテンプレではありません。

数字は2種類あり、**混ぜて比べないでください**（`winners.md` の2026-08-15の節）。

| 出どころ | 中身 | レンジ |
|---|---|---|
| 過去11本（ハイライト） | アカウントの**最高記録**。上澄み | 17万〜522万 |
| **公式エクスポート208本** | **全投稿（2025/05〜12）** | 27〜1272万（中央値2,110） |

**型の良し悪しは中央値で比べます。** 最高記録どうしの比較は
運の大きさを比べているだけになります。**全11本はエクスポートと照合済みです。**

### ⚠ ただし、型はインプレッションをほとんど説明しません

月をそろえて測り直すと、**型1・型2・型3は横並び**（相対中央値 1.07 / 1.02 / 1.35）。
型による差は2倍程度で、**月による差は300倍**でした（`winners.md`）。

**このライブラリは「書き方の引き出し」であって、当てる装置ではありません。**

**効く要素は型ごとに違います。** 全型に共通のチェックリストは作れません
（「他人が登場」ですら型4では0.1倍）。診断は `python x/x_diag.py` が
型ごとに行います。

`/x-draft` はここから型を選びます。`/x-scout` が競合を分析して型を追加します。

## グループAの書式（型1・2・3・5）

**『』で囲んだ決め台詞を、独立した1行に置く。** 前後に空行。
投稿の重心はここで、読者が引用RTするのもここです。

**締めは「同意誘導」であって「問いかけ」ではない。**

- 「〜よね。」「〜なんだよな。」「〜からね。」で終える
- 疑問形にしない。**この人の型では同意誘導のほうが返信が付いています**
  （521万の投稿で215返信、426万の投稿で77返信）

**箇条書きは「・」で3〜4項目。** 体験談型では使わない。観察型でのみ使う。

**B・C・D には当てはまりません。** 型4には『』も同意誘導の締めも無く、
それで いいね7.6万 を取っています。**以前このファイルに「過去11本すべてに例外なく」と
書いていましたが、事実誤認でした。** 型4が最初から例外です。

### 522万と1,009本を分けたもの（同じ「自分の失敗＋上司の一言」で5,000倍差）

```
新卒１年目、ワイの失態により顧客が「上司も連れて謝りにこい！」とブチギレ。
客先への道中で緊張MAXの中、上司は「今後は気をつけろ」と怒るのではなく、

### ★ 対比を作るために、上司の役割を否定しない（2026-09-04）

```
✕ 『俺は"評価する人"ちゃうで。"お前が使う道具"や。はよ使え。』
○ 『俺に"気に入られる"より、俺を"うまく使う"ほうが評価上がるで』
```

> **上司が評価する人なのは間違いないので違和感。**（Hideさん）

**私は "〜" を2つ入れる形を作るために、事実でない否定を置きました。**
上司は実際に評価する人です。**そこを否定した瞬間、読者の現実と食い違います。**

**対比は、事実を否定せずに作れます。** 上の○は「上司＝評価者」を認めたうえで、
**評価者本人が攻略法を明かす**形にしているので、対比も笑いも成立しています。

**型2の「意外で、かつ本当か」と同じ話**です（`formats.md` 型2）。
**決め台詞でも、前提の事実は曲げないでください。**

**最終版ではもう一段直りました。**

```
1. 『俺は"評価する人"ちゃうで。"お前が使う道具"や』  ← 事実を否定（却下）
2. 『俺に"気に入られる"より、俺を"うまく使う"ほうが〜』 ← 私の直し
3. 『俺に"気を遣う"より、俺を"うまく使う"ほうが〜』    ← Hideさん最終版
```

**「気に入られる」は相手が主語の受け身**で、読者が自分について言う言葉ではありません。
**「気を遣う」は自分の行動**なので、心当たりが立ちます
（`voice.md`「分析的な語より、状態の語」の確認法：**その言葉を読者が自分について言うか**）。
対比も鋭くなります —— **自分がコストを払う（気を遣う）／相手をコストにする（うまく使う）。**

### ★★ 落ち込んでいる場面も、セリフで書く（2026-09-04）

**同じ最終版で、場面が丸ごと書き直されました。**

| | |
|---|---|
| 私の案 | 謝りに行く電車の中で**ずっと黙り込んでたら** |
| Hideさん | **上司を連れて**謝りにいく電車の中で**「すみません」を繰り返す私に** |

**私は主人公を黙らせていました。** `voice.md` の「述語はセリフにする」は
上司の一言だけの話ではありません。**自分の状態もセリフにできます。**
「黙り込む」は状態の描写ですが、「『すみません』を繰り返す」は**その場にいた人しか
書けない絵**になります。

**同時に直った4点**:

```
✕ ワイの詰めが甘くて〜と言われ、        ○ 詰めが甘くて〜と言われた。
✕ 「担当を変えてくれ」                  ○ 「担当を変えろ」
✕ 上司は「反省しとけ」と言うのではなく    ○ 上司は「反省しろ」と叱るのではなく
✕ と笑って言われたのを、今でも覚えてる。  ○ と笑って言われたのを今でも覚えてる。
```

- **1行目は文として閉じる。**「〜と言われ、」で繋がず「〜と言われた。」で切る
- **顧客のセリフは温度を上げる**（`voice.md` 6番）。「変えてくれ」は怒っていません
- **無色の動詞を使わない。**「言うのではなく」→「**叱る**のではなく」
  （522万の実測も「**怒る**のではなく」です）
- **一人称は地の文の頭では省く。** 「ワイの詰めが甘くて」→「詰めが甘くて」。
  必要な1箇所（「繰り返す**私に**」）だけ残す

### ★★ 決め台詞に「その場で動く一言」を足す —— そして締めを消す（2026-09-04）

**同じ投稿がもう一度直り、締めが丸ごと消えました。**

```
[3稿]
『俺に"気を遣う"より、俺を"うまく使う"ほうが評価上がるで』
と笑って言われたのを今でも覚えてる。上司を使い倒す方が成果を出せるし、早く評価されるんだよね。

[最終版]
『俺に"気を遣う"より、俺を"うまく使う"ほうが評価上がるで。まずは謝りにいこか。』
と笑って言われたのを今でも覚えてる。
```

**1. 決め台詞の2文目が、上司の行動になっています。**
「使え」と言った直後に「**まずは謝りにいこか**」——
**上司が、自分を使わせる実演をしています。** 522万の「この上司は何も教えていない」と
同じ方向で、**説教が行動に変わる**のがこの1文です。

**2. だから締めが要らなくなりました。**
決め台詞が2文になって重心が十分に乗ったので、一般化の締めは説明になります
（`voice.md` 削り方1番）。**522万の実測も「今でも感謝してる。」で終わっています。**

> **型1の締めは必須ではありません。** 決め台詞が2文で自己完結したら、
> **「今でも覚えてる。」で終える**。16.9万のように一般化で締める形もありますが、
> **足すかどうかは決め台詞の重さで決めます。**

**3. 決め台詞を足したら、場面の時刻と矛盾しないか確認すること。**

```
✕ 上司を連れて謝りにいく電車の中で … 『まずは謝りにいこか。』  ← もう向かっている
○ 上司に報告し「すみません」を繰り返す私だったが … 『まずは謝りにいこか。』
```

**場面が「謝りに行く途中」のままだと、この一言は言えません。**
Hideさんは場面を**報告した直後**まで巻き戻しました。
**決め台詞を書き換えたら、その台詞が言える時刻に場面を置き直してください。**

**4. 上司のセリフにも「！」を付ける。**「反省しろ」→「**反省しろ！**」
（`voice.md` 6番。前回は顧客のセリフにしか当てていませんでした）

**構造**（522万の実測から）

```

```

**確認は2段階です。**

1. **各項目が、決め台詞の一文で説明できるか。** できない項目は捨てる
2. **その言葉を実際に言う場面が浮かぶか。** 浮かばないなら具体化する
   —— **2回外しています**（「ここまでは分かりました」／「どこまで共有されてますか」）。
   どちらも**主語や目的語が省かれていて、誰が何についての話か復元できない**のが原因。
   **その一言だけを人に見せて、場面が1つに決まるか**を見てください

**3版目**（遅れ・途中・詰まりの申告で揃えたもの）:

```
・「今日中は厳しそうです」と早めに言う
・「途中ですけど、一回見てもらえますか」と持ってくる
・「ここが分からなくて30分止まってます」と申告できる
　　→ 総じて「自分の状態を、聞かれる前に出してる」
```

**言いにくいことを言えている形にすると、生意気に見えません。**

### ★ 最終版で直された3点（2026-08-18）

**1. 数字が主張を裏切っていないか。**

```
✕ ・「ここが分からなくて30分止まってます」   ← 30分は「十分粘ってから」に見える
○ ・「ここが分からなくて15分止まってます」   ← 主張が"早さ"なので短い数字
```

**数字を具体的にすることばかり考えて、その数字が主張と合っているかを
見ていませんでした。**

**2. 決め台詞の主語を、語り手の視点に合わせる。**

```
✕ 「自分の状態を、聞かれる前に出してる」      ← 本人視点の行動描写
○ 「自分の状態を、聞かれる前に教えてくれる」  ← 上司から見た受け取り方
```

**観察型（型3・型5）の語り手は上司側にいます。**
「〜してくれる」にすると**関係が見えて、感謝の温度も乗ります**。
締めの「上司が一番しんどいのは」とも主語が揃います。

**3. 決め台詞が言い切りなら「になってる。」は要らない。**

シグネチャ構文「などあるが、総じて言うと、〜になってる。」の受けは、
**決め台詞の形によっては落とせます。** 1行減って締めに直結します。

**箇条書きは3つまで**（型3の実測で4つ以上は0.3倍。型5にも当てています）。


**実績: 27万**（2025/09/07）

**構造**

```
1行目: 「いろんな新人を見てきたが、[比喩]な人って、」
2〜5行目: ・「セリフ」が言えない、の形で4つ
6行目:  などあるが、総じて言うと、

「[一言で束ねる]」

になってる。
締め:   突き放した一言（「誰もお前に興味はないから、〜」）
```

**効く理由**: 箇条書きの各項目を**セリフ**にしているのが型3との差。
読者が自分の口癖として思い当たる。

### ★ 派生「呼びかけ版」——観察を報告せず、読者の場面から入る（2026-08-21）

**私の下書きを3回外して、Hideさんが視点ごと書き換えた形です。**
骨格（箇条書き3つ → 総括の接続 → 『決め台詞』）は同じで、**立ち位置だけが違います。**

```

**書くときの注意3つ。**

1. **決め台詞は独立した文でなくてよい。**
   「相手の頭の中をイメージする」＋「クセをつけるのが大事。」で一文です。

   「箇条書きの重複」参照）のに対し、呼びかけ版は**注意点の列挙**なので
   条件がゆるみます

**どちらを選ぶか**: 主張が**読者本人の行動を変える話**なら呼びかけ版、

## 議論系の締め —— 「？？」で終える（2026-08-18・Hideさんの指示）

> **炎上、議論を狙う系は、参照アカウントと同様に？で終えたい。**

**議論を狙う投稿だけは、疑問形で終えます。** いつもの同意誘導（〜よね。）は使いません。

### 「疑問形は0.28倍」は、この型に当てはまりません

`voice.md` の「疑問形にしない」と、208本で測った**疑問形終わり0.28倍**という数字は、
**いつもの型に質問を付け足しただけの6本**を測ったものです。
**議論を狙って設計した投稿は1本もありません。** 反証として使えない数字でした。

### 形

```
（場面 or 伝聞で、争いのある事実を出す）

【Aの言い分】なのか、【Bの言い分】なのか、どうだろう…？
```

**争点と質問は1文にまとめます。** 分けて「これどっち…？」と置くより短く、
**選択を迫る形ではなく独り言に寄る**ぶん、うちの独白文体に合います。

**★ 締めの直前に争点を並べること。** ここが要点です。
「どっちが正解？？」だけでは**何について答えればいいか分からず、リプが散ります。**
momoの922万も、直前に2人のセリフを並べてから聞いています。

### 同意を求める疑問にしないこと

| 終わり方 | 例 | momoの実測 |
|---|---|---|
| **判定の委譲** | これどっちが正解？？ | **922万** |
| **判定の委譲** | え、これ私が間違ってる？？ | **765万** |
| 同意を求める | 男性上司のほうがやりやすくない？ | 3.1万 |
| 同意を求める | 年下が上司でも敬語使うよね？ | 3.6万 |

**「〜よね？」は語り手の答えが見えているので、読者は「うん」で終わります。**
**答えを持っていないことが伝わる形にしてください。**

### ★ 「？？」ではなく「…？」（2026-08-18 訂正）

**ここに「？？を2つ重ねるのがmomoの形」と書きました。そのまま移すのは誤りです。**
Hideさんの最終版は **「これどっち…？」** でした。

```
✕ これどっち？？          ← 問い詰め。カジュアル。momoの文体
△ これどっち…？          ← 迷いは出るが、まだ選択を迫っている
○ 〜なのか、どうだろう…？ ← 独り言。うちの文体
```

**2段階かけて自分の声に戻しています。** 他アカウントの形は
**構造だけ借りて、記号も語尾も自分のものに置き換える**こと。

**「…」はこのアカウントに元からある記号**です（1stリプでずっと使っています）。
**他アカウントの形は構造だけ借りて、記号や語尾は自分のものに戻すこと。**

### ★ 議論系では「一言かばう」を入れない（2026-08-18）

`voice.md` の削り方7番（落としっぱなしにせず一言かばう）は、
**議論を狙う回には当てはまりません。**

```
✕ 「キラキラ系は採らない」と言ってた。理由は炎上リスク。
　 本人の能力の話じゃなくて、何かあったとき会社ごと燃えるのが怖いだけらしい。
○ 「キラキラ系は採らない」と言ってた。理由は「炎上リスクがあるから」だって。
```

**かばうと、読者が「なるほど」で納得して争点が片付きます。**
**説明を足すほど、答える余地が減ります。**

**代わりに距離を取ってください。** 「だって」「らしい」で伝聞を明示すれば、
**語り手が肯定していないことは伝わり、判定は読者に残ります。**

### 議論系以外には持ち込まないこと

**通常の型では引き続き疑問形にしません。** 実測（521万で215返信、426万で77返信）で

### 型の骨格（2本に共通する部分）

```
【1】導入 —— 上の視点が見える場所を提示する
【2】中身 —— 上が何を見ているかを書く
【3】転換 —— 「ですが、」「どれだけ〜していても、」
【4】★助詞のまま切る★ —— 「〜とは、」「〜理由は、」
────────────────────────────
【自己リプ】答え → 一般化 → 明日できる1つの行動
```

**書式も2本で共通しています。**

- **改行なし・空行なし。** 画面を一塊で埋める（うちは1〜2文ごとに改行）
- **1文が長い。** 本文は2〜3文だけ（うちの1行中央値は18字）
- **主語は必ず「上」。** 「上に引き上げても」「上が最後に見ている」
  「上が引き上げを諦める」。**評価する側を主語にした暴露**です
- **切るのは必ず【名詞 ＋ は、／とは、】。** 体言止めにすらしない

**構文が閉じていないので、脳が補完を求めます。**
答えを見るには**詳細クリックかリプ欄を開くしかありません。**

## 断言-リスト（断言 → たとえば、→ 箇条書き → 締め）

Hideさんが2本続けて採用している形です（「新卒ベンチャーは勧めない」
「着手が速いだけ」）。**どちらも私の下書きをHideさんが直しています。**

```
【1行目】結論を言い切る。人物を1人入れる

たとえば、

・作業（4項目）

【締め】読者の得 ＋ 遅い側の名指し
```

### 1行目に引きを作らないこと（2026-08-16）

私は毎回、1行目に「誤解 → 訂正」の二段を作って直されています。

```
私   同期に一人、いつも先に仕事を終わらせてるやつがいた。
　　 手が速いのかと思ってたけど、違った。着手が速いだけだった。（3文）
　　　　　　↓
Hide 東大卒の同僚、いつも仕事が速かったのは、着手が速いだけだった。（1文）
```

**断言型の1行目は主張そのものです。** 引きを作る型（型1の失敗ドラマ、
型6の二段）と混同しないこと。**「◯◯かと思ってたけど、違った」は要りません。**

### 学歴・年齢を1行目に入れる

上の例で**私は学歴を入れ忘れ、Hideさんが「東大卒の」を足しました。**
断言型では**他人3.8倍・年齢3.5倍・学歴3.2倍**（`voice.md`）。
**規定に書いてあるのに下書きで抜けます。書いたあとに必ず確認してください。**

### 箇条書きの重複は「言葉」ではなく「行動」で見る

Hideさんの指摘で気づいた点です。私の4項目のうち2つが重複していました。

```
・まとまった時間が空くのを待たない
・完成させてから見せない        ← 言葉は違うが、同じ「遅らせない」
```

**型4の「1つの主張を6回言い換える」とは別物です。**
型4は**主張が同じで行動が違う**。ここでやったのは**行動そのものが同じ**。

判定方法: **各項目を「明日やること」に読み替えて、同じ動作にならないか見る。**
Hideさんの直した4項目は、骨組みを作る／確認する／分解する／迷わない、と
**全部ちがう動作**になっています。

**この規定は断言-リストだけの話ではありません。箇条書きを使う型すべてに効きます。**
型5でも同じ外し方をして、**外から直されるのは2回目**になりました（2026-08-21）。

```
・「前提から説明したほうがいいですか」と先に聞く
・知らない人には背景から、知ってる人には結論から
        ← 言葉は違うが、どちらも「相手の既知量に合わせて説明の深さを変える」
```

型5は**3つとも決め台詞の実例**にする必要があるので、実例を並べようとすると
**同じ動作の言い換えになりやすい**です。決め台詞に寄せた直後に、
**もう一度「明日やること」で読み直してください。**

### ★ 重複を指摘されたら、直すのは「直したばかりの項目」（2026-08-21）

**上の型5で、私は直す項目を取り違えました。**

経緯です。1つ目が不明瞭と言われて書き直す → その直後に
**「箇条書きの2つめと内容がほぼ同じ」**。私はこれを「2つ目を直せ」と読んで
2つ目を差し替えましたが、Hideさんの最終版では**2つ目が残り、私が直した1つ目が消えて**
います。指摘は**「（いま直した1つ目が）2つ目とほぼ同じ」**という意味でした。

- **直した直後の指摘は、直した箇所への続き**として読む。
  同じ項目の話が続いている前提で読んでください
- **重複の解消は「片方を外す」が既定**です。私は毎回**両方残して片方を作り直し**、
  新しい動作を発明しています。**弱いほうを落として3つに戻すほうが速い**
- どちらが弱いかは**決め台詞との距離**で決める。
  外れた「先に聞く」は、確かめる動作そのもので**決め台詞とほぼ同義**でした
  （実例ではなく言い換えになっていた）
