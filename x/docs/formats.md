# 型ライブラリ

**すべて @nekosukexx の実測から作っています。** 一般論のテンプレではありません。

数字は2種類あり、**混ぜて比べないでください**（`winners.md` の2026-08-15の節）。

| 出どころ | 中身 | レンジ |
|---|---|---|
| 過去11本（ハイライト） | アカウントの**最高記録**。上澄み | 17万〜522万 |
| **公式エクスポート208本** | **全投稿（2025/05〜12）** | 27〜1272万（中央値2,110） |

**型の良し悪しは中央値で比べます。** 最高記録どうしの比較は
運の大きさを比べているだけになります。**全11本はエクスポートと照合済みです。**

### ⚠ ただし、型はインプレッションをほとんど説明しません

月をそろえて測り直すと、**型1・型2・型3は横並び**（相対中央値 1.07 / 1.02 / 1.35）。
型による差は2倍程度で、**月による差は300倍**でした（`winners.md`）。

**このライブラリは「書き方の引き出し」であって、当てる装置ではありません。**
はっきり効くのは「他人が登場しない断言を避ける」ことだけです。

`/x-draft` はここから型を選びます。`/x-scout` が競合を分析して型を追加します。

## 骨格グループ —— 飽きを防ぐための分類

**型が5つあっても、骨格は実質1つでした。** 型1・2・3・5 はどれも
「前振り → 箇条書きか状況 → 『などあるが』 → 『決め台詞』 → 同意誘導」で同じです。

月2本のときは反復が見えませんでしたが、**1日2本＝月60本では並んで見えます。**
そこで骨格でグループ分けし、日をまたいで散らします。

| グループ | 型 | 骨格 | 見た目 |
|---|---|---|---|
| **A** | 型1・型2・型3・型5 | 前振り→『決め台詞』→同意誘導 | 10〜14行。実績はここに集中 |
| **B** | 型4 | 見出し＋2列リスト | リスト。『』も締めも無い |
| **C** | 型7 | セリフの応酬だけ | 5〜8行。地の文が無い |
| **D** | 型8 | 短文 | 5〜7行。箇条書きも『』も無い |

**在庫（`stock.md`）の中で A と 非A を半々に保つ。** 投稿の順番はHideさんが
決めるので「今日はA、明日は非A」という組み方はできません。在庫が半々なら、
どこから取っても非Aが混ざります。Aが実測最強なので、Aを捨てるのではなく
**必ず非Aを混ぜる**形にしています。

## グループAの書式（型1・2・3・5）

**『』で囲んだ決め台詞を、独立した1行に置く。** 前後に空行。
投稿の重心はここで、読者が引用RTするのもここです。

**締めは「同意誘導」であって「問いかけ」ではない。**

- 「〜よね。」「〜なんだよな。」「〜からね。」で終える
- 疑問形にしない。**この人の型では同意誘導のほうが返信が付いています**
  （521万の投稿で215返信、426万の投稿で77返信）

**箇条書きは「・」で3〜4項目。** 体験談型では使わない。観察型でのみ使う。

**B・C・D には当てはまりません。** 型4には『』も同意誘導の締めも無く、
それで いいね7.6万 を取っています。**以前このファイルに「過去11本すべてに例外なく」と
書いていましたが、事実誤認でした。** 型4が最初から例外です。

## 型1: 上司の一言 —— **当たり外れが最大の型**

**実測57本。中央値895、最大522万。**

| | 型1 | 型3 |
|---|---|---|
| 本数 | 57 | 58 |
| 中央値 | **895** | 3,676 |
| 最大 | **522万** | 333万 |

**同じ本数で、中央値は4分の1なのに天井は上。** 57本のうち10万を超えたのは
3本だけで、残りは数百〜数千で終わっています。**宝くじ型です。**

「★最強」と書いていたのは誤りでしたが、その後「最弱」と書いたのも誤りでした。
**外れが多いので在庫に1本まで**、というルールで扱ってください。

### 522万と1,009本を分けたもの（同じ「自分の失敗＋上司の一言」で5,000倍差）

```
新卒１年目、ワイの失態により顧客が「上司も連れて謝りにこい！」とブチギレ。
客先への道中で緊張MAXの中、上司は「今後は気をつけろ」と怒るのではなく、

「いい歳したオッサンが本気で怒る様子なんて滅多に見れへんで。楽しみやな。」

と言って和ませてくれたのを、今でも感謝してる。
```

**1. 失敗を他人のセリフで見せる。**「怒られた」ではなく顧客の言葉をそのまま引く
**2. 物理的な場面を1行入れる。**「客先への道中」「緊張MAX」
**3. 決め台詞を教訓にしない。** この上司はジョークを言っているだけで何も
教えていません。**教えると説教になり、笑わせると引用されます**

関西弁が入るのもこの上司の特徴です（12月の5,972本も「聞きたいねん」）。

### 「質問から始まる形は出すな」は撤回

その形の**169,468は57本中3位**でした。禁止する根拠がありません。

```
新卒２年目で「どうすれば早く昇進できますか？」と聞いたら早稲田卒に、
「"お前を使うと楽になる"と俺に思わせてくれ」
と笑って言われたのを覚えてる。
```

### 決め台詞は、中に対比か言い換えを入れる

```
「"お前を使うと楽になる"と俺に思わせてくれ」        16.9万
「"質問の数"と"成長の速さ"は比例するぞ」            7.0万
「"自分がいないと回らない状態" のうちは半人前だな」    3.4万
「"上司に怒られたくない"で動くな。"顧客に喜ばれたい"で動け」 1.1万
```

**単なる格言にしないでください。** 対比も言い換えも無い決め台詞は数千止まりです。

**構造**（522万の実測から）

```
1行目: 新卒[N]年目 + 自分の失敗を、**他人のセリフ**で見せる
2行目: 物理的な場面（移動中、呼び出された、緊張MAX）
3行目: 上司は「[凡庸な予想]」と◯◯するのではなく、

『[予想外の一言。教訓ではなく、笑わせる]』

と言って[くれた/言われた]。
締め:   今でも感謝してる。／今なら分かる。
```

**効く理由**: 1〜3行目で読者に予測を作らせ、決め台詞で裏切る。
予測のつくり方は**自分の失敗でなくてよい**（質問・場面・他人の失敗でも成立）。

**この型で失敗する形**

**教訓を語るだけ**にすると落ちます（733でその月の最下位）。
「昔◯◯と言われた。大事だと思う」は、予測も裏切りも無いので何も起きません。

**誰かの具体的な場面から始まっていない投稿は、この型ではありません。**

## 型2: 面接官の暴露 ★転職導線に最適

**実測15本。中央値6,294、最大155万。総合導線率が全型で1位（0.0508%）。**

**拡散は3位でも、クリックは型3の4倍**生みます。読者が面接の文脈にいる状態で
リプに降りてくるからです。**導線を伸ばしたいならこの型を増やしてください。**

**1行目は必ず「ベンチャーで面接官してる[が/けど/ますが/のだが]、」**（15本中15本）。

### 実測で一番強かった型2は、決め台詞が無い「リスト形式」でした

```
ベンチャーで面接官してるけど、これ履歴書に書いてると正直キツイ…

・MOS
・簿記3級
・教員免許
・秘書検定3級
・TOEIC 650点
・中小企業診断士
・ビジネス実務マナー検定
```

**194,747インプレッション・返信32（9月の最多）。** 『』も締めもありません。
**具体名を並べるだけ**で、読者が自分の履歴書を見に行きます。

返信が伸びる＝荒れやすい形でもあります。**人格ではなく「並び」を批評する**
形にしてください（関連実測: 「TOEIC850＋簿記3級」と「MOS＋秘書検定3級＋簿記3級」
では人事の読み方が違う、という8/12の投稿）。

**構造**

```
1行目: 「ベンチャーで面接官してますが、」＋ 判断の話だと宣言する
2〜5行目: ・箇条書きで「よくあるNG理由」を3つ（読者が予想できるもの）
6行目:  などあるが、実はよく落とすのが、

『[意外な一項目]』

と言う人。
締め:   なぜそれがNGなのかを、採用側の損得で1〜2行
```

**効く理由**: 「元リクルート／現面接官」という立場でしか言えない内部情報。
読者が自分の面接を思い返すので、**プロフィールに来る動機が最も強い型**です。

**転職アフィリの導線としては、この型が本命です。**
15本ぶんの実測で**総合導線率1位（0.0508%）**が裏づけになりました。

**注意**: 断定的に人を否定すると荒れます。落とす理由は「採用側のコスト」として
説明する（実例では「無駄なマネジメントコストがかかる」）。人格の話にしない。

**もう1つの注意 —— 意外性のために事実を曲げないこと。**
「ベンチャーでビジョン共感を落とす」という案を出して却下されました。
ベンチャーはむしろミッションフィットを重視するので、業界の人が読むと明確に
間違いです。**Hideさんは実際の面接官なので、事実誤認は意外性の価値を上回って
信用を削ります。** 「意外で、かつ本当」を両方満たすものだけを使ってください。

### 素材バンク（出典つき）

**型2はリサーチしてから書くほうが確実です。** 打率の実績:

| 書き方 | 結果 |
|---|---|
| 想像で書く | **4本中3本却下**（事実誤認 / ポジション崩し / 論理が繋がらない） |
| 出典を取ってから書く | 1本中1本通過 |

想像でも通ることはあります（「裁量のある環境で働きたい」は出典なしで通過）。
ただし**外したときの損害が大きい**——Hideさんは実際の面接官なので、
事実誤認は意外性の価値を上回って信用を削ります。**迷ったら調べてください。**

**最終判定はHideさんです。** 業界の現実に照らせるのは本人だけなので、
出典があっても違和感を言われたら差し替えます。

**NG例3つに使えるもの**（読者が予想できる、一般的な見送り理由）

・スキルが足りない ・経験が合っていない ・転職回数が多い
・在職期間が短い ・コミュニケーション能力

**「意外な1つ」に使えるもの**（一見好印象だが採用側は警戒する。
出典: [doda人事ジャーナル](https://www.dodadsj.com/content/230915_answers_that_require_attention/)）

| 候補者の答え | 採用側の懸念 |
|---|---|
| 『努力して、一人で乗り越えてきました』 | 協調性・チームプレイの意欲が不明。職場適応に不安 |
| 『困難と感じたことはありません』 | 自己分析不足。問題対処能力が測れない |
| 『誰にも負けない熱意があります』 | 具体性が無く、実務スキルの説明になっていない |
| 『この場の誰よりリーダーシップがあります』 | 自己中心的に見え、入社後チーム内で反感を招く |
| 『成長させてもらえると思ったからです』 | 受け身。主体性への不安 |
| 『経営理念に共感したからです』 | 汎用的で具体性が無く、企業研究不足に見える |
| 『どのような研修制度がありますか』（逆質問） | HPで分かる情報。受け身で早期離職リスク |

**注意**: 「経営理念に共感」は**共感すること自体が悪いのではありません。**
懸念されるのは「具体性が無い共感」です。ここを取り違えて
「ベンチャーでビジョン共感を落とす」と書き、却下されました。
**出典の懸念点をそのまま使ってください。言い換えると意味が変わります。**

## 型3: 人物観察（学歴・年齢つき）★平常値の稼ぎ頭

**実測58本。中央値3,676、最大333万。全型で最多の本数。**

**拡散の土台です。** 全体の中央値2,110を上回り、外れが少ない。
ただし**総合導線率は0.0123%で全型の最下位** —— 枚数はここで稼ぎ、
クリックは型2・型7で取る、という役割分担になります。

**年齢・職種・学歴を必ず頭に置きます。** 青学卒の営業（28才）は9月だけで
4回登場していて、**同じ人物を使い回して構いません。**

**構造**（9月の実測4本から。**接続の言い回しが毎回違います**）

```
1行目: [学歴]卒の[修飾]営業（28才）、[何]が[評価]で、
2〜4行目: ・箇条書きで具体的な作業を3つ
5行目:  これだけでも[偉いが/優秀だが/助かるが/安心感あるが/信頼されるが]、
        とくに[良かった/印象的だった/驚いた/光っていた]のは、…
          ↑ ここで本文が折りたたまれる

『[核心の一行]』

という点。
締め:   一般化して「〜よね」「〜からね」
```

**「これだけでも◯◯が、とくに◯◯のは、」が9月の勝ちパターンです。**
`voice.md` の「などあるが、とくに良いのは、」より、こちらのほうが実測が上。
**◯◯の中身は毎回変えてください**（同じだと連投で見飽きます）。

**決め台詞は折りたたみの下に置く。** 上位投稿はすべて接続の行で「…」と切れて
いて、読者に「もっと見る」を踏ませています（＝詳細クリックが稼げる）。

**効く理由**: 学歴と年齢が引きの装置として働いている。**この2つを外さないこと。**
「優秀な後輩が」では引きが消えます。

**333万と23万を分けたもの**: 333万の投稿（議事録）は、箇条書き3つが全部
「読者が真似できる具体的な作業」でした。23万の投稿（炎上対応）は箇条書きが
「深夜でも最速対応」など**姿勢**の話で、真似できません。

**箇条書きは行動で書く。姿勢で書かない。**

### Hideさんの修正から（2026-08-13・2122imp）

下書きを6箇所直されました。**型3を書くときはここを最初に見てください。**

| 出した案 | 直された形 | 学び |
|---|---|---|
| クロージングが妙にうまくて | **売れてるには理由があって** | 手段ではなく**結果**から入る。「妙にうまい」は評価者目線で上から |
| 提案の前に決裁者と決裁時期を確認 | **決裁時期を必ず確認** | **箇条書きは1項目1要素。** 2つ詰めない |
| 次のアポを通話が切れる前に取る | **商談中に次の日程を抑える** | 同上。短く |
| 保留されたら | **「検討する」と言われたら** | **抽象語を、相手が実際に言う言葉に置き換える** |
| などあるが | **など基本だが** | 箇条書きを「当たり前」と明示すると、次の決め台詞が立つ |
| 26才 | **29才** | その練度に達する年齢のリアリティ |

**締めの直しが一番大きい。**

- 出した案: 「断られたあとに動ける人が、結局いちばん数字を持ってくるんだよな。」
- 直された形: 「**彼いわく、「一度断られてからが勝負です」とのこと。強い。**」

**語り手が一般化して閉じるのではなく、本人にもう一度喋らせている。**
決め台詞が2つある構造で、しかも最後は「強い。」の2文字。
詳細は `voice.md` の「締めの型」。

## 型4: 対比リスト ★平常値で1位

**実測12本。中央値5,782、最大1272万。**

**2025/09/11【本当に強いのはこういう人】= 12,729,541インプレッション。
全208本の1位**です。いいね76,782・返信280・プロフクリック10,387。

**しかも導線でも最高**でした（リプ969,170imp → **2,820クリック**。
8ヶ月の全クリック5,314の53%）。`funnel.md` の「型4には貼らない」は撤回しています。

**テーマで1700倍ちがいます。**

| | テーマ | imp |
|---|---|---|
| 09/11【本当に強いのはこういう人】 | **完璧主義をやめる・頑張りすぎない** | **1272万** |
| 12/08【転職がうまくいく人】 | 転職 | 7,433 |

**「頑張りすぎる人へのゆるし」がこの人の最大の当たりテーマです。**
転職テーマは導線に近いぶん、拡散では圧倒的に負けます。**まず「ゆるし」側から。**

```
【本当に強いのはこういう人】

←強い人　　　　　　　　弱い人→
・80点で十分　　　　　・100点を求める
・受け流す天才　　　　 ・抱え込む天才
・うまくサボれる　　　 ・常にマジメすぎる
・自分に優しい　　　　 ・自分に厳しい
・自分と比べる　　　　 ・他人と比べる
・いいねが口癖…
```

**【】の見出しを付ける。** 実測で伸びた2本はどちらも【】付きです。

**構造**

```
【断言の見出し】

←強い人        弱い人→
・項目          ・逆の項目
（9項目前後、2列で対にする）
```

**効く理由**: いいね率が全型で突出。保存・引用されやすく、本文を読む必要がない。

**注意**: 締めの文が無くても成立する型です。**説明を足さないでください。**
また、この型は**年収の話に橋を架けにくい**ので（`funnel.md`）、導線としては
期待していません。

**最高記録でも平常値でも1位なのに、いまの在庫は0本です。** 骨格が唯一違う
（グループB）ので飽き対策にもなります。**最優先で補充してください。**

**実例（7,433）の構成** —— 転職というテーマで、9項目・2列。

```
【転職がうまくいく人】
←うまくいく　　　　　うまくいかない→
・企業を選ぶ　　　　・選ばれるのに必死
・転職軸が明確　　　・大手ならどこでも...
・弱点も話せる　　　・強みだけ主張
・受け身じゃない　　・"どんな仕事がありますか？"
・面接が会話　　　　・面接がプレゼン大会
```

**右側（うまくいかない側）に具体的なセリフを混ぜている**のが効いています。
「受け身」ではなく「"どんな仕事がありますか？"」。読者が自分の言葉として
思い当たる形です。

## 型7: 会話だけ（グループC）

**平常値: 1,219**（2025/12/03）—— 中央値ちょうど。**拡散はしません。**
ただし**返信6件はその月の最多**で、エンゲージ率3.20%も上位です。

**リーチではなく反応を取る型**として使ってください。返信はアルゴリズム上の
重みが大きく、しかも導線（1stリプ）まで降りてもらう必要があるこの運用では、
**「リプ欄を開かせる型」には固有の価値があります。**

うちに無い骨格（`accounts.md` の @mei3_biz）。
**地の文なし・『』なし・締めなし・箇条書きなし。**

**実例（1,219・返信6）** —— 同じ質問に戻るループで落としています。

```
面接官「どんな企業に入りたい？」
👨「ベンチャーです」
面接官「どんな働き方を希望？」
👨「必ず定時退社したいです」
面接官「どんな仕事がしたい？」
👨「言われた作業だけやって1,000万もらえる仕事です」
面接官「どんな企業に入りたい？」
👨「ベンチャーです」
```

**最後に1問目へ戻す。** 心の声を書かずに、矛盾を読者に気づかせる形です。
下の「心の声で締める」形とどちらが効くかは、まだ比較できていません。

**構造**

```
[役職A]「（質問）」

[役職B]「（用意してきた答え）」

[役職A]「（一歩踏み込む）」

[役職B]「（崩れる）」

[役職A]（心の声）
```

**例**

```
面接官「退職理由を教えてください」

候補者「キャリアアップのためです」

面接官「具体的にはどのあたりを？」

候補者「…成長できる環境を求めまして」

面接官（あ、用意してきた答えだけか）
```

**効く理由（推定）**: 説明が一切無く、読者が場面を再生する。
**型2の素材バンク7項目が全部この形で書き直せる**ので、実質的に在庫が倍になります。

**注意**

- **往復は2〜4回まで。** 長い会話は読まれません
- **締めは2択。** 括弧書きの心の声 か、1問目に戻すループ
- **面接シーンで使うときは**、語り手のポジションは型2と同じ（**判断する側**）。
  自社が答えられないと自己申告する形にしない
- **上司-部下のシーンでは、上司が反省する側でよい。** このアカウントの
  語り手は基本的に「失敗する側・教わる側」なので、そちらが自然です
- **拡散を期待しない。** 返信を取りに行く型として使います

## 型6候補: 二段の引き（@sayu5632j から。**部分的にだけ借りる**）

**実測 519万 / 73万**（他人のアカウント。うちではまだ未検証）

@sayu5632j の投稿は30〜50行の**長文・物語再現形式**です。一人称は「私」で丁寧語。
うちは10行前後・独白・「ワイ」なので、**形式をそのまま持ち込むと別人になります。**

**借りるのは引きの設置だけ。**

```
（本命の決め台詞の前に、もう1段置く）

… でも、唯一の謎があった。      ← 1段目。読者を次の行へ送る
（謎の提示）
（一言その1）
… でも、刺さったのは次の言葉だった。  ← 2段目
『本命の決め台詞』
```

**効く理由**: 一言を1つで終わらせず、もう1段深いところに本命を置くと、
読者が途中で離脱しなくなる。うちの投稿は決め台詞が1つだけなので、ここは伸びしろです。

**注意**: 引きを増やすと本文が長くなります。**10〜14行を超えないこと。**
超えるならこの型は諦めて、通常の型に戻してください。

**あわせて**: 読者に**何を予測させるか**を1〜3行目で作る（`winners.md` の検証結果）。
自分の失敗だけが手段ではありません。謎の提示、期待させてから落とす形でも代替できます。

## 使わない型: 他人が登場しない断言

**実績: 4万**（2025/08/20「社会人10年やって気づいた〜これに尽きる」）
**過去11本でインプレッション最下位。**

体験談も箇条書きも観察対象もなく、意見だけを断言する形。

**正確に言うと「反応されない」のではありません。** この投稿のエンゲージ率は2.73%で
実は11本中トップです。届いた人は反応している。**配信が伸びなかった**のが問題です。
とはいえサンプルは1本なので、断定はしていません（`winners.md` 参照）。

いずれにせよ、**`/x-draft` はこの形を出さないこと。** 他に実測で桁違いに強い型が
あるので、枠を割く理由がありません。

見分け方: **登場人物が自分ひとりしかいない投稿は、この形に落ちています。**
上司・後輩・新人・候補者。誰か他人が出てこない下書きは書き直してください。
