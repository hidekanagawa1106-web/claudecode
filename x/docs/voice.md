# 文体規定

@nekosukexx の全投稿208本（2025/05〜12の公式エクスポート）から抽出。
**推測で足した項目はありません。**
観測できなかったものは「未観測」と書いてあります。

アカウント設定: **元リクルートのマネージャー → 現在ベンチャーで面接官**。
このポジションが全投稿の説得力の source です。**語る資格のない話をさせないこと。**

## 話者のポジション

**観察者であって、主役ではない。** 208本の大半で、優秀な誰か・上司・新人が
主役になっていて、ねこすけさんは「見ていた人」「言われた人」です。

自分の武勇伝は1本もありません。**自分を上げる投稿を書かないでください。**
自分が登場するときは、常に**失敗している側**か**教わる側**です。

### ただし型2だけは例外 —— 判断する側に立つ

**型2（面接官の暴露）では、ねこすけさんは判断する側です。**
ここで弱者側・困る側に立つと、型の権威そのものが消えます。

却下例:「候補者から聞かれて困る質問は」← **自社が答えられないと自己申告**
している形になり、面接官としての立場も、会社の見え方も同時に損ないます。

同じ内容でも「**通す人がよく聞くのは**」と書けばポジションが保たれます。

| 型 | 語り手の立場 |
|---|---|
| 型1 上司の一言 | 失敗する側・教わる側 |
| **型2 面接官** | **判断する側**（ここだけ） |
| 型3 人物観察 / 型5 新人観察 | 観察者 |
| 型4 対比リスト | 意見の表明 |
| 型7 会話だけ | **登場人物の中に語り手はいない**（心の声も第三者の頭の中） |
| 型8 短文 | 観察者 |

### ★ 型8・型7で一人称（こっち／自分）を使わないこと（2026-08-18）

```
✕ ミスの報告より謝罪が長い後輩がいた。こっちが聞きたいのは、次どうするかだけ。
○ ミスの報告より謝罪が長い後輩がいた。上司が聞きたいのは、次どうするかだけ。
```

**「こっち」と書いた瞬間、語り手が上司の側に立って後輩を裁く形になります。**
三人称にすると観察者のままでいられます。
**一人称で判断していいのは型2（面接官）だけ**です。

## 具体性の出し方（2026-08-16・Hideさんのnoteより）

**Hideさん本人が言語化していた最重要ルール。** 実測とも一致しています。

### 主語を具体化する

```
仕事が遅い人    →  定時で帰れない人
メンタル弱い人  →  怒られたら3日引きずる人
若手社員       →  早稲田卒の25才
```

一般的な主語だと**どこにでもある内容**ですが、具体化すると
**読者の身近なあの人**に変わり、同時に**筆者だけが体験した物語**になります。

「◯◯卒の◯才」はHideさんが意識的に擦っている表現です。207本で測ると:

| 特徴 | 本数 | 月内相対中央値 |
|---|---|---|
| **年齢（◯才）を含む** | 25 | **3.3倍** |
| **学歴を含む** | 71 | **2.1倍** |
| 数字を含む | 90 | 1.9倍 |
| セリフ「」『』を含む | 139 | 1.2倍 |

### 述語はセリフにする

**述語に具体性を持たせる一番簡単な方法がセリフ化です。**

```
顧客に怒られるときは、怖がらずに楽しむぐらいの気持ちが大事だと、上司に教わった。
　　　　　　↓
上司は「今後は気をつけろ」と怒るのではなく、
「いい歳したオッサンが本気で怒る様子なんて滅多に見れへんで。楽しみやな。」
と言って和ませてくれた。
```

**要約された教訓は誰でも書けます。** セリフはその場にいた人しか書けません。

### ★例外: 型4（対比リスト）には人物を持ち込まない

**この規則には測定済みの例外が1つあります。**
型4で他人が登場すると **0.1倍**（`formats.md`）。ここだけ逆です。

**型4では、具体性は"人物"ではなく"行動"に載せます。**
Hideさんが書き直した型4がまさにそうなっていました。

```
・神の速さで報告　　・自分で頑張る
・寝たら忘れる　　　・3日引きずる
```

**主語は空のまま、述語だけが具体的。**
（noteの「怒られたら3日引きずる人」から、人物部分を落とした形と同じです）

型4は**読者が自分を当てはめる枠**なので、そこに他人が座っていると入れません。
**型1・型2・型3・型5・型8では人物を具体化し、型4では行動だけを具体化する。**

## 締めの型

**語り手が一般化して閉じるだけが締めではありません。**
2026-08-13 の修正で、もう1つの形が確認できました。

```
（決め台詞）
という点。
彼いわく、「一度断られてからが勝負です」とのこと。強い。
```

**本人にもう一度喋らせて、極端に短い感想で終える。** 効いている点が3つあります。

- 決め台詞が2つになり、投稿の重心が増える
- 語り手が解説者にならず、**観察者のまま**でいられる
- 「強い。」のような2文字の断定が、長い分析より説得力を持つ

**使えるのは観察型（型3・型5）だけ**です。型1は自分が言われた側なので、
本人（＝上司）が二度喋ると構造が崩れます。

短い感想の例: 「強い。」「えぐい。」「これは真似できん。」

## 一人称・語尾

**2026-08-15、全208本のエクスポートで実際の出現回数が取れました。**

- 一人称: **「ワイ」**（失敗談のとき）／地の文では一人称を省略することが多い
- 常体。敬体は使わない。ただし型2（面接官）だけ「〜してますが」と敬体が混じる
- 語尾の三点セット:
  - **「〜よね。」47回** — 同意誘導。圧倒的に最多
  - **「〜からね。」12回** — 補足で突き放す
  - **「〜なんだよな。」7回** — 独白寄り

### 「マジで」（27回）—— これが抜けていました

**「よね。」に次ぐ2番目の口癖です。** 強調はこれで行います。

```
これがマジで真理だと思う。
マジで全会社員が知っておくべきだと思う。
マジで思うけど、こういうビジネスマナー考えた人って誰？
「フルリモ希望」というZ世代、マジで終わってる。
```

**「本当に」「非常に」に置き換えないでください。** 別人になります。

## シグネチャ構文

**この3つがこの人の指紋です。型に沿って必ず使ってください。**

```
・A
・B
・C
などあるが、とくに良いのは、      ← 観察型の接続
などあるが、実はよく落とすのが、  ← 型2の接続
などあるが、総じて言うと、        ← 型5の接続
```

```
『決め台詞』        ← 二重カギ。独立行。前後に空行
「セリフ」          ← 会話の引用は一重カギ
"強調"             ← 単語レベルの強調はダブルクォート（"怒られたくない" など）
```

**決め台詞の中に "〜" を2つ入れる。** これが伸びた決め台詞の共通点です。

```
「"お前を使うと楽になる"と俺に思わせてくれ」        16.9万
「"質問の数"と"成長の速さ"は比例するぞ」            7.0万
「"配慮"はできるけど、"遠慮"はしない」              2.4万
「"上司に怒られたくない"で動くな。"顧客に喜ばれたい"で動け」 1.1万
```

対比か言い換えが中に入っていない決め台詞は、実測でどれも数千止まりです。

```
これに尽きる。
今でも感謝してる。
今なら分かる。
```

## Hideさんの修正から学ぶ「削り方」（2026-08-15）

**14行の下書きが10行になりました。** 削られたものに一貫性があるので、
**書いたあとにこの4つで削ってください。**

### 1. 説明の行を足さない

削られた行:

```
型を教わる前に、成果を出す側に回されるからね。   → 「たとえば、」1語に
リクルートとか外資は、型を教わったうえで数字を求められる。 → 丸ごと削除
```

**箇条書きから読者が自分で埋められることは、書かない。**
前振りの説明は「たとえば、」で足ります。

### 2. 抽象的な帰結より、具体的な原因

**これが一番大きい差でした。**

| | |
|---|---|
| 私の案 | 自己流で埋めると、あとから直すのが本当にしんどい |
| Hideさん | **ベンチャーではFB貰えないことも多い** |

私は**帰結**（だからどうなるか）を書き、Hideさんは**原因**（なぜそうなるか）に
差し替えました。**帰結は読者が自分で想像できます。** 書くべきは原因のほうです。

**「FB」のような現場の略語を使う。** 「フィードバック」と伸ばすと説明口調になります。

### 3. 2文を1文に圧縮する

```
新卒でベンチャーはあんまり勧めない。      →  ベンチャーで働いてるが、
ベンチャーで働いてる側だけど。               新卒ベンチャーは勧めない。

狙うなら "大手なのに実力主義" の会社。   →  狙うなら "大手なのに実力主義" の
リクルートとか外資は、〜                     リクルートとか外資。
```

**逆接の「が」で1文にまとめる。** 修飾は別の文にせず、名詞に直付けする。

### 4. 締めで決め台詞を言い換えない —— **一段上に上げる**

**2本目の修正（クッション言葉の型1）で、締めが丸ごと差し替わりました。**

| | |
|---|---|
| 私の案 | 何を聞くかじゃなくて、なんで聞くのかを言ってなかっただけなんだよな |
| Hideさん | **影響力をもった人は、質問1つでも見え方まで気にするべきと学んだ** |

私の締めは、**上司が直前に言ったことの言い換え**でした。
同じことを二度言うと、**決め台詞のほうが安く見えます。**

Hideさんの締めは**話の対象を広げています。**

```
上司の話 …… 進捗確認の聞き方（マネージャーになりたての自分の話）
締め   …… 影響力をもった人は見え方まで気にするべき（読者全般の話）
```

**実測でも同じでした。**

| imp | 締め |
|---|---|
| 16.9万 | ようやく昇進できるのだと今なら分かる（← 昇進の条件に一般化） |
| 7.0万 | 遠慮より"素直さ"がキャリアを決めるよね（← キャリアに一般化） |

**締めは「今の自分の解釈」ですが、解釈＝要約ではありません。**
エピソードより**一段広い主語**に上げてください。

**「〜と学んだ。」も締めの型です。** 教わる側のポジションが残ります。

### 5. 名詞化して短くする

```
新卒でベンチャー → 新卒ベンチャー
基礎体力       → 基礎
この辺の基礎体力は → などの基礎は     ← 箇条書きを受けるのは「など」
```

**箇条書きを受ける語は「など」。** シグネチャ構文なので「この辺の」にしない。
副詞も削られます（**あきらかに**顔がこわばった → 顔がこわばった／
**勝手に**頼られていく → 頼られる）。

### 6. セリフに「！」を付けて温度を出す

```
「前職では、こうやってました」  →  「前職では、こうやってました！」
```

**得意げなトーンが出て、なぜその人が浮くのかが1行目だけで伝わります。**
セリフは温度が乗ってはじめて場面になります。

### 7. 落としっぱなしにしない —— 一言かばう

| | |
|---|---|
| 私の案 | 中途で入った人からこの一言が出たとき、だいたい半年後に浮いてる |
| Hideさん | （同上）**＋ 前提条件がちがうと、前のやり方が通用しないことは当然ある** |

**Hideさんは、その人を一言かばってから締めています。**
落としっぱなしだと、読者は「見下してるな」と感じて離れます。

### 8. 副詞を削る／1行目を改行しない

```
あきらかに顔がこわばった  →  顔がこわばった

マネージャーになりたての頃、      →  マネージャーになりたての頃、
部下に進捗を聞いただけなのに、〜       部下に進捗を聞いただけなのに顔がこわばった。
```

**2本とも1行目の改行が削られました。** 状況説明は1行に収めてください。

### 9. 「自分」を主語にした語を、悪い側にそろえる（2026-08-16）

型4の全項目を書き直されたときの差です（詳細は `formats.md` の型4の3原則）。

| | 悪い側の書き方 |
|---|---|
| 私の案 | 3日引きずる／固まって止まる／どう思われたかを見る |
| Hideさん | **自分で頑張る／自分が凹むだけ／自分の身を守る** |

**Hideさんは「自分」という語を悪い側に3回置いています。**
私の書き方は状態の描写で、読者は「よくないな」で終わります。
「自分の身を守る」は**動機を名指し**しているので、心当たりのある人に刺さります。

**このアカウントの持論は一貫して「ベクトルが自分に向いている人は伸びない」**です
（型2「一人で乗り越えた」、型1「できひんとこばっかり見てたら」も同じ）。
新しい投稿を書くときも、悪い側は**自分に向いている状態**として書いてください。

### 10. 締めの語尾は「〜だよね。」が既定（2026-08-16）

同じ日、型1の締めも直されました。

```
凹む時間は自分のためで、直す時間は相手のためなんだよな。
　　　　　　↓
凹む時間に意味はなくて、次に繋げるのが仕事なんだよね。
```

**私が「なんだよな」を使いすぎていました。** この規定の上のほうに
「〜よね。47回／〜からね。12回／〜なんだよな。7回」と書いてあるのに、
下書きでは毎回「なんだよな」を選んでいます。**書いたあとに語尾を確認してください。**

307本を月内相対で測り直しても同じでした。

| 語尾 | 本数 | 月内相対中央値 |
|---|---|---|
| **〜よね。** | **76** | **1.05** |
| 〜だよな。 | 12 | 0.80 |
| 〜からね。 | 14 | **0.40** |

**「からね。」は最も弱い**ので、補足で突き放したいとき以外は使わないこと。
（本数が少ないので伸びの差は参考値ですが、**どれがこの人の口癖か**は明確です）

**同時に直された2点**:

- **技巧的な対句をやめる。** 「自分のためで／相手のため」は形が整いすぎです。
  Hideさんは「次に繋げるのが仕事」と**言い切り**に変えました
- **一段広い主語に上げる**（削り方4番と同じ操作）。「相手のため」→「仕事」

### 12. 締めで誰も下げない —— 選択肢を渡す（2026-08-18）

```
私   新卒でリクルートや外資に入った人が有利なのは、
　　 そこが評価されてるというより、最初の値札の位置が違うだけなんだよね。
　　　　　　↓
Hide 逆に新卒でリクルートなどメガベンチャーがお勧めなのは、
　　 成長・安定・給料のバランスが取れてるから。
```

**私の版は誰も得をしません。** ベンチャー出身は損だと言われ、
リクルート出身も「実力じゃない」と言われる。
**Hideさんの版は"お勧めの理由"として書いていて、読者に選択肢が残ります。**

**構造の問題を指摘したら、締めは提案で閉じる。** 批判で閉じない。
「成長・安定・給料」のように**3語で価値を出して、話を一段広げる**のも効いています。

### ★ 削り方7番（一言かばう）の適用範囲

同じ投稿で、私が入れた**かばう一文が削られました**。

```
✕ 新卒でベンチャーに入った人は最初の提示が低い。
　 未経験を育てる前提なので、会社としては当然そうなる。
○ 新卒ベンチャーだと初任給が低いし、給料upもしづらい。
```

**かばうのは"人"を落としたときだけです。**

7番（「前職では」の中途社員をかばう）は人が対象でした。**混同しないこと。**

### ★ 実務を書くときは、強い語を選ばない

```
✕ 中途の年収は前職の額から逆算して決めます
○ 中途の年収は前職の額も参考に決めます
```

**「逆算」だと、年収が前職だけで機械的に決まると言い切る形**になります。
Hideさんは実際の面接官なので、実務の記述が不正確だと信用を削ります
（`formats.md` 型2の「意外で、かつ本当」と同じ話）。
**強い語は主張に使うもので、事実の説明には使いません。**

### ★ 分析的な語より、状態の語

```
✕ 転職しても上がり幅が小さい     ← 分析
○ 転職しても低いまま…           ← 状態
```

**読者が自分を当てはめられるのは状態のほうです。**
（型4で「どう思われたかを見る」→「自分の身を守る」に直されたのと同じ操作）

### ★ 依頼に書かれた要素を落とさない

Hideさんの依頼文には「給与が安く、**給与アップもしにくい**」とありましたが、
私は**初任給の話だけ**にしていました。最終版で「給料upもしづらい」が戻っています。
**連鎖を書くときほど、元の依頼と1段ずつ突き合わせること。**

### 11. 台詞のハードルを、読者が超えられる高さにする（2026-08-16）

```
『同じミスせえへん仕組み、もう作ったんか』  →  『…仕組み、考えたか？』
```

**「作ったか」だと新卒には非現実的**で、読者も自分に置き換えられません。
「考えたか」なら誰でも当てはまります。**説教の高さは、読者が今日できる高さに。**

**「〜だけや」→「〜だけやで」。** 関西弁の語尾に「で」を足すと、
突き放しではなく諭す温度になります（削り方7番と同じ方向）。

**1行目に人物を出す。** 「資料の抜けを指摘されて」→「**上司に**資料の抜けを
指摘され」。次の行の「見かねた上司に」が自然に繋がります。
あわせて「手が止まっていた」→「**手が止まった**」。語尾は短いほうを選ぶ。

**もう1つ、語の温度。** 「1時間で仕切り直す」→「**神の速さで報告**」、
「固まって止まる」→「**思考がフリーズ**」。
正確だが平熱の語を、誇張とカタカナで温度のある語に差し替えています。

## 改行と、折りたたみの使い方

**2026-08-15 に実データで測り直しました。** 以前ここに「1〜2文で改行。
3行以上の塊を作らない」と書いていましたが、**それが原因で文の途中で
改行していました。** 実際は違います。

| | 1行の中央値 | 40字超の行 |
|---|---|---|
| 全208本 | 18字 | 9.3% |
| 上位20本 | **16字** | 3.6% |

**行が短いのは、箇条書きの投稿が多いから**です（項目そのものが短い）。
**散文のパートは2文を1行にまとめています。**

```
[522万の1行目 = 74字・2文]
新卒１年目、ワイの失態により顧客が「上司も連れて謝りにこい！」とブチギレ。
客先への道中で緊張MAXの中、上司は「今後は気をつけろ」と怒るのではなく、
```

**ルールは2つ。**

- **文の途中で改行しない。** 句点で切る。2文を1行にまとめてよい
- **例外は決め台詞の直前だけ。** 読点で切って空行を挟み、決め台詞を独立させる

決め台詞の前後は必ず空行。

### 折りたたみを使う

**決め台詞は折りたたみの下に置きます。** 9月の上位投稿はすべて、箇条書きの
直後の接続行で切れていて、続きは「もっと見る」の中にあります。

```
・議事録は30分以内に送る
・相手の「雑談ネタ」まで残してる
・必ず「次回のアクション」を添える
これだけでも助かるが、とくに驚いたのは、      ← ここで折りたたまれる
```

読者に一手間かけさせるぶん、**詳細クリックというエンゲージメントが稼げます。**
1画面に全部収めようとしないでください。

## 固有名詞の使い方

**学歴を毎回出す。**（慶應卒 / 早稲田卒 / 青学卒）これは引きの装置として
機能しているので外さない。年齢も「（29才）」の形で添える。

会社名・部署名・製品名は出さない。業種と規模だけ（「ベンチャー」「顧客」）。

## 書かないこと

以下は1つでも入ると、この人の投稿に見えなくなります。

- **絵文字**。208本中3本（型7の「👨」など、話者記号としてのみ）
- **ハッシュタグ**。**208本中0本**
- **本文中の外部リンク**。導線は必ず1stリプ
- 「〜ではないでしょうか」「〜と言えるでしょう」— 断定を避ける言い回し
- 「実は衝撃の」「意外にも」— 煽り語。この人は煽らずに事実で引いている

**ただし「立場をはっきりさせる語」は煽り語ではありません。**
「ぬくぬくのJTC」「マジで終わってる」「ポンコツ」のような言い方は、
**スタンスを明示するためのもの**なので使ってよい（2026-08-16・Hideさん）。

```
煽り語（使わない）  … 実は衝撃の / 意外にも / 驚愕の
立場の明示（使う）  … ぬくぬくのJTC / マジで終わってる / ポンコツ
```

違いは**中身があるかどうか**です。煽り語は読ませるためだけに付ける形容で、
立場の明示は**書き手がどちら側に立つかの宣言**です。角を丸めて
「安定した企業」に直すと、この人の投稿ではなくなります。
- 「いかがでしたか」「参考になれば幸いです」
- **疑問形の締め**。この人は同意誘導で終える（`formats.md` 参照）
- **自分ひとりしか登場しない投稿**（4万しか取れていない形です）

無ければ、それは最下位の型に落ちています。書き直してください。
