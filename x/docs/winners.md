## 評価の基準（先に決めておく）

インプレッションで判断しません。目的が転職アフィリへの導線である以上、
本命の指標はこの順です。

1. **プロフクリック率**（profile_clicks / impressions）— 「この人を知りたい」に
   なったかどうか。導線の入口はここ
2. **フォロー増** — 翌日以降も届く母数が増えたか
3. **エンゲージ率** — 会話が起きたか
4. インプレッション — 最後。**バズっても導線に来なければ意味がない**

`x_review.py` が出す「伸びたのにプロフィールに来ていない投稿」は、
この基準で見ると失敗です。数字が大きくても失敗として記録してください。

## 判断を確定させる本数

**1本の結果で型を評価しない。** 同じ型が3本溜まるまでは「観測中」とだけ書きます。
X の配信はばらつきが大きく、1本の当たり外れは運の範囲です。
