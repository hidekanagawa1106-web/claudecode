# 導線（1stリプ）

本文でリーチを取り、**バズを確認してから**1stリプにアフィリリンクを貼る。
リンクを本文に入れるとリーチが30〜50%落ちるうえ、伸びていない投稿にリンクを
足しても意味がないため。

## 実例（2025/11/17・本文333万インプレッション）

本文は型3（人物観察）。慶應卒の営業の議事録が優れている、という内容。
そこに付けた1stリプ:

```
これだけ優秀でも、年収って働く会社で決まるから残酷だよな…
自分が損しないように、まず「自分は本当は年収いくら貰えるか？」を知るには
ミイダスがおすすめ。pr

▼3分で無料診断する▼
twr.mobi/xxxxxx
```

## ⚠ 2026-08-15: 実測が出た（2025-12-01の2本）

公式エクスポートで、導線の数字が初めて取れました（`python x/analytics.py`）。

| | リプimp | URLクリック | **CTR** | プロフクリック |
|---|---|---|---|---|
| 1本目 15:22（ミイダス・**画像つき**） | 202,136 | **210** | **0.104%** | 314 |
| 2本目 20:08（タレントスクエア・同じ親） | 59,412 | 18 | 0.030% | 23 |

**1. 導線リプは1本に絞る。** 2本目はインプレッションが1本目の29%まで落ち、
CTRも3分の1以下。**取れたクリックは18本**です。労力に見合わないうえ、
リプ欄が広告2連になる副作用のほうが大きい。

**2. 画像を付ける。** 効いた1本目には診断結果のスクショが付いていて、
メディアエンゲージメント761（クリック210の3.6倍）。
**画像がリンクの手前の説明を肩代わりしています。** 2本目に画像はありましたが、
本文が「有名企業への転職可能性が【たった2分】で」と**サービス説明から
入っていて**、公式の橋渡し（本文を受けてから渡す）を踏んでいません。

**3. 導線リプはプロフィール流入の本体でもある。** プロフクリックは
オーガニック投稿が1本1〜8なのに対し、この1本で**314**。桁が2つ違います。

**目安は CTR 0.1%。** 20万インプレッションで210クリック。
平常運転（本文1,000〜4,000imp）ではリプ側は数百impで、クリックは0〜1本です。
**導線が意味を持つのは跳ねた投稿だけ** —— 「バズを確認してから貼る」は正しい。

## 橋渡しの公式

上の実例から抽出した構造。**これが1stリプの型です。**

```
1行目: [本文の主役や結論を受ける] + でも + [それは本人の力では決まらない]
       + 「〜だよな…」（本文と同じ独白の語尾で引き継ぐ）
2行目: [読者の損失回避] + 「[具体的な問い]」を知るには [サービス名] がおすすめ。pr
3行目: ▼[所要時間]で[無料]〜する▼
4行目: リンク
```

**効いている理由は3つあります。**

**1. 本文の主役を否定していない。** 「これだけ優秀でも」——優秀さを認めたうえで、
年収を決めるのは**構造**（働く会社）だと言っている。読者も否定していません。

**「あなたは損してる」と煽らないこと。** 不安を煽る形にすると、リプ欄が荒れて
本文の伸びまで殺します。**損しているのは構造のせい**、という置き方を守ってください。

**2. 本文の語尾を引き継いでいる。** 「残酷だよな…」は本文の「〜からね」「〜よね」と
同じ独白のトーン。**リプが広告に見えず、本文の続きとして読まれます。**

**3. 問いの形にしている。** 「自分は本当は年収いくら貰えるか？」——
サービスの説明ではなく、読者の中に問いを作ってから診断に渡している。

## 型ごとの橋

サービスが年収診断系（ミイダス）なので、**すべての橋は「年収は自分の能力では
決まらない」に集約されます。** 型ごとに入口だけ変えます。

| 型 | 橋の入口 | 相性 |
|---|---|---|
| 型3 人物観察 | 「これだけ優秀でも、年収は働く会社で決まる」 | ◎ 実例がこれ |
| 型2 面接官の暴露 | 「落とされる理由が分かっても、自分がいくらで売れるか知らないと交渉できない」 | ◎ 転職文脈が最短 |
| 型1 上司の一言 | 「どんな上司の下につくかは運。年収も同じで自分では決まらない」 | ○ |
| 型5 新人観察 | 「伸びるかどうかは環境次第。環境を選ぶ前に自分の値段を知る」 | ○ |
| 型4 対比リスト | —— | △ 橋が遠い。**無理に架けない** |

**橋が遠い型には貼らないでください。** 唐突な広告リプは、本文の評価を下げます。

## タイミング

**本文と同時に貼らない。** 反応が付き始めてから（目安1〜2時間）追加します。

理由は2つ。伸びなかった投稿にリンクを付けても意味がないこと。そしてリプ欄の
1本目が広告だと、会話が始まらないこと（リプライは評価シグナルとして重い）。

**「バズを確認してから」が判断基準です。** 伸びていない投稿には貼らず、
その日のうちに捨てる判断でかまいません。

**そして1本だけにしてください。** 同じ親に2本目を足しても、実測では
18クリックしか増えませんでした（1本目は210）。

## 担当の切り分け

**リンク・広告表記・ASPまわりはHideさんの担当です。** エージェントが出すのは
橋渡しの文（1〜2行目）までで、表記の要否や書き方には踏み込みません。

## 測ること

導線は2段のファネルです。**どちらが抜けているかで打ち手が変わります。**

```
本文インプレッション → リプに降りた人 → リンクを踏んだ人
          リプ到達率        リプCTR
          └────────── 総合導線率 ──────────┘
```

- **リプ到達率が低い** → 本文とリプの断絶。本文が完結しすぎて、リプ欄を開く理由がない
- **リプCTRが低い** → 橋渡しの文の問題。1行目の受けが弱いか、煽りすぎている
- **総合導線率** → 最終的な導線効率。型の比較はこれで行う

記録するもの:

- `--reply-impressions` … リプ投稿側のアナリティクスのインプレッション
- `--link-clicks` … **ASP管理画面のクリック数が最も正確**。
  短縮リンク側のクリック数でも可。Xのリンククリック数は取りこぼしがあります

`/x-review` がこの3つを集計して、型ごとの総合導線率を出します。

**なお、この3つは公式エクスポートのCSVに全部入っています**（`URLクリック数`）。
毎回スクショを起こさなくても、月に一度エクスポートを `x/data/raw/` に置いて
`python x/analytics.py` を叩けば導線の一覧が出ます。
