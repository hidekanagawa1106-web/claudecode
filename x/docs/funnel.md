# 導線（1stリプ）

本文でリーチを取り、**バズを確認してから**1stリプにアフィリリンクを貼る。
リンクを本文に入れるとリーチが30〜50%落ちるうえ、伸びていない投稿にリンクを
足しても意味がないため。

## 実例（2025/11/17・本文333万インプレッション）

本文は型3（人物観察）。慶應卒の営業の議事録が優れている、という内容。
そこに付けた1stリプ:

```
これだけ優秀でも、年収って働く会社で決まるから残酷だよな…
自分が損しないように、まず「自分は本当は年収いくら貰えるか？」を知るには
ミイダスがおすすめ。pr

▼3分で無料診断する▼
twr.mobi/xxxxxx
```

## ⚠ 2026-08-15: 19ケースぶんの実測が出た

公式エクスポート8ヶ月ぶん（導線リプ99本・**合計5,314クリック**）から、
2段ファネルを復元しました（`python x/analytics.py`、詳細は `winners.md`）。

### リプ到達率は約10%

本文インプレッションの **5〜18%（中央値およそ10%）** が導線リプまで降りてきます。
19ケースで最も安定した数字なので、**見込みはこれで計算できます。**

```
本文 100万 imp → リプ 10万 imp → クリック 100〜400
```

### ⚠ 「型4には貼らない」は誤りでした

このファイルは型4を「橋が遠い。**無理に架けない**」と書いていましたが、
**8ヶ月で最も稼いだ1本が型4です。**

```
09/11【本当に強いのはこういう人】1272万 imp
  → リプ 969,170 imp（到達率7.6%）
  → 2,820クリック（CTR 0.291%）
```

**全期間5,314クリックの53%が、この1本**でした。橋はこう架かっています。

> 実際、性格次第で向いてる仕事や環境は変わるよね。ちなみにミイダスは…

型4のテーマが**性格・メンタル**（完璧主義をやめる）だったので、
**性格診断ツールに一直線でつながった**わけです。

→ **型4に貼らないのではなく、「性格・働き方」テーマの型4に貼る。**
転職テーマの型4は拡散でも導線でも負けます。

**型11（箇条書きリスト）の大型2本について、初めて2段が両方測れました。**

| 本文 | 本文imp | リプimp | **到達率** | クリック | リプCTR | 総合導線率 |

| 新人へ（08/26・型11-命令10項目） | 193万 | **144,542** | **7.49%** | 207 | 0.143% | 0.0107% |
| リーダーになる人へ（09/03・型11-命令11項目） | 126万 | **64,039** | **5.07%** | 89 | 0.139% | 0.0070% |

（リプのプロフィールクリックは 277 / 91。**導線リプがプロフィール流入の本体**という
過去の観測はここでも同じでした）

### 橋渡しの文は悪くありません。穴は到達率です。

2025年の17ケース（1本目のみ・`analytics.py` で再集計）と比べます。

- **リプCTR 中央値 0.095%、上位25%が0.14%以上。**
  今回の 0.143% / 0.139% は**上位25%に入っています。** 文章は直す必要がありません
- **リプ到達率 中央値 11.0%。100万imp超の5本に絞っても中央値 9.18%
  （7.61〜12.04%）。** 今回の 7.49% は下限すれすれ、**5.07% は過去最低水準**です

規模のせいではありません。**到達率と本文impの相関はほぼゼロ**（r=-0.02）で、
1272万impの型4でも7.61%出ています。

**到達率が100万超の中央値9.18%まで戻ったときの計算:**

```
新人へ    144,542 → 177,000（+23%）  クリック 207 → 253
リーダー   64,039 → 116,000（+81%）  クリック  89 → 161
```

### 仮説: 項目が増えるほど到達率が落ちる

型11の3本を項目数で並べると、**きれいに単調です。**

| 型11 | 項目数 | 本文imp | 到達率 |
|---|---|---|---|
| 履歴書に書いてると正直キツイ（2025-09） | 7 | 19.5万 | **11.75%** |
| 新人へ（2026-08） | 10 | 193万 | 7.49% |
| リーダーになる人へ（2026-09） | 11 | 126万 | **5.07%** |

**n=3なので確定ではありません。** ただし説明はつきます。型11は締めが無く、
長いので本文が「さらに表示」で畳まれる。読者は**本文の中で展開して読み切り、
スレッドまで降りない**——つまり `詳細クリック` が本文内で消費されている可能性です。

**これは測れます。** 本文の詳細クリック率は月次エクスポートにだけ入っているので、
**9月のエクスポートを `x/data/raw/` に置けば、この仮説は一度で決着します。**

### タイミングはもう十分です

今回の2本は本文の **4時間10分後 / 1時間59分後** に貼っています。2025年の17本は
どれも4時間以降（中央値およそ6時間）でした。**一番早く貼った1時間59分の回が
一番到達率が低い**ので、これ以上早めても効きません。

### 「リプのimpを伸ばす」の優先順位

リプimp = **本文imp × 到達率** です。実測の振れ幅がまるで違います。

- 本文imp: 7.6万〜1272万（**167倍**）
- 到達率: 5.07〜17.8%（**3.5倍**）

**だから第一に本文をデカくすること。** そこは型11が正解で、
193万・126万はアカウントの上位2本です。ただし**リプimpの過去最高は
969,170（09/11・型4・本文1272万）、次が305,950（11/17・型3・本文333万）** で、
**型11の144,542はまだそこに届いていません。** 型11に寄せきるのではなく、
本文が桁で伸びる回を作りにいくほうが、リプimpへの寄与は大きいです。

第二が到達率の穴で、上の項目数仮説を9月エクスポートで確認してからにします。

## 橋渡しの公式

上の実例から抽出した構造。**これが1stリプの型です。**

```
1行目: [本文の主役や結論を受ける] + でも + [それは本人の力では決まらない]
       + 「〜だよな…」（本文と同じ独白の語尾で引き継ぐ）
2行目: [読者の損失回避] + 「[具体的な問い]」を知るには [サービス名] がおすすめ。pr
3行目: ▼[所要時間]で[無料]〜する▼
4行目: リンク
```

**効いている理由は3つあります。**

**1. 本文の主役を否定していない。** 「これだけ優秀でも」——優秀さを認めたうえで、
年収を決めるのは**構造**（働く会社）だと言っている。読者も否定していません。

**「あなたは損してる」と煽らないこと。** 不安を煽る形にすると、リプ欄が荒れて
本文の伸びまで殺します。**損しているのは構造のせい**、という置き方を守ってください。

**2. 本文の語尾を引き継いでいる。** 「残酷だよな…」は本文の「〜からね」「〜よね」と
同じ独白のトーン。**リプが広告に見えず、本文の続きとして読まれます。**

**3. 問いの形にしている。** 「自分は本当は年収いくら貰えるか？」——
サービスの説明ではなく、読者の中に問いを作ってから診断に渡している。

## 型ごとの橋

サービスが年収診断系（ミイダス）なので、**すべての橋は「年収は自分の能力では
決まらない」に集約されます。** 型ごとに入口だけ変えます。

| 型 | 橋の入口 | 相性 |
|---|---|---|
| 型3 人物観察 | 「これだけ優秀でも、年収は働く会社で決まる」 | ◎ 実例がこれ |
| 型2 面接官の暴露 | 「落とされる理由が分かっても、自分がいくらで売れるか知らないと交渉できない」 | ◎ 転職文脈が最短 |
| 型1 上司の一言 | 「どんな上司の下につくかは運。年収も同じで自分では決まらない」 | ○ |
| 型5 新人観察 | 「伸びるかどうかは環境次第。環境を選ぶ前に自分の値段を知る」 | ○ |
| **型4 対比リスト**（性格・働き方テーマ） | 「性格次第で向いてる仕事や環境は変わる」 | **◎ 実測最高の2,820クリック** |
| 型4 対比リスト（転職テーマ） | —— | △ 拡散でも導線でも負ける |
| ~~型7 会話だけ~~ | — | **廃止（2026-08-31）** |

**橋が遠い型には貼らないでください。** 唐突な広告リプは、本文の評価を下げます。
ただし**型4は「橋が遠い型」ではありませんでした**（上の訂正を参照）。

## タイミング

**本文と同時に貼らない。** 反応が付き始めてから（目安1〜2時間）追加します。

理由は2つ。伸びなかった投稿にリンクを付けても意味がないこと。そしてリプ欄の
1本目が広告だと、会話が始まらないこと（リプライは評価シグナルとして重い）。

**「バズを確認してから」が判断基準です。** 伸びていない投稿には貼らず、
その日のうちに捨てる判断でかまいません。

**そして1本だけにしてください。** 同じ親に2本目を足しても、実測では
18クリックしか増えませんでした（1本目は210）。

## 担当の切り分け

**リンク・広告表記・ASPまわりはHideさんの担当です。** エージェントが出すのは
橋渡しの文（1〜2行目）までで、表記の要否や書き方には踏み込みません。

## 測ること

導線は2段のファネルです。**どちらが抜けているかで打ち手が変わります。**

```
本文インプレッション → リプに降りた人 → リンクを踏んだ人
          リプ到達率        リプCTR
          └────────── 総合導線率 ──────────┘
```

- **リプ到達率が低い** → 本文とリプの断絶。本文が完結しすぎて、リプ欄を開く理由がない
- **リプCTRが低い** → 橋渡しの文の問題。1行目の受けが弱いか、煽りすぎている
- **総合導線率** → 最終的な導線効率。型の比較はこれで行う

記録するもの:

- `--reply-impressions` … リプ投稿側のアナリティクスのインプレッション
- `--link-clicks` … **ASP管理画面のクリック数が最も正確**。
  短縮リンク側のクリック数でも可。Xのリンククリック数は取りこぼしがあります

`/x-review` がこの3つを集計して、型ごとの総合導線率を出します。

**この3つは公式エクスポートのCSVに全部入っています**（`URLクリック数`）。
月に一度エクスポートを `x/data/raw/` に置いて `python x/analytics.py` を
叩けば導線の一覧が出ます。

**日次のAPI取得（`x_metrics.py`）は導線を取りません。** 2026-08-15に、
交流リプが1日50件あり捨てるだけで月$7.5かかると分かったため、返信ごと
除外しました。**導線の測定は月次エクスポートに一本化しています。**
