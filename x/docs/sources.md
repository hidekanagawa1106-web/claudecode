# ネタの調達元

実体験の掘り出しには限界があるので、**素材帳が空でも下書きが作れる**構成にします。
このファイルが `/x-draft` のソース優先順位です。

---

## 型ごとに、どこまで外部ソースで作れるか

型によって性質が違います。**一律に扱わないでください。**

| 型 | 外部ソースから作れるか | 理由 |
|---|---|---|
| 型2 面接官の暴露 | **○** | 「よくNGにするのは」＝ 一般化された観察。特定の日時に紐づかない |
| 型5 新人観察 | **○** | 「いろんな新人を見てきたが」＝ 明示的に総括の形 |
| 型4 対比リスト | **○** | 意見表明。体験を主張していない |
| 型3 人物観察 | **○** | ただし属性が具体的なので、`persona.md` の登場人物と衝突しないこと |
| 型1 上司の一言 | **○（枠の管理が要る）** | 日付つきの一人称主張なので、`persona.md` の年表を1つ消費する |

**型1だけは扱いが違います。** 実測で最強（521万・426万）ですが、
「◯年目に、この状況でこう言われた」という日付つきの主張なので、
書くたびに `persona.md` の年表が1枠埋まります。

**書けないわけではありません。枠を配るだけです。**

- **新卒1〜3年目は飽和**（既存5件）。**ここに新しい出来事を足さない**
- 中堅期・マネージャー期・転職時・現職は**丸ごと空いています**
- **一言の出どころは上司でなくていい。** 部下・顧客・エージェント・候補者・同僚
- 書いたら `persona.md` の「使用済みの枠」に追記する

→ **型1は1日3本のうち1本まで。** 実測で最強なので枠は大事に使います。

## ソースの優先順位

`/x-draft` はこの順で当日の3本を組みます。

### 1. 過去投稿の焼き直し（最優先）

**実測で伸びたテーマを、別の型で出し直す。** 新しいネタを探すより確実です。

- 型1で521万取った「上司が予想外に優しかった」→ 型5「伸びる新人は◯◯」で出し直す
- 型3で333万取った「議事録が会議中に完成」→ 型2「面接で議事録の話を聞くと分かること」

**同じ投稿の再投稿ではありません。** テーマだけ引き継いで、型と切り口を変えます。
`posts.csv` の伸びた行を見て、テーマを抽出してください。

**間隔は最低2ヶ月空ける。** 同じテーマが近い間隔で出ると、フォロワーに気づかれます。

### 2. スワイプ（他アカウントのバズ投稿）

`swipe.csv` から**構造とテーマ**を借ります。

**借りていいもの**: 情報の出す順番、1行目の作り方、切り口、テーマ

**借りてはいけないもの**: 言い回し、比喩、固有のフレーズ、**エピソードそのもの**

他人の体験談を自分の一人称に移すのは避けてください。転職系は業界が狭く、
元ネタの投稿者がフォロワーに混ざっています。**テーマが同じで構造が違う**なら問題ありません。

### 3. 時事・トレンド

`topics.md` の在庫から。**橋が架かるものだけ**使います。詳細は次のセクション。

### 4. 実体験（あれば最強）

`episodes.md` に在庫があれば優先的に使う。ただし**枯れても止まりません**。

## 時事の扱い

### 生のXトレンドはほぼ使えない

実測（2026/08/11）のトレンド上位30語は「打ち上げ成功／山の日／モンスト13周年／
台風15号／東京メトロ半蔵門線」。**このアカウントに橋が架かる語がゼロでした。**

生トレンドに無理に乗せると浮きます。**採用率は1割以下と考えてください。**
例外は、仕事・働き方まわりの炎上や大型ニュース（大企業のリストラ発表、
労働時間の制度変更、著名人の退職エントリなど）。

### 本命は「仕事・キャリア系の時事」

こちらは検索で安定して取れます。`/x-trend` が日次で拾います。

- 賃上げ・ボーナス
- 人手不足・採用難
- 転職市場の動向
- AI と雇用
- 大企業のリストラ・early retirement

### カレンダー要因が一番確実

**予測できるので事前に仕込めます。** 時事より扱いやすい。

| 時期 | 読者の状態 |
|---|---|
| 1月 | 賞与後の転職検討期 |
| 3月 | 期末・退職シーズン |
| 4月 | 新卒入社・異動。新人ネタが最も効く |
| 6月 | 夏賞与。評価への不満が出る |
| **8月（お盆）** | **休みでキャリアを見つめ直す人が増える。9月の転職活況の準備期** |
| 9月 | 下期スタート・転職活動が動く |
| 12月 | 冬賞与・年内の区切り |

### 時事を使うときのルール

**時事は「入口」にだけ使う。** 投稿の中身まで時事にしないこと。
このアカウントの強みは人物観察であって、ニュース解説ではありません。

```
1行目: 時事に触れる（1行だけ）
2行目以降: いつもの型（人物観察・面接官・上司の一言）
```

**断定的な社会批評をしない。** 政治・企業批判に踏み込むと、
アカウントの性格が変わってリプ欄が荒れます。
