# ネタの調達元

実体験の掘り出しには限界があるので、**素材帳が空でも下書きが作れる**構成にします。
このファイルが `/x-draft` のソース優先順位です。

---

## 型ごとに、どこまで外部ソースで作れるか

型によって性質が違います。**一律に扱わないでください。**

| 型 | 外部ソースから作れるか | 理由 |
|---|---|---|
| 型2 面接官の暴露 | **○（リサーチ推奨）** | 想像だと打率が低い（4本中3本却下）。`formats.md` の素材バンク推奨 |
| 型5 新人観察 | **○** | 「いろんな新人を見てきたが」＝ 明示的に総括の形 |
| 型4 対比リスト | **○** | 意見表明。体験を主張していない |
| 型3 人物観察 | **○** | ただし属性が具体的なので、`persona.md` の登場人物と衝突しないこと |
| 型1 上司の一言 | **○** | 新卒期の枠は使い放題。同じ上司が何度話しても構わない |

**型1が実測で最強です**（521万・426万）。新卒1〜3年目のエピソードが
いくつ増えても、同じ上司が何度名言を言っても構いません（Hideさんの判断）。

**唯一の制約は、同じ一言を使い回さないこと。** 決め台詞は読者が覚えています。
既に使った一言は `persona.md` に一覧があります。

一言の出どころは上司に限りません。部下・顧客・エージェント・候補者・同僚も
使えます —— 制約ではなく、**ネタの幅を広げる選択肢**として。

→ **型1に寄せすぎない。** 型を散らさないと、どの型が効くか分からなくなります。
（「1日3本のうち1本まで」という上限は 2026-08-31 に廃止）

## ソースの優先順位

`/x-draft` はこの順で当日の3本を組みます。

### 1. 過去投稿の焼き直し（最優先）

**実測で伸びたテーマを、別の型で出し直す。** 新しいネタを探すより確実です。

- 型1で521万取った「上司が予想外に優しかった」→ 型5「伸びる新人は◯◯」で出し直す
- 型3で333万取った「議事録が会議中に完成」→ 型2「面接で議事録の話を聞くと分かること」

**同じ投稿の再投稿ではありません。** テーマだけ引き継いで、型と切り口を変えます。
`posts.csv` の伸びた行を見て、テーマを抽出してください。

**間隔は気にしません**（2026-08-18・Hideさん「主張が重なることは今後も問題にしなくて良い」）。
同じテーマを別の型で何度出しても構いません。

### 2. スワイプ（他アカウントのバズ投稿）

`swipe.csv` から**構造とテーマ**を借ります。

**借りていいもの**: 情報の出す順番、1行目の作り方、切り口、テーマ

**借りてはいけないもの**: 言い回し、比喩、固有のフレーズ、**エピソードそのもの**

他人の体験談を自分の一人称に移すのは避けてください。転職系は業界が狭く、
元ネタの投稿者がフォロワーに混ざっています。**テーマが同じで構造が違う**なら問題ありません。

### 3. 時事・トレンド

`topics.md` の在庫から。**橋が架かるものだけ**使います。詳細は次のセクション。

### 4. 実体験（あれば最強）

`episodes.md` に在庫があれば優先的に使う。ただし**枯れても止まりません**。

### 5. 自分の投稿に付いたリプライ（2026-08-16 追加）

**Hideさんのnoteより。** 自分のポストに誰かが返してきた内容は、
**そのテーマが読者の中でどう受け取られたかの一次情報**です。

- 「自分の場合は…」と体験を書いてくれたリプは、**次の投稿の素材そのもの**
- 「それは違う」と来たリプは、**そのテーマに2割の反論があった証拠**
  （下の「伸びるテーマの条件」を参照）

**私からは見えません。** Hideさんが拾って渡してくれたぶんだけ使えます。
レビューのときに気になるリプがあれば貼ってください。

### 6. 他SNS（Instagram / TikTok / YouTube）（2026-08-16 追加）

**同じテーマでも、SNSごとに流行の時期がずれます。**
Instagramで流行っているがXではまだ来ていない切り口を先に拾う、という使い方。

**借りるのは切り口だけ**で、スワイプと同じルールです（言い回しとエピソードは借りない）。

## 伸びるテーマの条件（2026-08-16・Hideさんのnoteより）

テーマの良し悪しは、次の3つの掛け算で決まります。

- **「確かに！」と思える発見がある**
- **「それは違う！」と反論も生まれる**
- **「自分の場合は…」と意見を言いたくなる**

**一番伸びるのは、8割が賛同し、2割が反論するポスト。**

**全員が頷くテーマは、伸びないという意味ではなく、"言う必要がなかった"**
ということです。誰も反論しない主張は、読者にとって既知だからです。

### この8:2は、手元のデータでは検証できていません

やってみましたが、**測れませんでした**。理由を書いておきます。

反論の量に一番近い指標は返信数ですが、返信÷いいねで4分割すると
**返信比が低い群ほど圧倒的に伸びています**（月内相対 8.58 / 1.24 / 0.80 / 0.47）。
これは「反論されないほうが伸びる」ではなく、**伸びた投稿ではいいねが
返信よりはるかに速く増える**ための見かけの相関です（上位20本の返信/いいね比は
0.011、全体は0.088）。**分母が結果に引きずられるので、この比では判定できません。**

**判定できることが1つだけあります。返信数そのものを目的にしないこと。**
返信が多い群は実際に伸びていないので、「反論を狙う」を「絡まれにいく」と
取り違えると逆効果です。**狙うのは"意見を言いたくなる"であって、"反発"ではありません。**

引用リポストの被リポスト数が測れるようになれば検証できます（`x_metrics.py`）。

## 時事の扱い

### 生のXトレンドはほぼ使えない

実測（2026/08/11）のトレンド上位30語は「打ち上げ成功／山の日／モンスト13周年／
台風15号／東京メトロ半蔵門線」。**このアカウントに橋が架かる語がゼロでした。**

生トレンドに無理に乗せると浮きます。**採用率は1割以下と考えてください。**
例外は、仕事・働き方まわりの炎上や大型ニュース（大企業のリストラ発表、
労働時間の制度変更、著名人の退職エントリなど）。

### 本命は「仕事・キャリア系の時事」

こちらは検索で安定して取れます。`/x-trend` が日次で拾います。

- 賃上げ・ボーナス
- 人手不足・採用難
- 転職市場の動向
- AI と雇用
- 大企業のリストラ・early retirement

### カレンダー要因が一番確実

**予測できるので事前に仕込めます。** 時事より扱いやすい。

| 時期 | 読者の状態 |
|---|---|
| 1月 | 賞与後の転職検討期 |
| 3月 | 期末・退職シーズン |
| 4月 | 新卒入社・異動。新人ネタが最も効く |
| 6月 | 夏賞与。評価への不満が出る |
| **8月（お盆）** | **休みでキャリアを見つめ直す人が増える。9月の転職活況の準備期** |
| 9月 | 下期スタート・転職活動が動く |
| 12月 | 冬賞与・年内の区切り |

### 時事を使うときのルール

**時事は「入口」にだけ使う。** 投稿の中身まで時事にしないこと。
このアカウントの強みは人物観察であって、ニュース解説ではありません。

```
1行目: 時事に触れる（1行だけ）
2行目以降: いつもの型（人物観察・面接官・上司の一言）
```

**断定的な社会批評をしない。** 政治・企業批判に踏み込むと、
アカウントの性格が変わってリプ欄が荒れます。
