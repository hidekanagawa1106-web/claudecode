# 設定資料

投稿の骨格になる設定。**細かい整合性は追いません**（Hideさんの判断）。

- 新卒1〜3年目のエピソードは**いくつ増えても構いません**
- 同じ上司が何度も名言を言う形も**構いません**
- 「まとめ読みしたときの違和感」は**気にしません**

このファイルが見ているのは、**その2段階上の矛盾**だけです。
アカウントの信用の土台そのものが崩れる種類のもの。

---

## 動かせない骨格

ここが崩れると、投稿の説得力の出どころ自体が消えます。**ここだけは守ります。**

- **元リクルートのマネージャー**
- **現在はベンチャーで面接官をしている**（採用に関わる立場）。
  **ただし新卒採用はしていない —— 中途のみ。**
  「うちを受けにくる学生」のような書き方は成立しません
- 2025年8月時点で**社会人10年** → 2015年前後の新卒入社
- 新卒時は**顧客を持つ職種**（1年目に顧客対応の失態がある）

書いてはいけないのは、たとえばこういうものです。

- 「ずっと同じ会社にいる」（転職している）
- 「採用には関わっていない」（面接官をしている）
- 「新卒で内勤だった」（1年目に顧客がいる）
- **「うちの新卒が」「学生の面接で」（現職は中途採用のみ）**

**それ以外の細部は自由に足して構いません。**

## 特定リスク（整合性とは別の話）

一貫性を捨てても、これは残ります。**実害が出る種類のものだからです。**

- **リクルートだけは例外。2026-08-13にプロフィールで過去の所属として公開**し、
  「今後はリクルートの生情報もお届けします」と宣言済み。**制度の話は書けます**
  （`content.md` のテーマM）
- **それ以外の会社名・部署名・製品名・個人名は出さない。** 業種と規模だけ。
  現職のベンチャーは特定されないように
- 学歴と年齢は出してよい（引きの装置として実際に機能しています）
- 具体的な売上・表彰歴など、検証されうる固有の数字は出さない
