# 内容の素材帳 —— ねこすけさんが実際に言っていること

**2025年5〜12月の全投稿（自発208本）から抽出。** 推測はありません。
`/x-draft` は型を選んだあと、**必ずここから中身を取ってください。**

型（`formats.md`）が「どう書くか」なら、こちらは「**何について書くか**」です。
型が合っていても中身がこの人の関心から外れていると、別人の投稿になります。

```
・議事録は30分以内に送る        ・相手の「雑談ネタ」まで残してる

・学びは他の人が活かせるように記載  ・Slackの返信が最速

・雑談ではしっかり相槌          ・困ってそうな人にDMでフォロー

・率先して飲み会の幹事          ・誰かを待たせるタスクは即対応
・質問への回答は必ず「ありがとうございます」から
・挨拶の声がデカい             ・ゴミを積極的に拾う
```

### H. Z世代とAI（12月の主テーマ）

- 会議で意見を求められると即AIを開く

### I. 転職の失敗パターン（**導線に一番近い**）

- リモートが良い／給料が高ければ良い／仕事内容はなんでも良い／有名企業ならどこでも
- 上司の正解を探してる／転職を知ったかぶり／昇進したらゴールだと思ってる
- ワーホリでキャリアアップはしない（月50万稼げても後に残らない）
- 「転職エージェント経験者から言わせてもらうが、」で始める形が定番

### J. 言葉づかいから人を読む

- ポンコツの口癖「〜の認識です」「〜のはずです」「たぶん〜です」（5.0万）
- 「前職では」を言いがち
- 「どんな仕事がありますか？」と聞いてしまう

## 決め台詞のつくり方 —— **中に対比か言い換えを入れる**

伸びた決め台詞は、**ほぼ全部が引用符つきの言葉を2つ含むか、逆接になっています。**

```
「"お前を使うと楽になる"と俺に思わせてくれ」        16.9万
「"質問の数"と"成長の速さ"は比例するぞ」            7.0万
「"自分がいないと回らない状態" のうちは半人前だな」    3.4万
「"配慮"はできるけど、"遠慮"はしない」              2.4万
「"上司に怒られたくない"で動くな。"顧客に喜ばれたい"で動け」 1.1万
「"人に時間を借りる力"が、出世のスピードを決める」     2.5万
```

**単なる格言にしない。** 2つの言葉を並べて差をつけるか、否定と肯定を並べる。
ダブルクォート `"〜"` で語を囲むのがこの人の書き癖です。

### ただし、最大の1本は教訓ですらありませんでした

```
「いい歳したオッサンが本気で怒る様子なんて滅多に見れへんで。楽しみやな。」   522万
```

顧客にブチギレされて謝りに行く道中で、上司が言ったのはこれだけです。
**何も教えていません。関西弁で、笑わせているだけ。**

**教えると説教になり、笑わせると引用されます。** 決め台詞に迷ったら、
「この上司は教えているか、和ませているか」で見直してください。

## 締めのパターン

```
今なら分かる。 / 今も覚えてる。 / これに尽きる。

つべこべ言わずやれ。                    ← 突き放す形もある

```

## 使ってはいけないもの

- **他人の実名・社名。** 「大手の人事」「東大→外資コンサルの同僚」まで
- **自分の武勇伝。** 208本に1本もありません。自分は失敗する側か教わる側
- **数字の盛りすぎ。** 「15分黙り込む」で1本つぶしています
- **既に使った決め台詞の再利用**（`persona.md` の既出リスト）
