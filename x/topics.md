# 時事ネタの在庫

`/x-trend` が追記し、`/x-draft` が使います。**賞味期限が切れたものは消してください。**

## 使い方

時事は**入口にだけ**使います。1行目で触れて、2行目以降はいつもの型に戻る。
中身までニュース解説にすると、このアカウントの強み（人物観察）が消えます。

書式:

```
### T001 [見出し]
- 事実: （数字と出典があるもの。推測を混ぜない）
- 出典:
- 橋の入口: （どう1行目に置くか）
- 相性の良い型:
- 賞味期限:
- 使用: 未使用
```
