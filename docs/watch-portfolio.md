# ウォッチ・ポートフォリオ（15銘柄）

毎朝74銘柄をスクリーニングする `morning.py` とは別に、**あらかじめ決めた15銘柄を
毎日そのまま報告する**形式。銘柄が日替わりで入れ替わらないので、値動きの癖が身につく。

方針は 2026-08-04 に一度切り替えた。

| | 旧方針 | 現方針 |
|---|---|---|
| 選び方 | 値動きが重ならないように散らす | 売買代金が集まっている場所に居る |
| 半導体の扱い | 1枠（フジクラ）だけ | フジクラ＋3枠 |
| 根拠 | 相関の最小化 | 東証プライム売買代金上位40のうち19銘柄が半導体・AI関連 |

切り替えの理由は、**市場の売買代金の半分近くが集まっている場所に、旧15銘柄では
2つ（フジクラ・パナソニックHD）しか反応していなかった**こと。分散としては正しくても、
相場が半導体主導で動く日にウォッチ対象が静かになる。

## 2026-08-05 の入れ替え: 任天堂 → 安川電機

任天堂は毎朝の枠として機能していなかった。200営業日で測った2つの数字が
どちらも15銘柄中で最下位だった。

| | 順張りの土俵に乗る日 | 日経225内での最大相関 |
|---|---|---|
| 7974 任天堂 | **4%** | **0.43** |
| （次に低い） | 日本郵船 28% | 良品計画 0.42 |
| 15銘柄の中央値 | 44% | 0.70 |

順張り成立率4%は、**200営業日のうち192日はレポートに載っても何もできない**という意味。
連動相関0.43は §3-1 条件4「連動銘柄が同方向に動いているか」が判定できない水準。

差し替え先は日経225から次の条件で絞った（`tools/slot_candidates.py`）。

    売買代金        150億円/日 以上   毎朝見る枠としての厚み
    連動先の最大相関   0.55 以上        §3-1 条件4 が成立すること
    残す13銘柄との相関  0.60 未満        既存の枠と重複しないこと

## なぜこの3銘柄なのか

半導体・AI関連は一枚岩ではなく、さらに5つの塊に割れている。塊の中どうしは
0.69〜0.81でほとんど同じ動きをするので、**塊ごとに1枠まで**とした。

| 塊 | 中身 | この15銘柄での担当 |
|---|---|---|
| 電線・データセンター | フジクラ / 古河電工 / 住友電工 | **フジクラ**（固定枠） |
| 前工程装置 | 東エレク / SCREEN / KOKUSAI | **KOKUSAI** |
| 検査・後工程装置 | アドバンテスト / ディスコ / レーザーテック | なし |
| 電子部品・基板 | 村田 / 太陽誘電 / TDK / イビデン | **村田製作所** |
| AI投資 | ソフトバンクG | **ソフトバンクG** |
| 材料・シリコン | 信越化学 / SUMCO / レゾナック | なし |

- **KOKUSAI (6525)** — 前工程装置枠。東エレクは売買代金3,076億で最大だが1単元555万円。
  KOKUSAIは782億／77.8万円で、装置クラスタの値動きはほぼ同じ（東エレクとの相関0.75）
- **ソフトバンクG (9984)** — 2,924億。半導体との連動0.51だが、動く理由が投資先評価なので
  装置・部品とは別枠として成立する
- **村田製作所 (6981)** — 2,638億。太陽誘電（2,867億）の方が代金は多いが1単元99.2万円、
  ATR13.7%。村田は74.2万円／11.1%で、両者の相関は0.81でほぼ同じ動き

## 検討して見送った案

| 案 | 装置枠 | 平均相関 | 最大 | ATR% | 合計代金 | 総額 |
|---|---|---|---|---|---|---|
| A 代金最大 | アドバンテスト | 0.171 | 0.56 | 5.00 | 16,466億 | 1,015万 |
| **B（採用）** | **KOKUSAI** | **0.162** | **0.56** | **5.22** | **14,387億** | **768万** |
| C 装置を厚く | 東京エレクトロン | 0.170 | 0.61 | 5.04 | 16,681億 | 1,245万 |
| D 素材を混ぜる | アドバンテスト＋信越化学 | 0.174 | 0.53 | 4.62 | 14,427億 | 999万 |

Bを採ったのは、Aに対して**合計売買代金は13%減るだけで、総額が247万円安く済む**ため。
アドバンテストは1単元325万円で、他の銘柄（30〜80万円）の4〜10倍になる。
100株が最小単位である以上これは避けられず、1銘柄が全体のリスクを支配する。

資金が制約でないなら A の方が方針に忠実。装置枠を差し替えるだけで移行できる。

## いま押さえておくべきこと

**2026-07-31時点で、15銘柄のうちハードフィルタ（終値>MA25 かつ MA25が20日前より上）を
通るのは9銘柄。** 通らない6銘柄は以下。

```
× 5803 フジクラ      MA25から -15.3%
× 6981 村田製作所     MA25から -18.1%
× 6525 ＫＯＫＵＳＡＩ   MA25から -17.9%
× 9984 ソフトバンクＧ   MA25から  -9.1%
× 7011 三菱重工業     MA25から  -1.1%（MA25の傾きは上向き）
× 8058 三菱商事      終値はMA25の上だが傾きが下向き
```

追加した半導体3銘柄はいずれも現在MA25を割っている。半導体・AI関連の60日騰落は
フジクラ−35.8%、古河−32.1%、JX金属−29.0%、信越化学−24.8%と、
**テーマ全体が調整局面にある**。

売買代金が集まる場所に寄せるという判断は、いま調整しているテーマに寄せるということ。
順張り条件が揃うまでウォッチだけが続く可能性がある。これは方針を選んだ結果であって
不具合ではない。

## 前提

- 「材料の裏付け」は自動判定していない。決算・ニュース・材料面は個別に確認すること
- ここに並ぶのは「ウォッチする候補」であり、実際のエントリーは場中に順張り4条件
  （ORB・VWAP・出来高・連動銘柄）を満たすかで別途判断する
- 相関・ATR・売買代金は204営業日の実測。ニューストピックによる連動は含まない
