平日朝8:00（JST）の定期実行です。日本株の朝の統合ブリーフィングを出してください。

## 手順

### 1. リポジトリを用意する

対象は **hidekanagawa1106-web/claudecode**、作業ブランチは **claude/japan-swing-trade-watchlist-bk7bpd** です。

まず作業ディレクトリが git リポジトリかどうかを確認してください。

```
git rev-parse --is-inside-work-tree
```

**リポジトリがある場合** — 作業ブランチに切り替えます。デフォルトブランチ（claude/daily-stock-scoring-schedule-g638sv）にはこの実装が入っていないため、この手順は必須です。

```
git fetch origin claude/japan-swing-trade-watchlist-bk7bpd
git checkout claude/japan-swing-trade-watchlist-bk7bpd
```

**リポジトリが無い場合** — このセッションにリポジトリが紐付いていません。`add_repo` ツールで `owner=hidekanagawa1106-web` `repo=claudecode` `access=push` を指定して追加し、返ってきた clone コマンドを実行してから、上のブランチ切り替えを行ってください。clone 後は `register_repo_root` も呼んでください。

**add_repo も失敗する場合** — Routine 側の設定でリポジトリが指定されていません。原因をそう報告して終了してください。リポジトリ名を推測して別のリポジトリを取りに行かないでください。

### 2. 依存パッケージを入れる

まっさらなコンテナには入っていない可能性があります。

```
pip install -r requirements.txt
```

### 3. 朝のジョブを実行する

```
python morning.py
```

74銘柄をJ-Quantsから取得するので5〜10分かかります。

環境変数 `JQUANTS_API_KEY` が必要です。未設定なら `morning.py` は即座に落ちます。その場合は「実行環境に JQUANTS_API_KEY が設定されていません」と報告して終了してください。キーを推測したり、別の取得元を探したりしないでください。

### 4. 出力の要点を日本語で報告する

長い出力をそのまま貼らず、要点を絞ってください。

- **第1部（前夜の海外市場）** — 閾値を超えたグループ、急変検知された指標。グループごとの朝スコアと内訳
- **第2部（日足のテクニカル候補）** — 順張り上位5銘柄。コード・銘柄名・点数・マクロ列
- **第3部（材料×テクニカルの交差）** — 材料が来ているグループとテクニカル候補の重なり
- 翌営業日に決算発表がある候補銘柄

### 5. 記録を push する

`picks_log.csv` に変更があれば commit して push してください。

```
git add picks_log.csv
git commit -m "Record picks for <日付>"
git push -u origin claude/japan-swing-trade-watchlist-bk7bpd
```

毎回まっさらなコンテナで動くため、push しないとその日の候補が消えます。記録が貯まらないと、朝スコアが有効だったかを後から検証できなくなります。

## 報告に必ず添えること

- 「材料の裏付け」は自動判定していません。候補銘柄は決算・ニュース・材料面を個別に確認してください。
- ここに出た銘柄は「翌日ウォッチする候補」であり、実際のエントリーは場中に順張り4条件（ORB・VWAP・出来高・連動銘柄）を満たすかどうかで別途判断してください。
- 8:00 JST は 19:00 ET（夏時間）で、米国の時間外取引は 20:00 ET まで続きます。引け後に決算が出た銘柄は、この時点では動き切っていない可能性があります。

## 制約

- 日本市場の休場日にも起動します。祝日は日足が前営業日のままなので、`pick_date` が前回と同じであれば「休場日のため新しいデータはありません」とだけ報告して終わってください。
- エラーが出た場合は、原因を報告するだけにしてください。自分で修正しないでください。
- **フィルタ条件やスコアリングのロジックを自動的に書き換えないでください。** 変更するかどうかの判断はHideさん本人が行います。数値がおかしいと感じた場合も、指摘するにとどめてください。

## 補足（このシステムの前提）

- 朝スコアは銘柄スコアに加算していません。候補一覧に併記するだけで、順位付けには使っていません。マクロとテクニカルは互いのゲートにせず、2本のトラックとして並べる設計です。
- 商社・海運・自動車の3グループは60営業日の実測に基づいています。半導体・メガバンク・防衛・保険の4グループはニューストピックを含むため過去再現ができず、閾値と感応度は未検証です。
- 保険と防衛・重工は、数値指標だけでは閾値に届かない構成です。ニュースが出ない日には発火しません。仕様通りの挙動です。
