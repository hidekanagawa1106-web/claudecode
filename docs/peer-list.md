# 連動確認用の参考銘柄（2026-08-05 時点）

運用方針_v2 §3-1 条件4「連動銘柄が同方向に動いているか」を場中に確認するための一覧。
証券アプリのお気に入りに入れておき、買う直前に目で確かめる用途で、**売買対象ではない**。

測り方は日経225全銘柄・299営業日の日次リターン相関。売買代金は20日平均で
80億円/日以上に絞った。相関が高くても薄商いの銘柄は、確認したい瞬間に板が見えない。

再生成は `python tools/peer_finder.py`。銘柄を入れ替えたら回し直す。

## 信頼度は3段階に分かれる

| | 銘柄 | 使い方 |
|---|---|---|
| 強（0.7以上） | 三菱UFJ・日本郵船・トヨタ・三菱重工・KOKUSAI・村田・フジクラ・富士通・三菱商事・安川電機 | §3-1 条件4 の判定に使える |
| 中（0.5〜0.7） | 東京海上・KDDI・パナHD・SBG | 参考程度。逆行していたら見送る材料 |
| 弱（0.5未満） | **良品計画** | 連動確認は機能しない |

**良品計画（最高0.42）は条件4を実質的に満たせない。**
残り3条件（ORB・VWAP・出来高1.5倍）で判断する前提で見る。

任天堂（最高0.43）も同じ状態だったが、2026-08-05 に安川電機と入れ替えた
（経緯は docs/watch-portfolio.md）。安川電機はファナックとの 0.76 で条件4が使える。

## 読むときの注意

- 相関は**日足**で測っている。場中の分足での連動は別物なので、使いながら
  「本当に一緒に動くか」を確かめる必要がある。数字は出発点でしかない
- **ソフトバンクGの連動先に同業（通信）が1つも入らなかった。** イビデン・ディスコ・
  村田といった半導体関連が並ぶ。SBGは通信株ではなく半導体・AI関連として動いている、
  という以前の実測がここでも裏付けられた
- 日本郵船の4位以下（三井物産 .41、INPEX .38、武田 .37）は連動とは呼べない。
  海運3社（9107・9104）だけで見る
- `driver_map.yaml` の「連動確認」に指定済みの銘柄とはおおむね一致した
  （商社→8031 三井物産、海運→9104 商船三井）
