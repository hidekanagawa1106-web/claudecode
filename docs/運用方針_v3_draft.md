# 運用方針 v3（ドラフト）

2026-08-06 起草。v2 を、実測にもとづいて書き直したもの。**確定前のドラフト。**

## このドラフトの読み方

v2 の条文のうち、**検証で否定側の結果が出たものを外し、支持されたものを具体化した**。
根拠となる数値は `verify/README.md` と各スクリプトにある。

**重要な非対称がある。** 「外す」判断には複数の独立したデータによる証拠があるが、
「代わりに据える」条件の側には確証がない。最良の組み合わせでも n=214・22営業日で、
95%信頼区間はゼロをかろうじて外れる程度だった。したがってこの v3 は
**「効かないと分かったものを減らした v2」であって、「効くと分かったものを積んだ新方針」ではない。**

条件を減らす方向の変更は、間違っていても失うのは機会だけで済む。そこを判断の軸にした。

### v2 から変えた点

| 項目 | v2 | v3 | 根拠の強さ |
|---|---|---|---|
| 順張り | 4条件すべて必須 | 必須2つ＋参考3つ | 強 |
| 出来高1.5倍 | 必須条件 | 参考（多いほど良いとは扱わない） | 強 |
| VWAP上 | 必須条件 | 参考（条件1と重複） | 強 |
| 日足MA25の上 | 条件になし | **必須** | 中 |
| 時間帯 | 規定なし | 14:00以降の新規を見送り | 中 |
| 禁止事項 | 7項目 | 1項目＋参考1項目 | 下記 |
| RSI 70超で買わない | 禁止事項 | **撤回**（参考表示に降格） | 最も強い |
| 逆張り | 場中の分足で判定 | **日足に限定** | 中 |
| 損切り | 一律 -4% | 日足ATR(14)の1.5〜2倍 | 強 |
| 持ち越し | 明示なし | **持ち越し前提と明記** | 強 |

## §0 大前提

- **本ルールは投資助言ではない。最終判断は自己責任。**
- エントリー直後に逆指値・指値で発注し、**あとから動かさない**。
- ポジションサイズは損切り幅から逆算する。ただし持ち越す以上、
  **想定すべきは損切り幅ではなく最悪のギャップ**（§5）。
- 条件が揃わなければ何もしない。**条件を甘く読むことがいちばんの害になる。**

## §1 対象銘柄と連動確認

（v2 から変更なし。`driver_map.yaml` の連動グループを使う）

連動銘柄の同方向確認は、5分足での実測では情報を持たなかった
（過半がプラスのとき素の60分後 -0.031%、マイナスのとき -0.064%、勝率50.6% 対 48.6%）。
**判定条件からは外すが、銘柄選定の枠組みとしては残す。**

## §2 イベントフィルタ（スコアより優先）

（v2 から変更なし）

- 決算発表の当日・翌日 → ポジション半分以下、または見送り
- FOMC・日銀会合の当日 → 寄り付き直後は入らない
- 決算・会合をまたぐ持ち越しはしない

**この項目は一度も検証していない。** 検証がないことを理由に外さない。
値動きの優位を主張するものではなく、想定外の損失を避けるための規律であり、
独立に正当化できる。

## §3 エントリー

### §3-1 順張り

**必須（2つとも満たすこと）**

1. **オープニングレンジ（9:00〜9:15）の高値を明確に上抜けている**
2. **前日終値時点の日足MA25より上にある**

**参考（見るが、欠けても見送りにはしない）**

- VWAPより上か — 条件1を満たす場面ではほぼ同時に成立し、独立した情報がない
- 場中の出来高倍率 — **多いほど良いとは扱わない**（下記）
- 連動銘柄の方向 — §1のとおり情報を持たなかった

**見送る条件（いずれかに当たれば入らない）**

- **14:00以降の新規エントリー**
- **ORB高値から+1%以上離れている**

**根拠**

条件を重ねるほど成績が落ちた（15銘柄・22営業日・5分足）。

| | 勝率 | 超過60分 |
|---|---|---|
| 条件1のみ | 53.4% | +0.037% |
| 条件1+2 | 53.5% | +0.039% |
| 条件1+2+3（出来高） | 45.3% | -0.085% |
| 4条件すべて | **35.5%** | **-0.333%**（CIがゼロを外れる） |

出来高スパイクは方向を持たない。買いが集まる瞬間と、利確の売りが出る瞬間の
区別がつかない。同じ理由で大陽線・大きな足も直後の成績が悪かった
（実体+0.3%超で -0.099%、直近20本比2.5倍超の足で -0.102%）。

日足MA25の上下では、RSI70以上の中で勝率 59.2% 対 52.5% に分かれた。
時間帯は前提条件下で符号が反転する（9時台 +0.336% / 12〜13時台 -0.068%）。
ORB高値からの乖離は、1〜2%で -0.022%、2%超で -0.063% と離れるほど悪い。

### §3-2 逆張り — **日足の判断に限る**

順張りが揃わない日の補完。**場中の分足では使わない。**

| 条件 | 判定 |
|---|---|
| 1. 日足RSI(14) が 30以下 | |
| 2. 日足MA25が下向きで、そこから大きく下方乖離（-10%以下） | |

**根拠**

時間軸で符号が反転した。

| | 日足5年 | 5分足1ヶ月 |
|---|---|---|
| RSI30以下 | **+0.64%** [+0.12, +1.13] | **-0.209%** [-0.392, -0.020] |
| 下降MAから大幅下方乖離 | **+0.61%**（10日 +1.38%） | **-0.938%**（勝率32.4%） |

**日単位では「行き過ぎからの反発」でも、分単位では落下の途中**でしかない。
v2 は §3-2 を「場中に見る条件」と定めていたが、その場中が最も不利だった。

v2 のボリンジャー -2σ タッチ・出来高急増・反発の陽線1本確定は、
5分足で単独に測るとそれぞれ -0.089% / -0.020% / +0.042% で、
反発の陽線以外は情報を持たなかった。**反発の陽線は保留**（RSI70以上に足すと
+0.162% → +0.289% と改善したが n=84 で確証がない）。

## §4 禁止事項

**禁止（1項目）**

1. **下降トレンドの途中で買う** — 日足MA25が下向きで、かつその下にある状態

**参考（禁止ではない。記録して後で検証する）**

- **RSIの水準** — 高いほど順行しやすい。低い状態での順張りに注意する

### RSI 70超えの禁止を撤回した理由

**3つの独立したデータセットで、すべて否定側だった。**

| 検証 | データ | 結果 |
|---|---|---|
| 74銘柄・日足5年 | Yahoo | RSI70超 超過5日 +0.22% |
| 15銘柄・日足5年 | J-Quants | RSI70超 超過5日 +0.30%（5年すべてプラス） |
| 15銘柄・5分足1ヶ月 | Yahoo | RSI70以上 勝率57.2% |

5分足でRSIを7区分に切ると**単調増加**する。

| RSI | 超過60分 | 勝率 |
|---|---|---|
| 〜30 | -0.206% | 45.4% |
| 30〜40 | -0.076% | 46.8% |
| 40〜50 | -0.012% | 48.9% |
| 50〜60 | +0.045% | 53.1% |
| 60〜70 | +0.047% | 53.4% |
| 70〜80 | +0.088% | 54.7% |
| 80〜 | **+0.357%** | **63.8%** |

閾値の当てはめではなく水準そのものが効いている。計算式（ワイルダー平滑／単純平均）と
期間（9／14）の4通りすべてで同じ向きだった。**RSIは買われすぎ警告ではなく、
トレンドの強さの連続量として働いている。**

**段階を踏む。** まず自動ブロッカーから参考表示に降格し、`trade-review` の実取引が
20件ほど溜まってから条文を確定する。

### v2 から削除した禁止事項と、その行き先

| v2 の項目 | 削除理由と行き先 |
|---|---|
| 寄り付き直後の急騰・急落に飛びつく | §3-1 の条件1が9:15の確定を待つ設計なので実質的に内包される |
| 急騰銘柄を後から追いかける | §3-1 の見送り条件「ORB高値から+1%以上」に具体化。日足では乖離が大きいほど成績が良く（MA25から+10%以上で +0.37%）、一般則としては支持されなかった |
| 1日に複数銘柄へ次々と手を出す | 機械判定できない規律。§6 の記録で拾う |
| トレンドラインだけを根拠に買う | 同上 |
| エントリー後に理由を後付けする | 同上 |

**削除は「やってよい」という意味ではない。** ルールとして判定する対象から外し、
振り返りで見る対象に移した。

## §5 決済

### 損切り

**日足ATR(14)の1.5〜2倍**で決める。v2 の一律 -4% は使わない。

**根拠**: 10日以内にどちらへ先に届くかを測ると、**損切りが利確の1.5倍の頻度**で当たった。

| | +7%到達 | -4%到達 |
|---|---|---|
| 母集団 | 23.2% | 36.0% |
| 25日高値ブレイク＋出来高 | 24.1% | 38.0% |
| 20日騰落率上位10% | 27.6% | 38.1% |

-4% は日本株の日足ボラティリティに対して近すぎる。v2 §5 にも
「値動きの大きさに応じて幅を変える」とあり、思想の変更ではなく具体化にあたる。

### 利確

現値から**最も近い上値抵抗**（日足MA25・MA75、直近高値、節目）までの距離を出し、
損切り幅と比べる。

- 「最も近い抵抗までの距離 < 損切り幅」なら、リスクリワードが悪い位置と扱う
- 利確目標が抵抗の向こう側にあるなら「抵抗突破が前提」と明記する

### 持ち越しを前提とする

**リターンの発生場所は取引時間外にある。**

| | オーバーナイト（引け→翌寄り） | 日中（寄り→引け） |
|---|---|---|
| 母集団 | **+0.102%/日** | +0.018%/日 |
| 20日騰落率上位10% | **+0.139%/日** | +0.060%/日 |

同じシグナルでもデイトレ版（翌日寄り→同日引け）にすると、超過が
+0.382% → +0.041% まで落ちた。§5 がスイング基準である以上、入口も持ち越し前提で書く。

### ギャップリスクをサイズに織り込む

持ち越す以上、逆指値では止まらない。

- モメンタム銘柄の翌日ギャップは標準偏差 2.01%、下位5%が -2.74%
- **-4%を超える下ギャップが 2.17% の頻度**で発生、最悪 -23.0%

**ポジションサイズは損切り幅ではなく、想定される最悪ギャップから逆算する。**

## §6 記録（`trade-review`）

ルールの有効性を後から測れるよう、エントリー時点の以下を `trades.csv` に残す。

- 日足RSI(14) と 5分足RSI(14)
- 日足MA5・MA25からの乖離率
- エントリー時刻（前場／後場）
- ORB高値からの乖離率
- 参考条件（VWAP・出来高・連動）の充足状況
- **§4から削除した規律の該当状況** — その日すでに何銘柄目か、根拠は何だったか、
  理由を後から付けていないか

**これが無いと、この v3 が正しかったかを後から判定できない。**
実運用の記録は、22営業日のバックテストより価値が高い唯一のデータである。

## §7 検証の履歴と、その限界

検証スクリプトは `verify/` にある。数値の出どころはすべてそこで再現できる。

### 測り方の約束

- 判定は当該足の終値まで、約定は次の足の寄り
- **超過リターンで比べる**（素のリターンだと右肩上がりの局面では何でもプラスに見える）
- 95%信頼区間は日付クラスタのブートストラップ
- 年別・銘柄別の符号も見る

### 限界

- 5分足は Yahoo の1ヶ月ぶんしか遡れない。**すべての場中の検証が同じ22営業日を見ている**
- **Yahoo の5分足は86%の日で15:20で切れる。** 大引けと板寄せが無く、最終バーが正規の
  終値と一致したのは 327件中36件（11%）、差は平均 0.275%
- **画面のRSIとスクリプトのRSIは一致しない。** 楽天の分足RSI（短期9・長期14）と
  期間を揃えても合わない。**閾値を運用ルールにするなら画面の値を基準に決める**
- 日足5年の検証は現在のウォッチリスト銘柄で行っており、生存バイアスがある
- 効果の大きさは概ね 0.1〜0.3%。**往復の売買コストでほぼ消える水準**
- 30項目以上を比較している。95%信頼区間がゼロを外れるものが偶然1〜2個出る
