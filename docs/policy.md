## 0. 大前提

- 積立投資（オルカン等）とは完全に別枠。失っても生活に影響しない資金のみを使う。
- 判断に迷ったら「やらない」。取引しないことは損失ではない。
- 損切り・利確は**エントリー直後に逆指値・指値で発注**し、あとから動かさない。
- 本ルールは投資助言ではない。最終判断は自己責任。

## 1. 売買対象

**限定しない。**日経225の範囲で、§2 の朝の判定と §3 の場中条件を満たすものを対象にする。

v2 にあった3枠（キオクシア・三菱UFJ・IHI）と、連動確認用銘柄の売買禁止は撤廃した。
「連動確認用」は §3-1 条件4（連動銘柄が同方向か）の**判断材料としての役割は残る**が、
その銘柄自体を売買してはいけないという制約はない。

### 残す注意

- 大型株（三菱UFJ、トヨタ等）は1日の値幅が±1〜2%しかない。**デイトレでは値幅が取れないため、
  原則スイングで扱う。**デイトレする場合の損切り・利確は §5 の「大型株のデイトレ」区分。

### 連動の参照先

`driver_map.yaml` の各グループに、連動確認に使う指標と銘柄が定義されている。
グループは `universe.csv` の `group` 列（半導体・AI関連 / メガバンク / 防衛・重工 /
自動車 / 保険 / 商社 ほか）。

## 2. 毎朝の判定（8:00 の `morning.py`）

**グループ別のマクロスコアを正式な判定とする。**v2 の枠A/B/C別の項目表は、対象銘柄を
限定しなくなったため廃止した。

- 定義は `driver_map.yaml` の `グループ` 配下。各グループに指標と**閾値**が定義されている
- 各指標を **+1 / 0 / -1** で採点し、合計が閾値以上なら「そのグループに追い風」と判定する
- 出力は `morning.py`。候補は `picks_log.csv` に `macro_score` / `macro_threshold` 付きで残る

**閾値以上のグループに属する銘柄だけ、場中に §3 の条件を探す。閾値未達なら何もしない。**

### この判定の信頼度（必ず割り引くこと）

`driver_map.yaml` 冒頭に記載のとおり、**商社以外の5グループは閾値・感応度が未検証**である。
実測で組み直したのはグループ別の相関までで、閾値そのものの妥当性は確認できていない。
スコアが閾値を1〜2点上回った程度では、有意な差とみなさない。

### 個別に優先する条件

- 米関税のネガティブニュースがある日は、スコアに関わらず**防衛・重工グループは見送り**

### イベントフィルタ（スコアより優先）

- 決算発表の当日・翌日 → ポジションを通常の半分以下、または見送り
- FOMC・日銀会合の当日 → 寄り付き直後は入らない
- 決算・会合をまたぐ持ち越しはしない

## 3. エントリー条件

**朝のスコアが立った日だけ、場中に以下を確認する。揃わなければ何もしない。**

### 3-1. 順張り（4条件すべて必須）

1. **オープニングレンジブレイク** — 9:00〜9:15の高値・安値を記録し、その高値を明確に上抜けていること
2. **VWAP** — 価格がVWAPより上にあること（デイトレではVWAPが主。日足MAは補助）
3. **出来高** — 直近の出来高が当日平均の1.5倍以上
4. **連動銘柄** — 同セクターの銘柄が同方向に動いていること

補足:

- **1日1銘柄につき、最初の1シグナルのみ。2回目以降は見送る**
- 寄り付き直後15分は観察のみ。飛びつかない
- 条件が揃った足が**確定してから**発注する

### 3-2. 逆張り（4条件すべて必須）

順張りが揃わない日の補完。トレンドに逆らうため順張りより厳格に。

1. **ボリンジャーバンド ±2σタッチ**、またはスクイーズ後の拡大開始
2. **RSI 30以下**（短期・長期とも）
3. **出来高急増**
4. **反発の陽線が1本確定**していること。以下をすべて満たすこと:
   - 実体が、直前の下落を主導した陰線の**70%以上**
   - 出来高が、直前の下落局面と**同水準以上**
   - 上ヒゲが実体の**30%以下**（高値圏で引けている）

加点材料（必須ではないが信頼度が上がる）:

- **強気ダイバージェンス**: 価格は新安値を更新しているのに、RSIは前の安値ほど下がっていない

NG:

- 反発してもすぐ上にMAがある（MAより下の場合は含み損を抱えている人が多く、MAに戻ると
  売却してノーポジに戻したい勢がいるため、MAが上値になりやすい）

## 4. やってはいけないこと（明示的な禁止事項）

実際の失敗から抽出した、繰り返しやすいミス。

1. **下降トレンドの途中で買う**（価格がMAの下、MAが下向き）
2. **RSI 70超えで新規に買う**（買われすぎからの飛びつき）
3. **寄り付き直後の急騰・急落に飛びつく**（上ヒゲ・下ヒゲで振り落とされる）
4. **1日に複数銘柄へ次々と手を出す**（テーマに乗って衝動的に広げる）
5. **トレンドラインだけを根拠に買う**（ラインは水準の目安。反発4条件とセットで使う）
6. **エントリー後に理由を後付けする**（買う前に条件を確認する）
7. **急騰銘柄を後から追いかける**（初動を逃したら見送る）

## 5. 損切り・利確

**銘柄の値動きの大きさに応じて幅を変える。ここを一律にすると機能しない。**

| 対象 | 損切り | 利確 |
|---|---|---|
| 高ボラ銘柄のデイトレ（キオクシア、フジクラ等） | -2〜3% | +3〜5% |
| 大型株のデイトレ（三菱UFJ、トヨタ等） | -0.6% | +0.9%前後 |
| スイング | -4% | +7% |
| 逆張りエントリー | -1.5% | 順張りに準じる |

高ボラか大型株かは、`entry_check.py` が出す**直近14日の日中値幅の実測**で判断する
（目安: 平均5%超なら高ボラ、2%前後なら大型株）。

- ORBを使う場合、損切りはオープニングレンジの反対側（レンジ中間、またはレンジ幅基準）に置く
- ポジションサイズは損切り幅から逆算する

## 6. 手仕舞い

### デイトレ

**利確・損切りラインの到達有無に関わらず、例外なくその日のうちに手仕舞う。**

- 14:30 含み損益を確認、方針を決める
- 14:45 含み益なら成行で利確。含み損なら縮小を検討
- 14:50までにポジションをゼロにする

「大幅な上昇だから特別に持ち越す」という例外は設けない。大引け時点では「大幅かどうか」を
判定できず、事後的な結果論になるため。

### スイング

以下のいずれかに該当したら、翌営業日の寄り付きで手仕舞う。

- **日足終値がMA25を明確に割った**（メインの手仕舞い基準）
- 日銀会合・決算の前営業日になった
- 前提が崩れた（銀行株ならハト派報道、防衛・重工なら米関税ネガティブ報道など、
  その銘柄をエントリーした根拠が否定されたとき）

**保有日数の上限は設けない。** トレンドが続く限り持つ。実際、日足でMA25を割らずに数週間で
+20%以上伸びた例がある。日数で切ると大きな値幅を取り逃す。

## 7. スイングの新規銘柄を選ぶとき

「すでに上がった銘柄」ではなく「これから上がる初動」を探す。

```
[1] 日足で価格がMA25を上抜けた（または上抜け直後）か？
[2] MA25が横ばい〜上向きに転じているか？
[3] 上昇に材料の裏付けがあるか？（金利・為替・受注・政策など）
[4] 初動で出来高が増えているか？
[5] RSIがまだ70未満で、過熱していないか？
      ↓
  全部YES → エントリー候補
  1つでもNO → 見送り（特に[5]がNGなら「もう遅い」）
```

```

反省：ルール通りだったか。外れていたならどの条件を飛ばしたか
```

月次で集計し、以下を確認する:

- 勝率と平均損益
- 「条件が揃っていた取引」と「揃っていなかった取引」の成績差
- **銘柄ごとの成績差**

売買対象を限定しないため、銘柄ごとの件数は分散する。**母数が少ないうちは順位を読まない。**

## 9. 資金の増やし方

1. 最低20〜30取引を、資金量を固定したまま消化する
2. 判定基準: 取引20回以上／勝率65%以上／累計プラス／ドローダウンが損切りルールの範囲内
3. 基準をクリアしたら、1.5倍ずつ段階的に増やす
4. 基準を割ったら、ひとつ前の資金量に戻す

## 10. 用語メモ

- **VWAP**: 出来高加重平均価格。その日の実質的な平均取得コスト。上にいれば買い方優勢
- **オープニングレンジ**: 寄り付き後15分の高値・安値。その日の基準線として使う
- **押し目**: 上昇トレンド途中の一時的な下げ。VWAP・MA25の上で止まれば健全、割れたらトレンド転換
- **上ヒゲ**: 高値で売られて押し戻された跡。長い上ヒゲは買いの勢いが跳ね返されたサイン
- **RSI**: 一定期間の値上がり幅と値下がり幅の比率。70以上=買われすぎ、30以下=売られすぎ
- **ダイバージェンス**: 価格とRSIの食い違い。価格は新安値なのにRSIが切り上がっていれば、
  売りの勢いが弱まっているサイン
- **タカ派/ハト派**: 引き締め寄り/緩和寄り。銀行株にはタカ派がプラス、ハト派がマイナス
