## 0. 大前提

- 積立投資（オルカン等）とは完全に別枠。失っても生活に影響しない資金のみを使う。
- 判断に迷ったら「やらない」。取引しないことは損失ではない。
- 損切り・利確は**エントリー直後に逆指値・指値で発注**し、あとから動かさない。
- **逆指値はギャップを守らない。** 1321 の寄りギャップは平均0.80%、4%以上が1.3%の日で発生する。
  損切りが -4% でも、寄りで飛べば実際の損失はそれより大きくなる。**「-4%が最大損失」ではない。**
- 本ルールは投資助言ではない。最終判断は自己責任。

## 1. 売買対象

**1321（NEXT FUNDS 日経225連動型上場投信）のみ。現物のみ。**

- 1日あたり売買代金は中央値100億円。数口〜数十口の売買で流動性の問題は起きない。
- 単価が大きい（2026-08-07終値 67,960円）ため、口数の丸めでリスク量が設計値からずれる。
  §5 の計算例を参照。**売買単位は発注前に証券会社の画面で確認する。**

### 禁止する対象

| 対象 | 理由 |
|---|---|
| **1570（日経レバ）** | §9 の基準をクリアするまで禁止。詳細は下記 |
| **個別株** | 当面停止。再開の条件は §9 |
| **信用取引・先物・オプション** | 使わない |

### 1570 を当面使わない理由

**1570 を資金の50%持つことと、1321 を100%持つことは、指数エクスポージャーとしては同じ賭けである。**
商品を選んでいるのではなくポジションサイズを選んでいる。v3 §9 は「資金量を固定したまま
20〜30取引を消化してから増やす」と定めており、実績が無い段階で 1570 を選ぶのは**その手順を
飛ばして初日から2倍にする**行為にあたる。

実測（2021-08-10〜2026-08-07、1223営業日）:

| | 1321 | 1570 |
|---|---|---|
| 日次リターン σ | 1.42% | **2.85%** |
| ATR14 | 1.62% | **3.23%** |
| 寄りギャップ ≧4% の日 | 1.3% | **6.4%** |
| 1日の最大下落 | -8.3% | **-20.9%（2024-08-05）** |
| 3営業日の最大下落 | — | **-33.7%** |
| 買い持ちの最大ドローダウン | -25.0% | **-48.5%** |

**なお「レバレッジ減価」は当初考えていたほどの脅威ではない。**1570 の実リターンと 2×1321 の差を
実測すると、10営業日保有で中央値 -0.09%、20営業日で -0.21% しかない（実効レバレッジは
日次回帰で 1.992 と極めて正確）。減価が効いてくるのは60営業日以上のレンジ保有からで、
**スイングの時間軸で警戒すべきはギャップと日次ノイズであって、減価ではない。**

### 同時保有

**建てられるポジションは常に1つだけ。** 1321 を保有中に買い増ししない。

## 2. 相場環境の判定（レジームフィルタ）

**新規建ての必要条件は1つだけ。**

> **26週移動平均線（日足の130営業日移動平均、MA130）が上向きであること。**
> 判定: MA130 の値が10営業日前より高い。

MA130 が下向き、または横ばいの期間は**「買い禁止（静観）」**とする。1321 を持たない。

### マクロスコアは使わない

v3 §2 のグループ別マクロスコアは個別銘柄のセクター判定用であり、`driver_map.yaml` に
指数全体を対象とするグループは定義されていない。**検証されていないスコアを新規に作って
判断根拠にはしない。**日経の実質的なドライバー（ドル円・米国株・米金利）は朝の材料として
目に入れるが、点数化して条件には使わない。

### この判定の信頼度（必ず割り引くこと）

検証期間（2021-08〜2026-08）は MA130 が上向きの営業日が **70%** を占め、1321 は +138% 上昇した。
**サンプルの中に持続的な下降相場がほとんど無い。**したがってこのフィルタが下げ相場で効くかは
**この5年のデータでは検証できていない。**採用理由は実測の優位性ではなく、
「トレンドが下を向いている局面で新規に買わない」という §4-1 との一貫性である。

### イベントフィルタ（レジーム判定より優先）

指数ETFに個別決算は無いが、代わりにマクロイベントが効く。

**新規建てをしない日:**

- 日銀金融政策決定会合・FOMC の**当日および前営業日**
- SQ（メジャーSQ・マイナーSQ）**当日**
- 米雇用統計・米CPI の**発表を受けた翌営業日の寄り付き**（ギャップに飛びつかない）

**保有中にイベントをまたぐのは許容する。**日銀・FOMC・CPI・雇用統計を合計すると年40回を超え、
すべてを避けるとスイングが成立しない。またぐリスクは §5 のポジションサイズで吸収する。
ただし**会合をまたぐと分かっている日は、その晩に総資金の3%程度を失う可能性があることを
事前に確認してから寝る。**

## 3. エントリー条件

### 3-0. 判断のタイミング（これが v4 の中核）

**判定は引け後に日足で行い、発注は翌営業日の寄り付き成行。場中に判断しない。**

- 条件を確認するのは **15:30以降**。日足が確定してから。
- 条件が揃ったら、その場で翌朝の**寄り成行の買い注文**を出しておく。
- 翌朝、約定したら**即座に逆指値と指値を出す**（§0）。
- **場中はチャートを見ない。** 見て入るのも、見て降りるのもしない。

`trades.csv` の9取引のうち、寄り付き15分以内の飛びつきが2件、直近の急騰を追いかけたものが
1件、62秒後の買い直しが1件。**いずれも場中に画面を見ていたから起きた。**ザラ場の裁量を
ルールから取り除くことが、この方針でいちばん効く部分である。

### 3-1. パターンA — MA25 の上抜け

以下を**すべて**満たした日の引け後に、翌朝の寄り成行を発注する。

1. **MA130（26週線）が上向き**（§2）
2. **当日終値が MA25 を上抜けた**（前日終値 ≤ MA25 かつ 当日終値 > MA25）
3. **MA25 が上向き**（5営業日前より高い）
4. **RSI14 が 70 未満**
5. 直近5営業日以内に同じシグナルが出ていない

### 3-2. パターンB — MA25 の上での押し目反発

上昇トレンドが続いている途中の、浅い押し目を拾う。

1. **MA130（26週線）が上向き**（§2）
2. **MA25 が上向き**
3. **当日終値が MA25 より上**
4. **当日安値が MA25 の 1% 以内まで押した**（安値 ≤ MA25 × 1.01）
5. **陽線で返した**（終値 > 始値）
6. **RSI14 が 70 未満**
7. 直近5営業日以内に同じシグナルが出ていない

### 採用しなかった条件と、その理由

**26週線まで押したところを買う「深い押し目買い」は採用しない。**当初案の中心だった条件だが、
検証すると 1321 で41回中 勝率27%・平均 -0.74%、1570 でも同様に負けた。原因ははっきりしていて、
**26週線まで下げた時点で価格は MA25 の下にいる**（41回中20回、49%）。§6 の手仕舞い条件
「終値が MA25 を下回ったら降りる」が、**買った瞬間に成立している。**エントリー条件と
手仕舞い条件が論理的に矛盾していた。

**13週線ブレイク後の押し目**も同じ理由で不採用（1570 で37回・平均 -0.45%）。

**ただしこれは「押し目買いが駄目」という意味ではない。**出口を「MA25に戻ったら利確」に
組み替えれば矛盾は消え、そちらのほうが v4 の順張りより成績が良い。**この方針が順張りの
まま残っているのは、長期データでは押し目買いも機能しなかったからである。**経緯は §11-5。

## 4. やってはいけないこと（明示的な禁止事項）

実際の失敗から抽出した、繰り返しやすいミス。**v4 の読み替えを併記する。**

1. **下降トレンドの途中で買う** — MA130 が下向きの期間は §2 で新規建て禁止
2. **RSI 70超えで新規に買う** — §3 の条件に含む
3. **寄り付き直後の急騰・急落に飛びつく** — §3-0 により、そもそも場中に発注しない
4. **1日に複数のポジションへ手を出す** — 同時保有は常に1つ（§1）
5. **トレンドラインだけを根拠に買う** — §3 の条件を満たさないものは買わない
6. **エントリー後に理由を後付けする** — 判定は引け後、記録は §8 のフォーマットで
7. **急騰銘柄を後から追いかける** — RSI 70 以上、または MA25 から大きく離れた位置では入らない

### v4 で追加する禁止事項

8. **場中に損切り・利確の注文を動かす。** 出した逆指値・指値には触らない。
9. **シグナルが出ていない日に「そろそろ来そうだから」と先回りする。**
10. **手仕舞った銘柄をその日のうちに買い直す。** 次のシグナルまで待つ。

## 5. 損切り・利確・ポジションサイズ

**順序を守る。①損切り幅を決める → ②リスク予算で口数を出す → ③利確を置く。**
サイズを先に決めてはいけない。

### ① 損切り幅

> **ATR14 × 2.5。ただし下限 3.0%、上限 6.0% でクリップする。**

1321 の ATR14 は平均 1.62%（5〜95%パーセンタイルで 1.00〜2.96%）なので、実際の損切り幅は
おおむね **-3.0% 〜 -6.0%**、平均で **-3.7%** 前後になる。`entry_check.py` が出す実測 ATR を使う。

固定%ではなく ATR 基準にするのは、**同じ -4% でも凪の相場では遠く、荒れた相場では近い**ため。
ただし検証上、損切り幅を ATR×1.5〜4.0 の範囲で動かしても成績はほとんど変わらなかった
（平均損益の差 0.03pt 以内）。**実際に発動するのは全体の1割程度で、大半は §6 の手仕舞いが先に来る。
損切りは主たる出口ではなく、災害用の保険である。**細かく詰める価値は無い。

### ② ポジションサイズ

> **建玉金額 = （総資金 × 1.5%）÷ 損切り幅**
> **ただし総資金の 50% を上限とする。**

1回の取引で失う額を総資金の1.5%に固定する。口数は切り捨て。

計算例（1口 67,960円、2026-08-07終値）:

| 総資金 | 損切り幅 | 建玉の目安 | 実際の口数 | 建玉額（資金比） | 実リスク |
|---|---|---|---|---|---|
| 50万円 | -3% | 250,000円 | 3口 | 203,880円（40.8%） | 6,116円（1.22%） |
| 50万円 | -4% | 187,500円 | 2口 | 135,920円（27.2%） | 5,437円（1.09%） |
| 50万円 | -6% | 125,000円 | 1口 | 67,960円（13.6%） | 4,078円（0.82%） |
| 100万円 | -4% | 375,000円 | 5口 | 339,800円（34.0%） | 13,592円（1.36%） |
| 300万円 | -4% | 1,125,000円 | 16口 | 1,087,360円（36.2%） | 43,494円（1.45%） |

**資金が小さいほど丸めの影響が大きい**（50万円・-6% では実リスクが 0.82% まで落ちる）。
リスクが設計値を**上回る**方向には丸めない。切り捨てを守る。

### ③ 利確

> **+7%（指値）。**

エントリー直後に指値を置き、あとから動かさない。+10% の方が検証成績は良かったが
（1取引 +1.17% vs +0.74%）、26件のサンプルで選んだ差であり、v3 からの継続性を優先して +7% とする。

**浅くしてはいけない。**利確を +2.5% 以下にすると、勝率は上がるが売買コスト込みでマイナスになる。
負けの大きさは利確幅で変わらないため、ペイオフレシオだけが潰れるからである（§11-3）。

## 6. 手仕舞い

**デイトレは行わない。**v3 §6 のデイトレ手仕舞い（14:50までにゼロ）は v4 では該当なし。

### スイング

以下のいずれかに該当したら、**翌営業日の寄り付きで手仕舞う。**

1. **日足終値が MA25 を 1% 以上下回った**（終値 < MA25 × 0.99）— メインの手仕舞い基準
2. **保有が30営業日に達した** — 安全弁。実際にはほとんど発動しない
3. **前提が崩れた** — MA130 が下向きに転じた場合

### なぜ MA25 に 1% の緩衝を入れるか

v3 の「終値が MA25 を割ったら」をそのまま使うと、**§3 のエントリーが MA25 のすぐ上なので、
建てた直後の小さな揺れで手仕舞いが成立してしまう。**検証では40回中29回が MA25割れで終了し、
その大半が3営業日以内の小さな負けだった。

1% の緩衝を入れると、MA25割れによる終了は 29回 → 21回に減り、1取引あたりの平均損益は
**+0.60% → +1.55%** に改善した。緩衝2%だとさらに良かった（+1.81%）が、
**40件のサンプルで大きい方を選ぶのは過剰適合なので、保守側の1%を採る。**

## 7. エントリー前チェックリスト

引け後、`entry_check.py` の出力を見ながら上から順に確認する。

```
[1] MA130（26週線）は上向きか？                        → NOなら終わり（§2）
[2] 明日は日銀・FOMC・SQ か、その前営業日か？          → YESなら終わり（§2）
[3] §3-1（MA25上抜け）か §3-2（MA25上での押し目）か？  → どちらでもなければ終わり
[4] RSI14 は 70 未満か？                               → NOなら終わり（§4-2）
[5] いまポジションを持っていないか？                   → 持っていれば終わり（§1）
      ↓
[6] ATR14 × 2.5（3〜6%でクリップ）で損切り幅を出す
[7] （総資金 × 1.5%）÷ 損切り幅 で建玉金額 → 口数は切り捨て
[8] 翌朝の寄り成行を発注
[9] 約定したら即、逆指値（損切り）と指値（+7%）を発注
      ↓
    以降、場中は見ない。引け後に §6 の手仕舞い条件だけ確認する。
```

**[1]〜[5] のどれか1つでもNOなら、その日は何もしない。**

## 8. 記録（毎回残す）

```
日付 / 1321 / スイング
エントリー根拠（パターンA か B か。MA130・MA25・RSI の値）
イベント確認（当日と翌日に日銀・FOMC・SQ が無かったこと）
損切り幅の計算（ATR14 の実測値 → ×2.5 → クリップ後）
ポジションサイズの計算（総資金 → リスク1.5% → 建玉 → 口数）
エントリー価格 / 決済価格 / 決済理由 / 損益
反省：ルール通りだったか。外れていたならどの条件を飛ばしたか
```

月次で集計し、以下を確認する:

- 勝率・平均損益・**ペイオフレシオ**（勝ちトレード平均 ÷ 負けトレード平均の絶対値）
- 「条件が揃っていた取引」と「揃っていなかった取引」の成績差
- **決済理由の内訳**（MA25割れ／利確／損切り／30日上限）— どの出口が支配的か
- **場中に注文を動かした回数**（§4-8。ゼロであるべき）

対象が1銘柄になったため、v3 §8 の「銘柄ごとの成績差」は該当なし。

## 9. 資金の増やし方と、1570 への昇格

### 判定基準（v3 から校正し直した）

v3 は「勝率65%以上」を条件にしていたが、**これはこの戦略のペイオフレシオに対して過大**である。
損切り -4% / 利確 +7% なら損益分岐勝率は 4/(4+7) = **36.4%** にすぎない。65% を要求すると、
十分に儲かっている状態でも基準未達になり、永久に昇格できない。

> **判定基準（すべて満たすこと）**
> 1. **v4 で20取引以上**を、資金量を固定したまま消化した
> 2. **平均損益がプラス**
> 3. **勝率 35% 以上**
> 4. **最大ドローダウンが総資金の -10% 以内**
> 5. **§4-8（注文を動かさない）と §3-0（場中に判断しない）の違反がゼロ**

条件5を入れるのは、v4 が測ろうとしているのが収益性ではなく**執行の再現性**だからである。
ルールを破って勝った期間は、基準を満たしたことにしない。

### 到達までの時間

条文どおりに回すと、§3 のシグナルは **年5.8回**（4.4年で26取引）。**20取引には3年半かかる。**
これは短縮できない。回数を増やそうとして条件を緩めれば、測りたかったものが測れなくなる。

さらに §2 のイベントフィルタ（日銀・FOMC・SQ）は検証に入っていないので、**年5.8回は上限**である。

### クリアしたら

1. まず **1321 のまま、リスク予算を 1.5% → 2.0%** に上げる。さらに20取引。
2. それもクリアしたら、**1570 を検討してよい。** ただし移行時は
   **リスク予算を 1.5% に戻し、損切り幅は 1570 の ATR（平均3.23%）× 2.5 = 約8%** で計算し直す。
   建玉は総資金の 18% 程度になる。**「1570 を50%」は、どの段階でも採らない。**
3. 個別株の再開も同じ扱い。1321 で20取引の実績を作ってから、v3 §7 の形で少額から。
4. 基準を割ったら、ひとつ前の段階に戻す。

## 10. 用語メモ

- **MA25 / MA130**: 25日・130営業日（≒26週）移動平均。v4 では MA130 が相場環境の判定、
  MA25 がエントリーと手仕舞いの基準
- **ATR（Average True Range）**: 直近14日の「1日に動く幅」の平均。ギャップも含む。
  同じ -4% でも、ATR が小さい凪の相場では遠く、荒れた相場では近い
- **レジームフィルタ**: 「そもそも買ってよい相場か」を先に決める条件。v4 では MA130 の向き
- **リスク予算**: 1回の取引で失ってよい金額。v4 では総資金の1.5%。ここから口数を逆算する
- **ペイオフレシオ**: 勝ちトレードの平均利益 ÷ 負けトレードの平均損失。3.0 なら
  勝率25%で損益がトントン
- **損益分岐勝率**: 損切り幅 ÷（損切り幅 + 利確幅）。これを超える勝率なら期待値はプラス
- **レバレッジ減価**: レバレッジETFが上下動の繰り返しで元指数の倍数から下方に乖離する現象。
  1570 の実測では10営業日で -0.09%、60営業日で -0.78%。短期では小さい
- **RSI**: 一定期間の値上がり幅と値下がり幅の比率。70以上=買われすぎ、30以下=売られすぎ

### 11-4. マクロ（金利・為替・先物・VIX）

**① 夜間の材料は、寄り値に完全に織り込まれている。**

| 指標（前夜の変化） | 翌朝ギャップとのIC | 寄り後20日のIC |
|---|---|---|
| S&P500 | +0.665 | -0.021 |
| SOX指数 | +0.639 | +0.002 |
| CME日経先物 | +0.597 | -0.068 |
| 先物プレミアム（前日大引け比） | **+0.719** | -0.065 |
| VIX | -0.557 | +0.027 |

前半・後半で数字がほとんど変わらない、頑健な関係である。
**「米国株が上がった／先物が高いから買う」は構造的に無意味。**その情報は寄り値に
全額入っている。先物を見る価値は「明日いくらで寄るか」を知ることであって、
「買うべきか」ではない。

**② 金利・VIX の効き方は局面で反転する。**

| 指標 | 全期間IC | 前半 | 後半 |
|---|---|---|---|
| 米5年債利回りの水準 | -0.100 | **-0.298 (t-7.3)** | **+0.108 (t+2.5)** |
| 米10年債利回りの水準 | -0.074 | **-0.262 (t-6.3)** | **+0.139 (t+3.2)** |
| VIXの20日変化 | +0.077 | **+0.267 (t+6.4)** | **-0.092 (t-2.1)** |

全期間で回すと |t|>3 が21個出る（偶然なら0.3個）が、**前半で強烈に効いた指標ほど
後半で符号が反転する。**過去データからマクロのルールを作ると、必ず前の局面に
最適化される。

**③ 両期間を生き延びたのは「ドル安（円高）方向がプラス」だけ**（ドル円5日変化 IC -0.122、
ドル指数水準 IC -0.116。実質は同じ1因子）。それでスコアを組んでも、年率は
買い持ちの +28.9% に対して +11.1% にしかならなかった。

### 11-5. 押し目買い（逆張り）への転換

**v4 は順張りだが、測定された市場の性質は逆張り方向だった。**
38銘柄のモメンタムIC平均は -0.098（＝上がったものは下がる）。
1321 で MA25 からの乖離別に見ると:

| 買う位置 | 20日後リターン | 勝率 |
|---|---|---|
| MA25 -4%より下 | **+6.23%** | **92%** |
| -1〜0% | +1.38% | 63% |
| +4%より上 | +1.40% | 62% |

そこで押し目買い（MA25から-4%下で買い、**MA25に戻ったら利確**）を組んだ。
**出口を MA25割れにしてはいけない。**MA25 より下で買う設計なので、建てた瞬間に
手仕舞い条件が成立する（41回中20回でそうなった）。これが最初に
「26週線の押し目」を捨てた原因で、押し目買いそのものの否定ではなかった。

**5年（2021-2026）では良く見える:** 勝率72%、1取引+1.35%、超過α +0.84%。
**この一連の検証で唯一プラスの超過αが出た設計である。**

**しかし日経57年（1970-2026）で回すと消える。**

| | フィルタなし | 26週線フィルタあり |
|---|---|---|
| 取引 | 222回 | 88回 |
| 勝率 | 62% | 59% |
| 1取引あたり | **+0.17%** | **-0.19%** |
| 資金ドローダウン | -60.7% | -43.5% |

| 年代 | 1取引あたり | 日経の10年変化 |
|---|---|---|

| **2020年代** | **+1.27%** | +189% |

**2021-2026 は57年で最良の期間だった。**そこでパラメータを決めていた。

11市場の全期間（32〜56年）でも同じ: 勝率65%、1取引+0.47%、年率+0.96%、

そして 2021年8月の前後で割ると、10市場すべてで後のほうが良い（平均 +0.34% → +1.33%）。

**意外だった点:** 押し目買いは弱気相場のほうが成績が良い（1年高値から-20%超で

という懸念は外れ、26週線フィルタはむしろ成績を下げる。**
ただし最悪の1取引は -16.1%、最大連敗5回。

### 11-6. レバレッジ商品（1570 / SOXL）

**1570（日経2倍）:** 実効レバレッジは日次回帰で 1.992 と正確。減価は10営業日で
中央値 -0.09%、60営業日で -0.78% と**短期では小さい**。警戒すべきは減価ではなく、
日次σ 2.85%・寄りギャップ4%以上が6.4%の日・**2024-08-05 の -20.9%**（3日で -33.7%）。
損切りの35%は逆指値を飛び越えて寄りで約定し、平均 -5.63%・最悪 -12.77% になった。

**SOXL（半導体3倍）:** 2010年3月設定。2010-2026 は年率+38.9%だが、最大DD -90.5%、
最悪の1日 -38.6%、日次σ 5.77%（年率92%）。減価も1年保有で中央値 -15.5% と大きい。

**^SOX に日次3倍を合成して1994年から回すと:**

| | 年率（32年） | 最大DD | 2000-2003の底までの下落 |
|---|---|---|---|
| 1倍 | **+15.5%** | -87.1% | -83.9% |
| 2倍 | +14.7% | -99.8% | -99.2% |
| **3倍** | **-0.8%** | **-100.0%** | **-100.0%** |

**3倍の半導体ETFはドットコム崩壊で消滅していた。**SOXL に壊滅イベントが
入っていないのは、その後に設定された商品だからである。

そしてレバレッジを上げると長期リターンが落ちる。最適レバレッジの目安は μ/σ² で、
年率15%・σ38% の資産なら**約1倍**。3倍は完全に行き過ぎている。

唯一の例外は **MA200 の上にいるときだけ持つ**設計で、3倍が -0.8% → +20.7% になった
（レバレッジ商品では破綻を避けること自体が価値になる）。ただし DD -98.8%。

### 11-7. 結論

**日足のタイミングで指数を売買して超過リターンを取る設計は、この枠組みでは成立しなかった。**

- エントリー、出口、マクロ、商品、順張り／逆張り — 主要なダイヤルはすべて回した
- どの組み合わせでも年率1〜3%のレンジに収まり、買い持ちに届かない
- 何度も現れた構造は「**1取引の質を上げると参加率が下がり、総額は増えない**」

**まだ検証していない領域は「銘柄間の相対（クロスセクション）」**である。
「今どれが強いか／割安か」は今回のすべてと別の統計で、学術的にも実務的にも
再現性が高いとされる。ただし常時複数銘柄を持つ設計になり、§4-4 と `trades.csv` の
失敗パターンに正面から衝突する。**やるなら §11 と同じ手順で先に検証すること**
（無条件との差を取る・前半後半で割る・長期データで確認する）。

## 付記3: 検証ツール

§11 の数字はすべてこの2本で再現できる。**ルールを変えたら回し直すこと。**

```bash
# ルール単体
python tools/backtest.py rules    --code 1321 --split   # v4の条文どおり
python tools/backtest.py dip      --code 1321 --split   # 押し目買い
python tools/backtest.py compare  --code 1321           # 主要な設計を横並び
python tools/backtest.py sweep    --code 1321           # 利確・損切りを振る
python tools/backtest.py universe --codes 1321,1306,1655,1343,1540

# 長期・多市場（下降相場を含める。新しいルールは必ずここを通す）
python tools/longrun.py regime   --symbol '^N225'       # 局面別・年代別（1970年〜）
python tools/longrun.py markets                          # 11市場の全期間
python tools/longrun.py era                              # 検証窓の内と外を比較
python tools/longrun.py leverage --symbol '^SOX'         # 合成レバレッジと減価
```

`backtest.py` は J-Quants（`JQUANTS_API_KEY` が要る、2021-08〜）、
`longrun.py` は Yahoo（指数の全期間）からデータを取る。
どちらも**シグナルは i 日目の確定足、約定は i+1 日目の始値**で固定してある（§3-0）。
`--source yahoo` を渡せば `backtest.py` でも米国ETFや指数を扱える。
