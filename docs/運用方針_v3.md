# 運用方針 v3

2026-08-06 制定。v2 を実測にもとづいて改訂したもの。
Notion の「運用方針_v3」と同じ内容を、リポジトリ側の参照用に置いている。

## この改訂の位置づけ

v2 の条文のうち、**検証で否定側の結果が出たものを外し、支持されたものを具体化した**。
根拠は `verify/` の各スクリプトで再現できる。

**証拠には非対称がある。** 「外す」判断には複数の独立したデータによる裏づけがあるが、
「代わりに据える」条件の側には確証がない。最良の組み合わせでも n=214・22営業日で、
95%信頼区間はゼロをかろうじて外れる程度だった。したがって v3 は
**「効かないと分かったものを減らした v2」であり、「効くと分かったものを積んだ新方針」ではない。**

条件を減らす方向なら、判断が間違っていても失うのは機会だけで済む。そこを軸にした。

### v2 からの変更点

| 項目 | v2 | v3 |
|---|---|---|
| §3-1 順張り | 4条件すべて必須 | 必須2つ＋参考3つ |
| §3-1 出来高1.5倍 | 必須条件 | 参考（多いほど良いとは扱わない） |
| §3-1 VWAP上 | 必須条件 | 参考（条件1と重複） |
| §3-1 日足MA25の上 | なし | **必須に追加** |
| §3-1 時間帯 | 規定なし | 14:00以降の新規を見送り |
| §3-2 逆張り | 場中の分足で判定 | **4条件は維持。日足で判定する** |
| §4 禁止事項 | 7項目 | 1項目＋参考1項目 |
| §4-2 RSI70超で買わない | 禁止 | **撤回**（§7[5]・§10も同様） |
| §5 スイングの損切り | -4% | 日足ATR(14)の1.5〜2倍 |
| §8 記録 | 5項目 | エントリー時の状態を追加 |

## §0 大前提

- 積立投資（オルカン等）とは完全に別枠。失っても生活に影響しない資金のみを使う。
- 判断に迷ったら「やらない」。取引しないことは損失ではない。
- 損切り・利確は**エントリー直後に逆指値・指値で発注**し、あとから動かさない。
- 本ルールは投資助言ではない。最終判断は自己責任。
- **条件が揃わなければ何もしない。条件を甘く読むことがいちばんの害になる。**

## §1 3つの枠

（v2 から変更なし）

値動きの理由（ドライバー）が異なる3枠を並行運用する。同じ日に全部が崩れるのを避けるため。

| 枠 | 銘柄 | ドライバー | 時間軸 |
|---|---|---|---|
| A. 半導体デイトレ | キオクシア(285A) | 半導体市況・AI需要 | その日のうちに完結 |
| B. 金融スイング | 三菱UFJ(8306) | 金利・利上げ観測 | 数日〜トレンド継続中 |
| C. 防衛スイング | IHI(7013) | 地政学・航空需要・米関税 | 数日〜トレンド継続中 |

### 連動確認用（エントリー判断の補助にのみ使う。売買はしない）

- A: 東京エレクトロン(8035)、SOX指数、サンディスク(SNDK)
- B: 三井住友(8316)、みずほ(8411)、米10年国債利回り、米銀大手
- C: 石川製作所(6208)、川崎重工(7012)、米国防衛株

### 重要な注意

- 半導体・AI関連（フジクラ、古河電工、三菱重工、ソフトバンクG等）は互いに連動する。
  **分散にならないので、同じ日に複数を持たない。**
- 大型株（三菱UFJ、トヨタ等）は1日の値幅が±1〜2%しかない。デイトレでは値幅が取れないため、
  原則スイングで扱う。

### 枠Aについての未決事項

**日中に完結する売買には、検証した範囲で優位が見つからなかった。**
リターンの発生場所を分解すると、オーバーナイト（引け→翌寄り）が +0.102%/日 に対し、
日中（寄り→引け）は +0.018%/日 だった。同じシグナルでもデイトレ版にすると
超過が +0.382% → +0.041% まで落ちる。

枠A の扱いは保留とする。**廃止も縮小もまだ決めていない。**
判断には、板・歩み値を含むデータか、実取引の記録が必要（§11）。

## §2 毎朝の判定（8:30頃）

（枠ごとのスコア表は v2 から変更なし）

### 枠A（キオクシア）— +3以上で場中に条件を探す

SOX指数が前日比プラス / サンディスクが前日比プラス / ドル円が円安方向 / PTS価格が前日終値比プラス

### 枠B（三菱UFJ）— +3以上で場中に条件を探す

米10年国債利回りが前日比で上昇 / ドル円が円安方向 / 米銀大手が前日比プラス /
利上げ観測ニュースあり / 日銀会合まで15営業日以内

### 枠C（IHI）— +2以上で場中に条件を探す

航空需要のポジティブ報道 / 地政学リスクのニュース / 国防費・装備移転の増額・進展報道 /
米国防衛株が前日比プラス / GX・個別材料あり

**※ 米関税のネガティブニュースがある日は、スコアに関わらず枠Cは見送り。**

### イベントフィルタ（スコアより優先）

- 決算発表の当日・翌日 → ポジションを通常の半分以下、または見送り
- FOMC・日銀会合の当日 → 寄り付き直後は入らない
- 決算・会合をまたぐ持ち越しはしない

**この項目は検証していない。検証がないことを理由に外さない。**
値動きの優位を主張するものではなく、想定外の損失を避けるための規律であり、
独立に正当化できる。

## §3 エントリー条件

**朝のスコアが立った日だけ、場中に以下を確認する。揃わなければ何もしない。**

### §3-1 順張り

**必須（2つとも満たすこと）**

1. **オープニングレンジブレイク**
   9:00〜9:15の高値・安値を記録し、その高値を明確に上抜けていること
2. **前日終値時点の日足MA25より上にあること**

**参考（見るが、欠けても見送りにはしない）**

- VWAPより上か — 条件1を満たす場面ではほぼ同時に成立し、独立した情報がない
- 場中の出来高倍率 — **多いほど良いとは扱わない**（下記）
- 連動銘柄の方向 — 実測では情報を持たなかった

**見送る条件（いずれかに当たれば入らない）**

- **14:00以降の新規エントリー**
- **ORB高値から+1%以上離れている**

**補足（v2 から維持）**

- 1日1銘柄につき、最初の1シグナルのみ。2回目以降は見送る
- 条件が揃った足が**確定してから**発注する

**根拠**

条件を重ねるほど成績が落ちた（15銘柄・22営業日・5分足）。

| | 勝率 | 超過60分 |
|---|---|---|
| 条件1のみ | 53.4% | +0.037% |
| 条件1+2 | 53.5% | +0.039% |
| 条件1+2+3（出来高） | 45.3% | -0.085% |
| 4条件すべて | **35.5%** | **-0.333%**（95%CIがゼロを外れる） |

出来高スパイクは方向を持たない。買いが集まる瞬間と、利確の売りが出る瞬間の
区別がつかない。同じ理由で大陽線・大きな足も直後の成績が悪かった
（実体+0.3%超で -0.099%、直近20本比2.5倍超の足で -0.102%）。

日足MA25の上下では、RSI70以上の中で勝率 59.2% 対 52.5% に分かれた。
時間帯は 9時台 +0.336% / 12〜13時台 -0.068% と符号が反転する。
ORB高値からの乖離は 1〜2%で -0.022%、2%超で -0.063% と、離れるほど悪い。

### §3-2 逆張り — **日足で判定する。場中の分足では使わない。**

順張りが揃わない日の補完。トレンドに逆らうため順張りより厳格に。
**4条件すべて必須（v2 から条件の中身は変えない）。判定する足を日足に変える。**

1. **日足のボリンジャーバンド -2σタッチ**、またはスクイーズ後の拡大開始
2. **日足RSI 30以下**（短期・長期とも）
3. **日足の出来高急増**
4. **反発の陽線が1本確定**していること。以下をすべて満たすこと:
   - 実体が、直前の下落を主導した陰線の**70%以上**
   - 出来高が、直前の下落局面と**同水準以上**
   - 上ヒゲが実体の**30%以下**（高値圏で引けている）

**加点材料**（必須ではないが信頼度が上がる）
- **強気ダイバージェンス**: 価格は新安値を更新しているのに、RSIは前の安値ほど下がっていない
  — ただし日足5年の実測では超過5日 -0.67% [-1.26, -0.06] とマイナスだった。**扱いは保留**

**NG**
- 反発してもすぐ上にMAがある（MAより下では含み損を抱えた売りが上値になりやすい）

**日足に限定する根拠**

時間軸で符号が反転した。

| | 日足5年 | 5分足1ヶ月 |
|---|---|---|
| RSI30以下 | **+0.64%** [+0.12, +1.13] | **-0.209%** [-0.392, -0.020] |
| 下降MAから大幅下方乖離 | **+0.61%**（10日 +1.38%） | **-0.938%**（勝率32.4%） |

**日単位では「行き過ぎからの反発」でも、分単位では落下の途中**でしかない。
v2 は §3-2 を場中に見る条件としていたが、その場中が最も不利だった。

## §4 やってはいけないこと

**禁止（1項目）**

1. **下降トレンドの途中で買う**（価格が日足MA25の下、かつMA25が下向き）

**参考（禁止ではない。記録して後で検証する）**

- **RSIの水準** — 高いほど順行しやすい。低い状態での順張りに注意する

### RSI 70超えの禁止を撤回した理由

**3つの独立したデータセットで、すべて否定側だった。**

| 検証 | データ | 結果 |
|---|---|---|
| 74銘柄・日足5年 | Yahoo | RSI70超 超過5日 +0.22% |
| 15銘柄・日足5年 | J-Quants | RSI70超 超過5日 +0.30%（5年すべてプラス） |
| 15銘柄・5分足1ヶ月 | Yahoo | RSI70以上 勝率57.2% |

5分足でRSIを7区分に切ると**単調増加**する。

| RSI | 超過60分 | 勝率 |
|---|---|---|
| 〜30 | -0.206% | 45.4% |
| 30〜40 | -0.076% | 46.8% |
| 40〜50 | -0.012% | 48.9% |
| 50〜60 | +0.045% | 53.1% |
| 60〜70 | +0.047% | 53.4% |
| 70〜80 | +0.088% | 54.7% |
| 80〜 | **+0.357%** | **63.8%** |

閾値の当てはめではなく水準そのものが効いている。計算式（ワイルダー平滑／単純平均）と
期間（9／14）の4通りすべてで同じ向きだった。**RSIは買われすぎ警告ではなく、
トレンドの強さの連続量として働いている。**

**この撤回は §7[5] と §10 にも及ぶ。** 同じ前提が3箇所に入っていた。

**段階を踏む。** まず自動ブロッカーから参考表示に降格し、実取引が20件ほど溜まってから
確定する（§11）。

### v2 から削除した禁止事項と、その行き先

| v2 の項目 | 削除理由と行き先 |
|---|---|
| 寄り付き直後の急騰・急落に飛びつく | §3-1 の条件1が9:15の確定を待つ設計なので実質的に内包される |
| 急騰銘柄を後から追いかける | §3-1 の見送り条件「ORB高値から+1%以上」に具体化。日足では乖離が大きいほど成績が良く（MA25から+10%以上で +0.37%）、一般則としては支持されなかった |
| 1日に複数銘柄へ次々と手を出す | 機械判定できない規律。§3-1 の補足と §8 の記録で拾う |
| トレンドラインだけを根拠に買う | 同上 |
| エントリー後に理由を後付けする | 同上 |

**削除は「やってよい」という意味ではない。**
ルールとして判定する対象から外し、振り返りで見る対象に移した。

## §5 損切り・利確

**銘柄の値動きの大きさに応じて幅を変える。** ここを一律にすると機能しない。

**損切り = 日足ATR(14)の1.5〜2倍。利確 = 損切り幅の1.75倍を目安。**

**v2 の銘柄タイプ別の表（高ボラデイトレ -2〜3%／大型株デイトレ -0.6%／
スイング -4%／逆張り -1.5%）は撤廃した。** ATR が銘柄ごとの値動きの大きさを
そのまま反映するので、タイプで場合分けすると二重になる。キオクシアの-2〜3%も
三菱UFJの-0.6%も、結局その銘柄のボラティリティを人手で当てはめた値だった。

- ORBを使う場合、損切りはオープニングレンジの反対側（レンジ中間、またはレンジ幅基準）に置く
- ポジションサイズは損切り幅から逆算する。**ただし持ち越す場合は下記のギャップを見る**

**デイトレに適用するときの注意**: 日足ATRの1.5〜2倍は、その日のうちに手仕舞う
取引には広すぎる。枠A を継続する場合は、日足ATR ではなく**当日の値幅**を基準に
読み替える必要がある。枠A 自体が保留中（§1）なので、ここは再開の判断とあわせて決める。

### 損切りを ATR 基準に変えた理由

10日以内にどちらへ先に届くかを測ると、**損切りが利確の1.5倍の頻度**で当たった。

| | +7%到達 | -4%到達 |
|---|---|---|
| 母集団 | 23.2% | 36.0% |
| 25日高値ブレイク＋出来高 | 24.1% | 38.0% |
| 20日騰落率上位10% | 27.6% | 38.1% |

-4% は日本株の日足ボラティリティに対して近すぎる。v2 の「値動きの大きさに応じて」
という思想はそのままに、スイング枠だけ具体化した。

### 利確目標は上値抵抗との距離で確かめる

現値から**最も近い上値抵抗**（日足MA25・MA75、直近高値、節目）までの距離を出し、
損切り幅と比べる。

- 「最も近い抵抗までの距離 < 損切り幅」なら、リスクリワードが悪い位置と扱う
- 利確目標が抵抗の向こう側にあるなら「抵抗突破が前提」と明記する

### 持ち越すときはギャップをサイズに織り込む

逆指値では寄り付きのギャップを止められない。

- モメンタム銘柄の翌日ギャップは標準偏差 2.01%、下位5%が -2.74%
- **-4%を超える下ギャップが 2.17% の頻度**で発生、最悪 -23.0%

**枠B・Cのポジションサイズは、損切り幅ではなく想定される最悪ギャップから逆算する。**

## §6 手仕舞い

（v2 から変更なし）

### 枠A（デイトレ）

**利確・損切りラインの到達有無に関わらず、例外なくその日のうちに手仕舞う。**

- 14:30 含み損益を確認、方針を決める
- 14:45 含み益なら成行で利確。含み損なら縮小を検討
- 14:50までにポジションをゼロにする

「大幅な上昇だから特別に持ち越す」という例外は設けない。大引け時点では
「大幅かどうか」を判定できず、事後的な結果論になるため。

### 枠B・C（スイング）

以下のいずれかに該当したら、翌営業日の寄り付きで手仕舞う。

- **日足終値がMA25を明確に割った**（メインの手仕舞い基準）
- 日銀会合・決算の前営業日になった
- 前提が崩れた（枠Bならハト派報道、枠Cなら米関税ネガティブ報道）

**保有日数の上限は設けない。** トレンドが続く限り持つ。日足でMA25を割らずに
数週間で+20%以上伸びた例がある。日数で切ると大きな値幅を取り逃す。

## §7 スイングの新規銘柄を選ぶとき

「すでに上がった銘柄」ではなく「これから上がる初動」を探す。

```
[1] 日足で価格がMA25を上抜けた（または上抜け直後）か？
[2] MA25が横ばい〜上向きに転じているか？
[3] 上昇に材料の裏付けがあるか？（金利・為替・受注・政策など）
[4] 初動で出来高が増えているか？
      ↓
  全部YES → エントリー候補
  1つでもNO → 見送り
```

**v2 の [5]「RSIがまだ70未満で、過熱していないか」は削除した。** §4 と同じ理由。
日足5年の実測では、RSI70超で買ったほうが超過リターンは高かった（5年すべてプラス）。
「もう遅い」という判断は、少なくともRSIでは測れていない。

[4] の出来高については、**日足の出来高（20日平均比）は有効だが、場中の出来高倍率は
そうではない**という差がある。混同しない。

## §8 記録（毎回残す）

```
日付 / 銘柄 / 枠(A/B/C)
朝のスコアと内訳
エントリー根拠（順張りの必須2条件、逆張り4条件のどれが揃ったか）
エントリー価格 / 決済価格 / 決済理由 / 損益
反省：ルール通りだったか。外れていたならどの条件を飛ばしたか
```

**v3 で追加する記録項目**（ルールの有効性を後から測るため）

- 日足RSI(14) と 場中RSI(14)
- 日足MA5・MA25からの乖離率
- エントリー時刻（前場／後場）
- ORB高値からの乖離率
- 参考条件（VWAP・場中の出来高・連動）の充足状況
- **§4 から削除した規律の該当状況** — その日すでに何銘柄目か、根拠は何だったか、
  理由を後から付けていないか

**これが無いと、v3 の変更が正しかったかを後から判定できない。**
実運用の記録は、22営業日のバックテストより価値が高い唯一のデータである。

月次で集計し、以下を確認する:

- 勝率と平均損益
- 「条件が揃っていた取引」と「揃っていなかった取引」の成績差
- 枠ごとの成績差
- **v3 で外した条件（出来高・VWAP・連動）が、実際に無関係だったか**

## §9 資金の増やし方

（v2 から変更なし）

1. 最低20〜30取引を、資金量を固定したまま消化する
2. 判定基準: 取引20回以上／勝率65%以上／累計プラス／ドローダウンが損切りルールの範囲内
3. 基準をクリアしたら、1.5倍ずつ段階的に増やす
4. 基準を割ったら、ひとつ前の資金量に戻す

## §10 用語メモ

- **VWAP**: 出来高加重平均価格。その日の実質的な平均取得コスト。上にいれば買い方優勢
- **オープニングレンジ**: 寄り付き後15分の高値・安値。その日の基準線として使う
- **押し目**: 上昇トレンド途中の一時的な下げ。MA25の上で止まれば健全、割れたらトレンド転換。
  ただし**浅い押し目（MA25から0〜-2%）は実測で最も成績が悪い**帯だった
- **上ヒゲ**: 高値で売られて押し戻された跡。ただし**実測では上ヒゲの長短で成績は変わらなかった**
- **RSI**: 一定期間の値上がり幅と値下がり幅の比率。
  **v2 では「70以上=買われすぎ、30以下=売られすぎ」としていたが、実測では
  日足・分足とも「高いほど順行しやすい」という結果だった。**
  トレンドの強さの連続量として読む
- **ダイバージェンス**: 価格とRSIの食い違い。価格は新安値なのにRSIが切り上がっていれば
  売りの勢いが弱まっているサイン。**ただし日足5年の実測ではマイナスだった（保留）**
- **タカ派/ハト派**: 引き締め寄り/緩和寄り。銀行株にはタカ派がプラス、ハト派がマイナス
- **95%信頼区間**: 平均値がどれくらい確からしいかの幅。ゼロを含むなら「効果があるとは
  言い切れない」。本方針の数値は日付クラスタのブートストラップで出している

## §11 検証の限界と、次に確かめること

検証スクリプトは `verify/` にある。数値の出どころはすべてそこで再現できる。

### 測り方の約束

- 判定は当該足の終値まで、約定は次の足の寄り（当日終値では約定できない）
- **超過リターンで比べる**（素のリターンだと、右肩上がりの局面では何でもプラスに見える）
- 95%信頼区間は日付クラスタのブートストラップ
- 年別・銘柄別の符号も見る

### 限界

- 5分足は Yahoo の1ヶ月ぶんしか遡れない。**場中の検証はすべて同じ22営業日を見ている**
- **Yahoo の5分足は86%の日で15:20で切れる。** 大引けと板寄せが無く、最終バーが正規の
  終値と一致したのは 327件中36件（11%）、差は平均 0.275%
- **画面のRSIとスクリプトのRSIは一致しない。** 楽天の分足RSI（短期9・長期14）と
  期間を揃えても合わない。**閾値を運用ルールにするなら画面の値を基準に決める**
- 日足5年の検証は現在のウォッチリスト銘柄で行っており、生存バイアスがある
- 効果の大きさは概ね 0.1〜0.3%。**往復の売買コストでほぼ消える水準**
- 30項目以上を比較している。95%信頼区間がゼロを外れるものが偶然1〜2個出る

### 保留・未検証

| 項目 | 状態 |
|---|---|
| 枠A（デイトレ）の存続 | 日中に優位が見つからない。板・歩み値か実取引の記録が必要 |
| §2 イベントフィルタ | 未検証。規律として維持 |

**採用しないと決めたもの**: チャート形状の判定（ヘッドアンドショルダーズ、三角保合い、
ソーサー、酒田五法、ローソク足の実体・ヒゲの長短）。いずれも情報を持たなかった。
効くのは「どんな形か」ではなく「どこにいるか」だった。
