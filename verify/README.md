# verify — ルールを実測で確かめるためのスクリプト

運用方針のルールが実際に効いているかを、後から数えるための道具置き場。
本番（`screen_daily.py` / `entry_check.py` / `morning.py`）からは呼ばれない。

生成されるCSVはリポジトリに入れない（合計120MB以上になる）。必要なときに
スクリプトを流し直せば取り直せる。実行は `verify/` の中で行う。

## データソースと、その落とし穴

| 用途 | ソース | 期間 | 注意 |
|---|---|---|---|
| 日足 | J-Quants `equities/bars/daily` | 2021-08-06〜 | `AdjC` など Adj 系列を使う。生値(`C`)は分割前後で不連続になる（NTTは25倍、日立は5倍ずれる） |
| 日足 | Yahoo `chart?interval=1d` | 5年 | 分割調整済み。J-Quantsの`AdjC`と日次リターンが1,022日中1,020日一致 |
| 5分足 | Yahoo `chart?interval=5m` | 1ヶ月 | **86%の日で15:20で切れる**。下記 |
| 1分足 | Yahoo `chart?interval=1m` | 7日 | 寄り付き直後が欠ける（ORB窓が丸ごと無い日がある） |

**Yahooの5分足は大引けが無い。** 15銘柄×22営業日で正規の終値と突合したところ、
最終バーが15:20で終わる日が282/327件（86%）、正規の終値と一致したのは36件（11%）、
差は平均0.275%・最大1.486%。引け値を起点にした計算はこのデータではできない。

J-Quantsの分足（`equities/bars/minute`）とティック（`equities/trades`）は
エンドポイントとしては存在するが、現在の契約では 403 が返る。板・気配は
どのプランにも無い（`equities/board` などは存在しない）。

## 中身

### 順張り4条件（§3-1）

- `orb_backtest.py <コード>` — 1銘柄の条件成立回数を5分足で数える
- `orb_universe.py` — `driver_tags.csv` の74銘柄へ拡張
- `orb_outcomes.py` — 条件の素の数値に、30分後・60分後・引け・MFE/MAEを紐づける
- `build_features.py` → `analyze.py` / `analyze2.py` — 運用方針に入っていない要素
  （ギャップ・当日出来高・時間帯・指数・日足トレンド）を足したときの変化

### 日足で組み直した場合（§3の前提そのものの検証）

- `daily_study.py` → `daily_eval2.py` — 74銘柄・5年。高値ブレイク・モメンタム・
  逆張りを、同じ日の全銘柄平均を引いた超過リターンで比較する

### テクニカル指標（マネックスの解説8本）

- `monex_fetch.py` → `monex_eval.py` — 15銘柄・日足5年。移動平均・ボリンジャー・
  RSI・ダブルボトム・逆三尊・三角保合い・ソーサー・酒田五法
- `monex5m_fetch.py` → `monex5m_eval.py` — 同じ8指標を5分足で
- `rule_cond_5m.py` — 運用方針の8条件それぞれの単独効果と、RSIとの関係

チャート形状のパターン5つは数値ルールへの近似で、定義は各スクリプトに書いてある。
目視の判断とは一致しない。

### ローソク足の形と、位置

- `shape_5m.py` — 実体・上ヒゲ・下ヒゲ・終値の位置・足の大きさと、日足MAからの
  乖離。日足MAは**前日終値まで**で計算する（当日の日足MAは引けるまで確定しない）
- `on_top.py` — 「RSI70以上かつ日足MA25の上」を前提に、そこへ35項目を足す

これまでで最も安定して見えたのは、順に RSIの水準・日足MAからの乖離・前場かどうか。
ローソク足の形（実体の割合・ヒゲの長短・包み足・はらみ足）はどれも前提と同じ
数字を返し、情報を足さなかった。効くのは「どんな形か」ではなく「どこにいるか」。

## 測り方の約束

- **判定は当日（当該バー）の終値まで。約定は次の足の寄り。** 当日終値では約定できない
- **超過リターンで比べる。** 素のリターンだと、右肩上がりの局面ではどの仕掛けも
  プラスに見える（5年の日足で母集団の5日リターンが +0.49% ある）
- **95%CIは日付クラスタのブートストラップ。** 同じ日のバーは独立ではない
- **年別・銘柄別の符号も見る。** 平均だけだと一つの局面や一銘柄で決まる
- 効果が0.1〜0.3%のものは、往復の売買コストでほぼ消える。優位の有無とは別に見る
