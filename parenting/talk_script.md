# 話すことリスト（録音用）

商品リストの43点をそのまま並べたものです。**上から順に話す必要はありません。**
言えることがある商品だけ話してください。話さなかったものは記事に載せません。

---

## 話し方

1商品あたり30〜60秒。この4つに答えるだけで足ります。

1. **いつ買ったか／いつから使ったか**（妊娠中・退院直後・生後1ヶ月…）
2. **どういう場面で困っていたか** ← ここが一番大事。**時刻と状況を具体的に**
3. **使ってどう変わったか**
4. **誰には要らないと思うか**／もう一度買うか

言い直し・言い淀み・フィラーはそのままで構いません。整えるのはこちらでやります。
**商品名さえ言っていただければ**、順番がバラバラでも紐付けます。

### 例（このくらいの粒度で十分です）

> ミルクウォーマー。えっと、退院してすぐ買った。夜中の2時とか3時に、片手で
> 子ども抱えながらお湯沸かして70度まで冷ますのが本当に無理で。これ入れてから
> 調乳が30秒で終わるようになった。完全母乳の人には要らないと思う。

## 商品以外に、必ず話してほしいこと

**ここが記事の差別化そのものです。** 商品の話だけだと量産記事になります。

### 1. 育休前にやったこと（買い物じゃない話）

- [ ] 上司にいつ、どう伝えたか（何ヶ月前／誰から順に）
- [ ] 引き継ぎで実際にやったこと
- [ ] **育児休業給付金の手続きと、入金までのタイムラグ** ← 金の話は具体的に
- [ ] 社会保険料の免除でどれくらい変わったか
- [ ] 復帰時期をどう決めたか

### 2. 買わなくてよかったもの（3つ）

- [ ] 買ったが使わなかったもの3つと、その理由

**記事で一番読まれるのはここです。** ここに正直さがあるから、
他の商品のリンクが押されます。逆にここが弱いと記事全体が売り込みに見えます。

### 3. やってみて分かったこと

- [ ] しておいてよかった判断／しておけばよかった判断
- [ ] 育休を取ったことが仕事にどう返ってきたか
- [ ] これから取る人へ、一つだけ

## こちらでやること

文字起こしをいただいたら、商品ごとに切り分けて `products.csv` の `comment` に入れ、
`docs/persona.md` の声で本文にします。**話していないことは書きません。**
情報が足りない商品は空のまま残して、最後にまとめて質問します。
