# 守るルール

書く前に一度読み、公開前にもう一度読む。ここを外すとアカウントごと飛ぶ。

## 1. note でのアフィリエイト

note は規約上、アフィリエイトを全面的に許可しているわけではありません。
**Amazon アソシエイトと楽天アフィリエイトは事実上黙認されている**という
位置づけで、A8.net・もしも・バリューコマースなど他ASPのリンクは原則禁止です。

したがって:

- **楽天（と Amazon）のリンクだけを貼る。** 他ASPは混ぜない
- **リンクだらけの構成にしない。** 商品カタログに見える記事はリスクが上がります。
  本文（体験・順番・判断）が主で、リンクは従。この比率を崩さない
- note の規約は変わります。**公開前に毎回ヘルプを確認する**
  https://www.help-note.com/

グレーである以上、note を収益の本命に置かない設計にしておくのが安全です
（→ §5）。

## 2. PR表記（これは法律。必須）

2023年10月からステルスマーケティングが景品表示法の規制対象です。
広告であることが一般の読者に明瞭でないと違反になります。

- **記事の冒頭**（タイトル直下、読み始める前に目に入る位置）に置く
- **記事の末尾**にも置く
- 文言はこれで統一する:

      ※この記事にはアフィリエイト広告（楽天アフィリエイト）が含まれます。

- 折りたたみの中や、小さい文字にしない
- `build_note.py` が冒頭と末尾に自動で入れます。**消さないこと**

## 3. 商品の書き方（景表法・薬機法）

ベビー用品は健康・発達に触れるため、書ける範囲が狭いです。

| 書ける | 書けない |
|---|---|
| うちの子は寝つきが早くなった | 寝つきが良くなります／睡眠の質が改善します |
| 肌荒れが落ち着いた気がする | アトピーに効く／肌トラブルを防ぐ |
| 3ヶ月使って壊れていない | 絶対に壊れません |
| 自分は買ってよかった | 全員買うべき／これ以外は無駄 |

原則は3つ。

1. **主語を自分と自分の子にする。** 一般化した瞬間に効能の断定になります
2. **医薬品・医療機器のような効能を書かない。** 治る・防ぐ・改善する は使わない
3. **最上級と断定を使わない。** 「最強」「唯一」「必ず」

**睡眠・うつぶせ寝・添い寝・離乳食まわりは特に慎重に。**
安全性に関わる話は、商品の紹介として書かず、必ず「取扱説明書と自治体の
案内に従ってください」を添える。

## 4. 楽天アフィリエイトの規約と仕組み

- **成果条件**: リンクのクリック後 **24時間以内にカゴに入れ、89日以内に購入完了**。
  クリックした商品以外を買っても成果になります（だから記事の役割は
  「楽天に行かせること」で、商品を当てにいくことではない）
- **料率**: ジャンルにより通常 2〜4%。店舗設定で最大20%
- **支払い**: 成果発生の翌々月10日に楽天キャッシュで。1円から支払われる。
  ただし **3,001円以上を受け取るには楽天カードの発行か、楽天銀行口座の
  楽天会員リンク登録が必要**。ここを先に済ませておかないと積み上がったまま止まります
- **自己購入は成果対象外。** 家族の購入も避ける
- **価格をベタ書きしない。** 価格は変動します。書くなら「執筆時点で約◯円」と添える。
  `rakuten_affiliate.py --check` で乖離を検知できます
- 楽天のロゴ・商標を加工して使わない

出典: https://affiliate.rakuten.co.jp/guides/rank/ ／
https://affiliate.rakuten.co.jp/guides/begin/

## 5. 「収益を生み続ける」ための構造上の注意

単発の note 記事は、公開直後に読まれてその後は忘れられます。
継続収益にするには、**流入が検索から入り続けること**が要ります。

- note 記事は検索に弱い。**note を入口ではなく受け皿として使う**
  （X からの導線 → note）
- 検索流入を本気で取りにいくなら、同じ原稿を自前ブログにも置く。
  `note_draft.md` はプラットフォーム非依存の素材として作ってあります
- **年2回、記事を更新する。** 型落ち・廃番・価格変動で記事は腐ります。
  `--check` を定期実行して、切れた商品を差し替える（→ README §5）
- 出産準備の需要は通年ですが、**楽天お買い物マラソン／スーパーSALE の
  期間に再告知する**と成果が固まります
