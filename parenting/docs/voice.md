# 文体

**です・ます調。ただし「書き言葉」ではなく「丁寧に喋っている」文章にする。**

一度この指摘を受けています ——「丁寧ではあるが硬い。AIで書かれた感じが色濃く残っている」。
その原因は語彙ではなく**構文**でした。以下は実際に直した箇所から抽出したものです。

## AIっぽさの正体

### 1. 名詞化（いちばんの原因）

動詞で言えることを名詞にすると、途端に人が書いた文でなくなります。

| 直す前 | 直した後 |
|---|---|
| 寝かせる場所の**選択には**、参照できるデータが**あります** | どこで寝かせるかは、好みで決めなくてよかったです |
| ここから**導かれる判断は**〜です | じゃあ〜すればいいかというと、うちはそうしませんでした |
| 残量を気にせず洗える**という状態そのものが**安心に**つながっています** | 残量を気にせず洗える、というだけでかなり安心できます |
| 分けて洗うことは回数が増えることを**意味します** | 分けるってことは、洗濯の回数がもう一段増えるということです |

**「〜の選択」「〜という状態」「〜における」「〜に関して」「〜を確保する」は使わない。**

### 2. 整いすぎた対句

三つ並べて韻を踏むと、書き手の顔が消えます。

- 直す前: 素材では妥協せず、種類は増やさず、枚数だけ確保する
- 直した後: 素材だけ選んで、種類は増やさず、あとは枚数

完全に揃えない。**わざと崩す。**

### 3. 太字の多用

1セクションに何度も太字が出ると、機械が強調箇所を判定した見た目になります。
**太字は1セクションに0〜1回。** 使わない節があっていい。

### 4. 均一な文の長さ

全部が2〜3行だと単調です。**一文だけの段落**や、10文字の文を混ぜる。

> 小さいことのようで、これが大きい。

### 5. 見出しが体言止め・宣言調

- 直す前: 観点2｜ベビーベッドは、寝る以外の機能で選ぶと化けます
- 直した後: ベビーベッド、寝かせる以外でいちばん使っています

「観点1｜」のような**通し番号のラベルは付けない**（テンプレート感が出ます）。
見出しも喋っているように書く。

### 6. 「——」（二倍ダッシュ）

使わない。読点か、文を分ける。

## 逆に、入れると人になるもの

- **「で、」「なので、」「ただ、」「あと、」「正直、」** で文を始める
- **「〜なんですよね」「〜んです」「〜んですが」** の説明の「ん」
- **「〜かなと」「〜と思います」で言い切らずに止める**（ただし多用しない）
- **読者への呼びかけ**:「〜ですよね」「悩む方は多いと思います」
- **自分の失敗を、言い訳せずに短く**:「準備のときに数を読み違えていたのは完全にここで」
- **口語の語順**。結論を先に言って、理由を後ろに付け足す

## 変えないもの

口語にしても、次は崩しません。

- **安全・医療に関する記述**（`rules.md` §3）。ここだけは硬くていい
- **出典の提示**。「消費者庁が〜出しています」は正確に
- **PR表記**の文言
- 敬体そのもの。**タメ口にはしない**

## 判定の仕方

書き終えたら声に出して読む。**息継ぎの位置が不自然なら名詞化を疑う。**
「〜の選択には」で詰まったら、そこが直す場所です。
