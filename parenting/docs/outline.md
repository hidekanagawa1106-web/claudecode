# 記事の構成

## 狙い

商品リスト記事にしない。**「育休を取る男性が、何を、いつ、どの順で
決めればいいか」の地図**にして、その各地点に商品を置く。

商品リストは検索すれば無数に出てきます。この記事が読まれる理由は、
**取得した本人が順番と失敗を書いていること**です。

## タイトル候補

読者は「育休 準備」「育休 男性 やること」「出産準備 リスト 夫」で来ます。
数字と期間を必ず入れる。

- 育休3ヶ月で買ったもの全部と、買わなくてよかったもの3つ
- 男性育休、準備で本当に必要だったもの◯個（買って失敗したものも書く）
- 育休を取る前の自分に渡したいリスト —— 買い物・手続き・引き継ぎ

避ける: 「完全ガイド」「必需品まとめ」（量産記事と同じ顔になります）

## 全体の並び

```
タイトル
PR表記                            ← 必須。冒頭
導入（3〜4行）
  育休を取った事実・期間・立場
  この記事で何がわかるか1行
─────────────────────────
1. 育休前にやること（買い物じゃない話）   ← ここを先に置く
2. 時期別・買ったもの                   ← 商品セクション群
3. 買わなくてよかったもの                ← 一番読まれる
4. 3ヶ月やってみて分かったこと
PR表記                            ← 必須。末尾
```

**1 を先に置くのが要点です。** いきなり商品から入ると量産記事に見えます。
手続きと引き継ぎの話を先に置くと、そのあとの商品紹介が「この人の判断」として
読まれます。

## 1. 育休前にやること

商品が一つも出てこないセクション。ここが差別化そのもの。

- 上司にいつ、どう伝えたか（何ヶ月前／誰から順に）
- 引き継ぎで実際にやったこと（属人化していた業務の棚卸し）
- 育児休業給付金の手続きと、**入金までのタイムラグ**（ここは実額の話が刺さる）
- 社会保険料の免除条件
- 復帰時期をどう決めたか

**金の話を具体的に書く。** 若手サラリーマンが一番不安なのは収入です。

## 2. 時期別・買ったもの（商品セクション）

`products.csv` の `section` をこの見出しに合わせる。
`build_note.py` の `ORDER` がこの並び順を持っています。

| section | いつの話か |
|---|---|
| 妊娠中に買う | 出産前。慌てて買わずに済むもの |
| 退院直後 | 最初の2週間。ここが一番きつい |
| 授乳・ミルク | 夜間対応の道具 |
| 寝かしつけ | 睡眠まわり（安全性の断定はしない） |
| おむつ | 消耗品と処理 |
| 外出 | 移動手段 |
| 家事削減 | 時間を買う道具。**男性読者に一番刺さる枠** |
| 自分のための道具 | 親側の消耗を減らすもの |

**見出しは商品名ではなく「観点」で立てます。** 商品を順番に紹介する形式にしない
（詳細は `persona.md`「書き方の骨格」）。

```
### 観点N｜この分野で気にする必要があること

前提知識 —— なぜそれが問題になるのか（出典を示せることだけ）
　↓
我が家の判断 —— その観点にどう答えたか
　↓
商品 —— 判断の結果として出てくる
　↓
誰には要らないか —— 逆の判断もありうる
```

観点は1セクションあたり3〜4個。1つの観点に商品は0〜1点です。
**商品が出てこない観点があっていい**（むしろ入れたほうが記事が締まります）。

「誰には要らないか」を書くと信頼が跳ね上がります。全部◎にしない。
**◎は全体の3分の1まで。**

セクションの最後に、観点だけを箇条書きで振り返る「まとめ」を置きます。
ここだけ読んでも判断基準が持ち帰れる状態にしておくと、保存されます。

## 3. 買わなくてよかったもの

3つ。理由付き。**リンクは貼らない。**

ここが記事で一番読まれ、一番引用されます。ここに正直さがあるから、
上のセクションの商品リンクが押されます。逆に言うと、
**このセクションが弱いと記事全体が売り込みに見えます。**

## 4. 3ヶ月やってみて分かったこと

商品に戻らない。読後感を作るところ。

- 準備しておいてよかった判断／しておけばよかった判断
- 育休を取ったことが仕事にどう返ってきたか
- これから取る人へ、一つだけ

## 分量

全体 6,000〜9,000字。商品は 12〜20点。
それ以上増やすと読了率が落ち、リンクが押される前に離脱します。
商品が多い場合はセクションを切り出して**別記事にして内部リンクで繋ぐ**
（回遊が増えるぶん、そちらのほうが成果は上がります）。
