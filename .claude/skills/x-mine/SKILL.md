# 素材の掘り出し

**このスキルは型1（上司の一言）の補充専用です。** 他の型は外部ソースから
作れるので、日常の下書きはこれを回さなくても止まりません（`docs/sources.md`）。

型1は実測で最強（521万・426万）ですが、特定の日時・場所・発言の一人称主張なので
`persona.md` の時系列に組み込まれます。**実体験に紐づけておく価値が、この型だけ
突出して高い**——だからこのスキルが残っています。

仕事は**Hideさんの記憶から一次素材を引き出して構造化すること**であって、
それらしい話を作ることではありません。

## 絶対にやらないこと

**素材を創作しない。** 「こういう体験談がありそう」で埋めない。
実在しない体験談を一人称で投稿すると、指摘されたときにアカウントが終わります。
情報が足りなければ**空欄のまま残して聞き返す**。

## 掘る対象

**種類A（言われた一言）を最優先で掘ってください。** これが型1の燃料です。

種類B（観察した人の行動）と種類C（面接官として見たもの）も記録できますが、
**この2つは外部ソースからでも作れる**ので、優先度は下がります。
Hideさんに実際の記憶があるなら取る、程度で構いません。

## 手順

### 1. 在庫を確認する

`x/episodes.md` の「未使用の素材」を種類別に数える。各種類3本以上が目標。

**種類Aが3本を切っていたら掘る。** それ以外は無理に回さなくて構いません。

### 2. 掘る

**一度に1問ずつ聞く。** 質問を並べて投げると、どれも浅い答えしか返りません。

**最初の1問は具体から入る。** 抽象的に聞くと何も出てきません。

- ✗「印象に残っている出来事は？」
- ○「新卒の頃、やらかして怒られたことって何かあります？」（種類A）
- ○「一緒に働いた中で、地味にすごいなと思った人っていました？」（種類B）
- ○「面接で『あ、これは無理だな』と思う瞬間ってどこですか？」（種類C）

### 3. 種類ごとに、必要なものが揃うまで追い質問する

**種類A —— 一言だけでは素材になりません。**

実測で、失敗のドラマがある2本は521万・426万、ない2本は17万・6.4万でした。
**40分の1です。** だから次の順で必ず全部取ります。

1. **自分の失敗** —「そのとき何をやらかしたんですか？」
2. **そのあとの状況** —「言われたのはどこでですか？そのとき何してました？」
3. **一言** —「正確にはどういう言い方でした？」← 言い回しをそのまま
4. **今の解釈** —「今ならどう受け取りますか？」

**失敗が出てこない話は、種類Aとして記録しないでください。**

**種類B —— 箇条書きは「作業」で取ります。**

実測で、真似できる作業を並べた投稿は333万、姿勢を並べた投稿は23万。**14倍**です。

- 「その人、具体的に何をやってました？」を3回聞く
- 「深夜でも対応する」「感情的にならない」のような**姿勢が返ってきたら、
  それを作業に降ろす**追い質問をする —「それって具体的にどういう動きですか？」
- 学歴・職種・年齢を必ず聞く（引きの装置として機能しています）

**種類C —— 意外性が要ります。**

- よくあるNG理由を3つ（読者が予想できるもの）
- **意外な1つ** —「実は、意外とこれで落とすっていうのあります？」
- **採用側の損得** —「それって採用側から見て何が困るんですか？」
  ← 人格の否定にしないための必須項目

### 4. 書く

`x/episodes.md` の「未使用の素材」に、あのファイルの書式で追記する。
IDは種類の頭文字（A001 / B001 / C001）。

会社名・部署名・製品名・個人名は素材帳の中にも書かない。
業種と規模だけ残す。学歴と年齢は出してよい。

### 5. 報告する

追加した素材のIDと見出しだけ並べる。全文は貼らない。
**種類ごとの在庫本数**を最後に書く。

## 文体の再学習（四半期に1回）

`x/docs/voice.md` は過去投稿11本から抽出済みです。「未観測」と書かれた項目
（投稿時間帯・リプライの文体・画像の使い方）は、追加の投稿を読ませれば埋まります。

**観測できなかった項目を推測で埋めないでください。** それが下書きに効いてしまいます。
