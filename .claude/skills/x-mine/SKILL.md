# 素材の掘り出し

体験談・暴露系で伸びない原因は、ほぼ全部ここの枯渇です。文章生成ではありません。
このスキルの仕事は**Hideさんの記憶から一次素材を引き出して構造化すること**であって、
それらしい話を作ることではありません。

## 絶対にやらないこと

**素材を創作しない。** 「こういう体験談がありそう」で埋めない。実在しない体験談を
一人称で投稿すると、指摘されたときにアカウントが終わります。
情報が足りなければ**空欄のまま残して聞き返す**。

## 手順

### 1. 在庫を確認する

`x/episodes.md` の「未使用の素材」を数える。

- 10本以上ある → 掘る必要なし。そう伝えて終了
- 10本未満 → 掘る。目標は1セッションで**3〜5本**

`x/docs/winners.md` の「素材の傾向」も読む。**どの種類が刺さっているかが分かって
いれば、そこを狙って掘る**。空なら全方位で掘る。

### 2. 掘る

**一度に1問ずつ聞く。** 質問を並べて投げると、どれも浅い答えしか返りません。
Hideさんは思い出しながら答えるので、追い質問で深めるほうが取れます。

最初の1問は、抽象的な質問を避けて具体から入る。

- ✗「転職で印象に残っていることは？」→ 何も出てこない
- ○「前職で、いま思い出しても腹が立つ一言ってあります？」

出てきたら、**次の4つが揃うまで追い質問する**。ここが揃っていない素材は使えません。

- **具体的な一言** — 誰かが実際に言った言葉。地の文の要約ではなく、そのままの言い回し
- **物理的な状況** — 時刻・場所・その場に何があったか
- **数字** — 残業時間、人数、年収差、期間。1つでいい
- **そのとき考えたこと** — 感想ではなく、その瞬間に頭をよぎったこと

追い質問の例:

- 「それ、正確にはどういう言い方でした？」
- 「それ何時ごろの話ですか？」
- 「そのとき何してました？」
- 「言われた瞬間、最初に思ったことって何でした？」

**1本掘り切ってから次に行く。** 浅い素材を5本より、深い素材を3本のほうが効きます。

### 3. 書く

`x/episodes.md` の「未使用の素材」に、あのファイルの書式で追記する。

**特定リスクを潰してから書く。** 会社名・部署名・製品名・個人名は素材帳の中にも
書かない。業種と規模だけ残す。事実と評価は分けて書く（`episodes.md` 冒頭の
ルール参照）。

書いたら、**どの型（formats.md）で使えそうか**を1行添える。ただし決め打ちしない
—— `/x-draft` が実績を見て選び直します。

### 4. 報告する

追加した素材のIDと見出しだけ並べる。全文は貼らない（ファイルにあります）。
未使用の在庫が何本になったかを最後に書く。

## 文体の抽出（初回、および四半期に1回）

`x/docs/voice.md` に `<!-- -->` のプレースホルダが残っている場合、
**先にこちらを片付けます**。素材があっても文体が無いと下書きがAI臭くなります。

1. Hideさんに**既存投稿を10本ほど貼ってもらう**（伸びたものを優先。スクショでも可）
2. 次を抽出して voice.md を埋める
   - 一人称と語尾（揺れているなら、伸びた投稿のほうに寄せる）
   - よく使う言い回し / 出てこない言い回し
   - 句読点の打ち方、改行位置、カタカナ表記の癖（「ヶ月」か「カ月」かの類）
3. **観測できなかった項目は埋めない。** 推測で書くと、それが下書きに効いてしまう

投稿が手元にない場合は、voice.md の一般則だけで進めます。その場合は
「文体は未学習なので、下書きは一般則ベースです」と毎回添えてください。
