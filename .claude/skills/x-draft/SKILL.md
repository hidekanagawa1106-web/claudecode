# 投稿の下書き

コピペしてそのまま投稿できる状態で返します。**投稿はHideさんが手動で行います** ——
このスキルは投稿しません。

## 手順

### 1. 読む

**毎回読むもの**

- `x/docs/winners.md` — **実測。ここが最優先**
- `x/docs/persona.md` — **設定。ここと矛盾する投稿は書けません**
- `x/docs/formats.md` — 型
- `x/docs/sources.md` — ソースの優先順位と、型ごとに外部ソースで作れる範囲
- `x/docs/voice.md` — 文体

**ソースとして読むもの**

- `x/posts.csv` — 伸びたテーマの焼き直し元
- `x/swipe.csv` — 他アカウントの構造とテーマ
- `x/topics.md` — 時事の在庫
- `x/episodes.md` — 実体験（あれば）

`x/docs/funnel.md` は1stリプの橋渡しを書くときに読みます。

### 2. 型を選ぶ

winners.md の「次の30本で検証すること」に従います。現時点の方針:

- **型2（面接官の暴露）を意識的に増やす** —— 導線の本命候補なのに1本しかない
- **型1は1日1本まで**。実測で最強なので枠を大事に使う
- **型1崩れ**（質問から始まる形）は出さない
- **型3の箇条書きは必ず「作業」で書く**（姿勢で書くと14倍沈みます）
- **他人が登場しない断言の形は出さない**（実測で最下位）

3本を全部同じ型で埋めないこと。勝ち型2本＋検証1本を基本にします。

### 3. ソースを選ぶ

`sources.md` の優先順位どおり。**素材帳が空でも止まりません。**

1. **過去投稿の焼き直し** — `posts.csv` の伸びた行からテーマを取り、別の型で出し直す。
   同じテーマは**最低2ヶ月空ける**
2. **スワイプ** — `swipe.csv` から構造とテーマを借りる。
   **言い回しとエピソードそのものは借りない**
3. **時事** — `topics.md` の在庫から。賞味期限を確認する。
   **1行目に置ける形にならないなら使わない**
4. **実体験** — `episodes.md` に在庫があれば優先的に

**3本すべてを時事にしないこと。** 時事は多くて1本です。

### 4. 設定と突き合わせる（外部ソースから作る場合は必須）

書いた内容が `persona.md` と矛盾していないか確認します。**ここが一番の失敗点です。**

- **型1を書くなら `persona.md` の年表で空き枠を確認する。**
  新卒1〜3年目は既存5件で飽和。**ここに新しい出来事を足さない**
  （中堅期・マネージャー期・転職時・現職は空き。一言の出どころも
  上司に限らず、部下・顧客・エージェント・候補者・同僚が使える）
- 上司を勝手に増やしていないか（早稲田卒の上司／関西弁の上司が既にいます）
- 既出の観察対象と同じ属性の人物を出していないか
  （慶應卒の営業29才／青学卒の営業28才／慶應卒のエース）
- **後から縛りになる新しい確定事実**（会社名・部下の人数・売上）を足していないか

矛盾しそうなら、**属性を変えるのではなく素材を変えてください。**

### 5. 書く

1本につき、次の形で出す。

```
──────── 朝（7:30想定）
【型】型2 面接官の暴露 ／【ソース】T002（賃上げ）＋ swipe #12 の構造

（投稿本文。コピペする範囲。ここにリンクは入れない）

──── 1stリプの橋渡し案（バズを確認してから使う）
（funnel.md の公式どおり、橋渡しの1〜2行だけ。
 リンクと広告表記はHideさんが付けるので書かない）

【狙い】この型・このソースで何を検証するか（1行）
```

**書式で必ず守ること**（詳細は `formats.md` と `voice.md`）:

- **『』の決め台詞を独立行に置く。** 前後に空行。投稿の重心はここ
- **締めは同意誘導。「〜よね。」「〜なんだよな。」「〜からね。」** 疑問形にしない
- **本文にリンクを入れない**
- 絵文字なし、ハッシュタグなし
- シグネチャ構文「などあるが、とくに良いのは、」を型どおりに使う
- 学歴・年齢を出す（型3）
- 改行は1〜2文ごと

**自分を上げる話にしない。** Hideさんが登場するときは、常に失敗している側か
教わる側です（過去11本に武勇伝は1本もありません）。

**時事を使う場合は入口だけ。** 1行目で触れて、2行目以降はいつもの型に戻る。
中身までニュース解説にしないこと。

### 6. 添える

3本を出したあと、短く3つ。

- **今日の3本で何を検証しているのか**（例:「型2が2本目。総合導線率を型3と比較したい」）
- **設定に新しく足した事実があれば明示する**（あれば `persona.md` に追記が要ります）
- 時事在庫のうち、期限が近いものがあれば一言

## 出してはいけないもの

- 4本以上。3本に絞る
- 本文の解説。狙い1行で足ります
- 「バズる保証」めいた前置き
- **他アカウントの投稿の言い回しをなぞったもの**（構造は可、表現は不可）
