# 投稿の下書き

コピペしてそのまま投稿できる状態で返します。**投稿はHideさんが手動で行います** —
このスキルは投稿しません。

## 手順

### 1. 読む（3つとも必ず読む）

- `x/docs/winners.md` — **何が効いているか。ここが最優先**
- `x/episodes.md` — 未使用の素材
- `x/docs/formats.md` — 型
- `x/docs/voice.md` — 文体

winners.md に「効かなかった型」が書いてあれば、**その型は使わない**。
「効いている型」があれば、当日3本のうち2本をそこに寄せ、1本は別の型で試す。
全部を勝ち型で埋めないでください —— 実績が偏ると次に打つ手が無くなります。

winners.md が空（データなし）の場合は、型1〜5から**バラして3本**選ぶ。
最初の2〜3週間は当てにいかず、型ごとのサンプルを溜めるほうが早く前に進みます。

### 2. 素材を選ぶ

未使用の素材から、当日の3本ぶんを選ぶ。

**未使用が3本未満なら、そこで止めて `/x-mine` を勧めてください。** 素材が無いのに
下書きを作ると、必ず一般論の投稿になります。使用済み素材を別の型で切り直すのは
可ですが、**その場合は「E003を型4で切り直し」と明示する**こと。

### 3. 書く

1本につき、次の形で出す。

```
──────── 朝（7:30想定）
【型】型3 分岐点 ／【素材】E007

（投稿本文。コピペする範囲。ここにリンクは入れない）

──── 1stリプ（反応が付いてから追加）
（本文の続きとして書く。宣伝文にしない。末尾に導線）

【狙い】この型・この素材でどの層に刺しにいくか（1行）
```

守ること（`formats.md` の共通制約と `voice.md` に全部書いてあります）:

- **本文にリンクを入れない**
- **末尾に問いかけを1行**
- **1行目に「一言」か「異常な数字」**。状況説明から始めない
- 絵文字での装飾なし、ハッシュタグなし、箇条書きなし
- 改行は1〜2文ごと

**素材に無い事実を足さない。** 情景を盛りたくなったら、その情景が素材帳にあるか
確認する。無ければ書かない。ここが体験談系で一番やってはいけないことです。

### 4. 添える

3本を出したあと、次の2つを短く。

- **今日の3本で何を検証しているのか**（例:「型3が2本目。型5は初回で観測用」）
- 未使用素材の残り本数。3本を切っていたら `/x-mine` を促す

## 出してはいけないもの

- 「バズる保証」めいた前置き。効果は結果でしか分かりません
- 4本以上。選択肢を増やすと選ぶ手間が増えるだけです。3本に絞る
- 本文の解説。読むのはHideさんだけなので、狙い1行で足ります
