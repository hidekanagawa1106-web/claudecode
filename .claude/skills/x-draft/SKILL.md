# 投稿の下書き

コピペしてそのまま投稿できる状態で返します。**投稿はHideさんが手動で行います** ——
このスキルは投稿しません。

## 手順

### 1. 読む（5つとも必ず読む）

- `x/docs/winners.md` — **実測。ここが最優先**
- `x/docs/formats.md` — 型（過去11本の実測から作られています）
- `x/episodes.md` — 未使用の素材
- `x/docs/voice.md` — 文体
- `x/docs/funnel.md` — 1stリプの橋渡し（型ごとに入口が違います）

### 2. 型を選ぶ

winners.md の「次の30本で検証すること」に従います。現時点の方針は:

- **型2（面接官の暴露）を意識的に増やす** —— 転職導線の本命候補なのに1本しかない
- **型1は「失敗ドラマあり」だけ**。型1崩れ（質問から始まる形）は出さない
- **型3の箇条書きは必ず「作業」で書く**（姿勢で書くと14倍沈みます）
- **他人が登場しない断言の形は出さない**（実測で最下位）

3本を全部同じ型で埋めないでください。**実績が偏ると次に打つ手が無くなります。**
勝ち型2本＋検証1本を基本にします。

### 3. 素材を選ぶ

未使用の素材から3本ぶん。**種類と型は対応しています**（A→型1、B→型3/型5、C→型2）。

**その型に使える素材が無いなら、その型は出せません。** 素材を creative に
埋めないでください。3本ぶんの素材が揃わなければ、**そこで止めて `/x-mine` を
勧めてください。** 一般論で埋めた投稿は実測で最下位（4万）です。

使用済み素材を別の型で切り直すのは可。その場合は「A002を型3で切り直し」と明示する。

### 4. 書く

1本につき、次の形で出す。

```
──────── 朝（7:30想定）
【型】型1 上司の一言（失敗ドラマ型） ／【素材】A007

（投稿本文。コピペする範囲。ここにリンクは入れない）

──── 1stリプ（バズを確認してから追加）
（funnel.md の公式どおり。本文の主役も読者も否定しない。
 本文と同じ独白の語尾で引き継ぐ。pr表記を忘れない）

【狙い】この型・この素材で何を検証するか（1行）
```

**書式で必ず守ること**（詳細は `formats.md` と `voice.md`）:

- **『』の決め台詞を独立行に置く。** 前後に空行。投稿の重心はここ
- **締めは同意誘導。「〜よね。」「〜なんだよな。」「〜からね。」**
  疑問形にしない。**この人の型では同意誘導のほうが返信が付いています**
- **本文にリンクを入れない**
- 絵文字なし、ハッシュタグなし
- シグネチャ構文「などあるが、とくに良いのは、」を型どおりに使う
- 学歴・年齢を出す（型3）
- 改行は1〜2文ごと

**素材に無い事実を足さない。** 情景を盛りたくなったら、素材帳にあるか確認する。
無ければ書かない。ここが一番やってはいけないことです。

**自分を上げる話にしない。** Hideさんが登場するときは、常に失敗している側か
教わる側です（過去11本に武勇伝は1本もありません）。

### 5. 添える

3本を出したあと、短く2つ。

- **今日の3本で何を検証しているのか**（例:「型2が2本目。総合導線率を型3と比較したい」）
- 未使用素材の残り本数（種類別）。3本を切っていたら `/x-mine` を促す

## 出してはいけないもの

- 4本以上。選択肢を増やすと選ぶ手間が増えるだけです。3本に絞る
- 本文の解説。読むのはHideさんだけなので、狙い1行で足ります
- 「バズる保証」めいた前置き
