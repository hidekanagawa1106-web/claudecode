# 今日の話題を拾う

**採用率は低くて構いません。** ほとんどの話題はこのアカウントに橋が架かりません。
無理に乗せると浮くので、**捨てるのがこのスキルの主な仕事**です。

## 手順

### 1. Xの生トレンドを見る（期待値は低い）

```
WebFetch https://jp.trend-calendar.com/
```

実測（2026/08/11）の上位30語は「打ち上げ成功／山の日／モンスト13周年／
台風15号／東京メトロ半蔵門線」。**橋が架かる語はゼロでした。**

**採用率は1割以下と考えてください。** 拾うのは次のような場合だけです。

- 大企業のリストラ・early retirement の発表
- 労働時間・雇用制度の変更
- 著名人の退職エントリや働き方の発言が伸びている
- 仕事・上司・職場まわりの炎上

**該当なしが普通です。** 無理に関連づけないこと。「山の日だから休み方の話」
のようなこじつけは、実際に投稿すると浮きます。

### 2. 仕事・キャリア系の時事を探す（本命）

こちらが安定して取れます。WebSearch で次の軸を回してください。

- 賃上げ・ボーナスの動向
- 人手不足・採用難
- 転職市場の動向（求人倍率・二極化・ミドル層）
- AI と雇用
- 大企業の人事制度の変更

**数字と出典があるものだけ拾う。** 「〜と言われている」レベルの記事は使いません。
投稿で数字を出したあと、根拠を聞かれて答えられない状態を作らないためです。

### 3. カレンダー要因を確認する

`x/docs/sources.md` の月別表を見て、**いまの時期に読者がどういう状態か**を
1行で出す。時事より確実で、事前に仕込めます。

### 4. 橋が架かるか判定する

拾った候補ごとに、**1行目に置ける形になるか**を実際に書いてみてください。

書けなければ捨てます。**「関連はしているが1行目にならない」ものが一番多く、
それは全部捨ててよい**です。

判定の基準:

- そのまま **型2（面接官）／型3（人物観察）／型5（新人観察）** の入口になるか
- **社会批評にならないか**（政治・企業批判に踏み込むとアカウントの性格が変わります）
- 断定した部分に、数字か出典の裏があるか

### 5. topics.md に書く

`x/topics.md` の書式で追記。**賞味期限を必ず入れる。**
期限切れの在庫があれば、このタイミングで消してください。

### 6. 報告する

- 拾った件数と、捨てた件数
- 追加したトピックのIDと見出しだけ
- 生トレンドが不作だった場合は、そう言って構いません（それが通常です）

## やらないこと

- **こじつけ。** 橋が架からない話題を無理に使わない
- **推測で数字を書く。** 出典が確認できないものは topics.md に入れない
- **政治・企業批判。** リプ欄が荒れて本文の伸びまで落ちます
- **その日のうちに投稿する義務はありません。** 在庫として貯めるのが目的です
