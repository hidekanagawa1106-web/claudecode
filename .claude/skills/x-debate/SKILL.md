# 議論を呼ぶテーマを探す

**テーマを5つ出して `x/debates.md` に貯めます。ポストにはしません**
（「これを投稿にして」と言われてから書きます）。

**なぜ `/x-draft` と分けるか。** x-draft は**型と在庫バランス**から入りますが、
議論系は**争点**から入ります。入口が違うので、同じ手順では作れません。
実際、x-draft の発想で出した5案は**全部「既に投稿した内容の焼き直し」で没**になりました
（2026-08-18）。

## 手順

### 1. 読む

- `x/debates.md` — **既出のテーマ。ここと重ならないこと**
- `x/posts.csv` — **過去に投稿した内容**
- `x/docs/formats.md` の「議論系の締め」（**型10候補は廃止**。締めの規定だけ使います）
- `x/docs/voice.md` の「話者のポジション」

### 2. ★ 既出チェック（ここを飛ばすと全没します）

**過去に投稿したテーマの言い換えを出さないこと。**

2026-08-18の失敗例: 転職回数／管理職になりたくない若手／残業／年収を同僚と話す／
上司ガチャ。**どれも既存投稿の領域内**で、5つとも棄却されました。

> 私が今まで投稿したような内容ではなく（Hideさん）

**「この主張、過去にどの型で出したか」を思い出せるなら、それは新しくありません。**

### 3. ★ 外を見に行く（WebSearch）

**頭の中だけを供給源にすると、既存テーマの焼き直しが出ます。**
**毎回、必ず検索してください。**

```
WebSearch  労働基準法 改正 2026 議論
WebSearch  働き方 職場 賛否 話題
WebSearch  人事 労務 トピック 2026
```

`x/topics.md` に `/x-trend` が貯めたものがあれば、そこも見ます。

**⚠ `/x-trend` と同じ検索でも、抜き方が違います。**

| | 何を抜くか |
|---|---|
| `/x-trend` | **投稿の入口**。1行目で触れて、2行目以降はいつもの型に戻す |
| `/x-debate` | **争点**。誰と誰が、何をめぐって対立しているか |

### ニュースから争点を抜く4つの読み方

**① 見送られた・反対された理由を見る**

**そこに必ず対立があります。** 2026年の労働基準法改正では、
「つながらない権利」と勤務間インターバル11時間義務化が**国会提出を見送られました**。
理由は**建設・運輸など人手不足業種が「回らない」と反発したから**。
**争点が公式に露出しています。**

**② 数字の線引きを見る**

「11時間」「14日連続」のような具体的な線は、**読者がその場で自分を当てはめられます。**
（22時退社なら翌朝9時出社がギリギリ、など）
フィルタ①「所属が瞬時に確定するか」を最も満たしやすいのが数字です。

**③ 得する側と損する側を特定する**

制度変更には必ず両方います。**片方だけを見て書くと主張になり、
両方を並べると争点になります。**

**④ 候補者・従業員の行動がどう変わるかまで降ろす**

**ここでHideさんの資産に接続します。** 制度の解説で終わらせないこと。

```
✕ 勤務間インターバル11時間が義務化されるらしい      ← ニュースの要約。誰でも書ける
○ 面接で「インターバルありますか」と聞くのはアリか  ← 面接官しか答えられない
```

**法改正そのものより、それが選考や職場のやりとりに降りてきた場面**のほうが、
このアカウントでは強く割れます。

### 4. 争点を探す —— 供給源は3つ

**① 新しい行動様式が現れたのに、評価する側がまだ態度を決めていない領域**

**ここが一番当たります。** 2026-08-18に採用されたのは全部この系統でした
（リモート面接のAIカンペ／人事が候補者のSNSを探す／退職代行）。

- まだ社会が扱いを決めていない行動（AI・退職代行・SNS・副業・リモート）
- **採用側／評価側がどう扱うかを、誰も答えていない**
- **賞味期限があります。** 扱いが定まると成立しません

**② 採用側と候補者で利害が逆になる場所**

Hideさんの資産はここです。**選考プロセスの内側**は読者が知りようがないので、
「確かに」の強度が上がります。

- カジュアル面談は選考なのか
- オファー面談での年収交渉は心証を下げるか
- 不採用の理由をなぜ答えないのか
- エージェント経由と直接応募、どちらが通りやすいか

**⚠ 内側を開けるほど、自社の運用を明かす形に近づきます。**
書くなら「業界で一般的にこうなっている」までに留めること。

**③ 自分の投稿に付いた「それは違う」というリプ**

**そのテーマに二陣営がある証拠**です。ただし**私からは見えません。**
Hideさんが拾って渡してくれたぶんだけ使えます。

### 5. 3つのフィルタにかける

**① 読者が瞬時に「自分がどちら側か」分かるか**

分からないテーマは、リプは付いても伸びません
（momoの「上司に奢ってもらった翌日またお礼は必要？」は117リプで**1.1万**）。

**② 片側が不名誉か。ただし行動が不名誉であって、人格ではないか**

不名誉な側がないと、誰も反論しません。ただし人格に踏み込むと炎上になります。

**③ 答えるコストがゼロか**

**性別・国籍・政治は避けてください。** 燃えずに**黙られます。**
答えると自分の評判が下がるテーマは、みんな書き込まないからです
（momoの「女性上司より男性上司のほうがやりやすくない？」は**3.1万・リプ37**で失速）。

**働き方・世代・マナー・評価**は、誰でもコストゼロで意見が言えます。

### 6. 一次情報の部分を明示する

**テーマを出すときに「これはHideさんの実体験として書けるか」を添えてください。**
判定できるのはHideさんだけなので、**こちらで勝手に狭めないこと。**

見たことがない、と言われたら**伝聞に切り替えます。**

```
（一次情報）ベンチャーで面接官してますが、AIを見ながら答えてる人はだいたい分かります。
（伝聞）    大手で面接官やってる友人が、AIを見ながら答えてる人はだいたい分かる、と言ってた。
```

**伝聞は逃げではなく手札です。** 一次情報の責任が相手側に移り、
締めだけHideさんの意見にできます。

### 7. 出す

**5つ。テーマ単位で、ポストにはしません。**

1つにつき次の3行。

```
【テーマ】（一文）
【割れ方】◯◯派 vs ◯◯派
【なぜ新しいか】誰も答えていない部分はどこか
```

**賞味期限があるものは明記。**

### 8. 貯める

`x/debates.md` に追記します。**上書きではなく追記。**
使ったもの・腐ったものは印を付けて残してください。

## ポストにするときの書式

**投稿を頼まれてから**、`formats.md` の「議論系の締め」に従います。

```
（場面 or 伝聞で、争いのある事実を出す）

【Aの言い分】なのか、【Bの言い分】なのか、どうだろう…？
```

- **締めの直前に争点を1行で並べる。** これが無いとリプが散ります
- **一言かばわない。** 説明を足すと読者が納得して争点が片付きます。
  代わりに**「だって」「らしい」で距離を取る**
- **「？？」ではなく「どうだろう…？」。** 選択を迫るより独り言に寄せる
- **記録時の `--format` は `議論系`**（型ではなく狙いで括ります）

## 出してはいけないもの

- **過去に投稿したテーマの言い換え**（2026-08-18に5つ全没）
- **性別・国籍・政治**（燃えずに黙られる）
- **一次情報か伝聞かを明示していないもの**（判定できるのはHideさんだけ）
- **人格を落とすもの**（行動を落とすこと）
- ポスト本文。**頼まれるまでテーマだけ**
