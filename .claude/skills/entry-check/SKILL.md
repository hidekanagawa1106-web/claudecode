# 場中エントリーチェック

チャート画像（分足・日足）から、その時点でエントリー条件が揃っているかを機械的に照合する。
**銘柄は問わない。** 画像から銘柄コードを読み取り、セクターに応じて連動銘柄を自動で切り替える。

売買推奨は行わない。ルールに対する ○/△/✗ の照合と、その根拠となる数値の提示に徹する。

## 入力

- 分足チャート（3分足・5分足など）1枚 — 必須に近い。これがないとトレンド判定ができない
- 日足チャート 1枚 — 上位足の方向確認用
- どちらか片方しかない場合は、欠けている足の判定を「データなし」とし、その旨を明記して進める

銘柄コード・現値・時刻はすべて画像から読み取る。ユーザーに聞き返さない。

---

## ステップ0: 画像からのデータ抽出

各画像から以下を読み取る。読めなかった項目は推測せず「読み取り不可」とする。

| 項目 | 場所 |
|---|---|
| 銘柄コード・銘柄名・市場 | ヘッダー |
| 現値・前日比・前日比率・取得時刻 | 価格パネル |
| 足種（3分足/日足など） | チャート左上のセレクタ |
| MA1(5) / MA2(25) / MA3(75) | 単純移動平均のオーバーレイ |
| 出来高（当該バー） | 出来高パネル |
| RSI 短期 / 長期 | RSIパネル |
| 始値・高値・安値・終値 | OHLC行 |

### 読み取り時の重要な注意

**OHLC行とMA値は「クロスヘア位置のローソク足」の値であり、最新の値とは限らない。**
チャート下部の黄色いラベル（`< 09:15 >` `< 08/03 >` など）がクロスヘア位置を示す。

- OHLC行の「終値」が価格パネルの現値と食い違う場合、**現値と前日比を正**とする。OHLC行の数値は矛盾する限り採用しない
- 前日終値は `現値 − 前日比` で必ず検算する。これがOHLC行と整合しない場合、OHLC行は別の足の値を表示している
- MA値もクロスヘア時点のもの。現値との大小比較に使う際は、**MAの傾き（上向き/下向き/横ばい）**を目視で併せて確認し、クロスヘアが古い位置にある場合はその分を割り引く

矛盾を見つけたら黙って片方を採用せず、レポートに「OHLC行は別足の値の可能性」と一行添える。

## ステップ1: セクター判定と連動銘柄の決定

銘柄コードから業種を判定し、確認すべき連動指標を決める。

| セクター | 該当例 | 連動指標（上から優先） |
|---|---|---|
| 半導体・半導体製造装置 | 285A, 8035, 6857, 6146, 6920, 6723 | SOX指数、東京エレクトロン(8035)、アドバンテスト(6857) |
| 防衛・重工・プラント | 7011, 7012, 7013, 6203 | 川崎重工(7012)、IHI(7013)、日経平均 |
| 自動車・部品 | 7203, 7267, 7201, 6902 | ドル円、トヨタ(7203)、米長期金利 |
| 銀行・保険・証券 | 8306, 8316, 8411, 8766, 8604 | 日本10年債利回り、米長期金利、三菱UFJ(8306) |
| 商社 | 8058, 8031, 8053, 8002 | 原油(WTI)、銅、ドル円 |
| 海運 | 9101, 9104, 9107 | BDI(バルチック海運指数)、原油 |
| 鉄鋼・非鉄 | 5401, 5411, 5713, 5802 | 鉄鉱石・銅価格、中国景気指標 |
| 電力・ガス | 9501, 9503, 9531 | 原油・LNG価格、長期金利 |
| 医薬・ヘルスケア | 4502, 4503, 4568 | ナスダックバイオテク指数、個別材料の比重が高い |
| 小売・内需 | 3382, 9843, 8267 | 日経平均、個人消費指標 |
| グロース・新興 | 東証グロース上場銘柄全般 | 東証グロース250指数、ナスダック総合 |

**判定できない場合のフォールバック**: 同業種の時価総額上位2銘柄 + 日経平均 + TOPIX。
セクターの当てはめに迷ったら、レポートに「セクター判定: ○○として評価」と明記する。

決めた連動指標は WebSearch で当日の方向を確認する。取れなければ「未確認」とし、条件3は保留扱い。

## ステップ2: トレンド判定（2軸で見る）

分足と日足の**両方**を判定する。片方だけで結論を出さない。

```
価格 > MA5 > MA25 > MA75  → 上昇トレンド（押し目買い）
価格 < MA5 < MA25 < MA75  → 下降トレンド（戻り売り/様子見）
上記以外                    → 交錯・もみ合い（ノートレード）
```

判定の組み合わせと扱い:

| 分足 | 日足 | 条件1の判定 |
|---|---|---|
| 上昇 | 上昇 | ○ トレンド明確 |
| 上昇 | 交錯 or 下降 | △ 分足のみ。上位足の抵抗が上に残る |
| 交錯 | 上昇 | △ 押し目形成中の可能性。分足の再加速待ち |
| 下降 | 下降 | ○（売り方向で明確） |
| その他 | | ✗ ノートレード |

日足で価格が MA25・MA75 の下にある場合、**そこが上値抵抗**になる。上値目標の設定時に必ず突き当てる。

トレンドラインや保ち合いが描画されている場合はそれも読み取り、現値との位置関係を書く。

---

## ステップ3: 出来高判定

基準は「当日平均の1.5倍以上」。ただし機械的に当てはめない。

### 構造的スパイクの除外

以下のバーは板寄せ（注文一括約定）による構造的な出来高であり、**シグナルとして扱わない**。当日平均を算出する母数からも除外する。

- **前場寄り付き（9:00〜9:05）** — 毎日必ず突出する
- **後場寄り付き（12:30〜12:35）** — 同上
- **大引け（14:55〜15:00）** — 引け成行の集中

これらのバーだけが1.5倍を超えていて、直後のバーが通常水準に戻っている場合、条件2は**△〜✗**とする。「数値上は満たすが意味を持たない」と明記する。

### 見るべきもの

- 現在バーの出来高が、直前10〜20本の通常バーの水準に対して何倍か
- 出来高の**トレンド**（右肩上がり=勢い継続 / 右肩下がり=勢い減衰）
- 価格が上昇しているのに出来高が細っている場合は減衰シグナルとして明記

---

## ステップ4: 連動銘柄の確認

ステップ1で決めた指標について、当日の方向を WebSearch で確認する。

- 対象銘柄と**同方向** → ○
- 逆方向 → ✗（単独の動きであり、続きにくい）
- 取得不可 → 保留（条件は未成立として扱う）

セクター特有の材料ニュース（決算、受注、規制、格付け）があれば併せて拾う。

---

## ステップ5: イベントフィルタ

**当該銘柄の決算発表日は必ず WebSearch で確認する。** これを省略しない。

| 該当 | 方針 |
|---|---|
| 決算発表 当日・翌日 | ポジションサイズを通常の半分以下 |
| 決算発表 **前日** | 持ち越し厳禁。決算前の様子見で薄商い・値動き不安定になりやすく、テクニカルの信頼度が下がる旨を明記 |
| FOMC 当日 | 寄り付き直後の飛びつきを避け、値動きが落ち着くまで様子見 |
| 日銀金融政策決定会合 当日 | 同上 |
| 米雇用統計・CPI 発表翌日 | 判定の信頼度を1段階下げる |
| 権利落ち日・株式分割・指数入替 | 需給要因として別記 |

該当があれば具体的な日付とイベント名を書く。

---

## ステップ6: 数値の算出

エントリーした場合の想定値を、現値ベースで必ず計算して出す。

| 項目 | 計算 |
|---|---|
| 損切り | 現値 −2% 〜 −3% |
| 利確 | 現値 +3% 〜 +5% |
| 手仕舞い判断期限 | 14:45 |

### リスクリワードの検証（必須）

利確目標を出しっぱなしにしない。**現値から最も近い上値抵抗**（日足MA25/MA75、直近高値、節目価格、価格帯別出来高の厚い帯）までの距離を出し、損切り幅と比較する。

- 「最も近い抵抗までの距離 < 損切り幅」なら、**リスクリワードが悪い位置**として明記する
- 利確目標が抵抗の向こう側にある場合、「抵抗突破が前提」と書く

### 押し目の目安

分足MA5・MA25、日足MA5 の価格と、現値からの乖離率を表で出す。

- 乖離が小さい（〜2%程度）→ 待つコストが低い
- 乖離が大きい（5%以上）→ 現在地は高値掴みゾーンである旨を明記

## 出力フォーマット

```
## 【<銘柄名>(<コード>) 場中エントリーチェック YYYY/MM/DD HH:MM】

### ■ 判定結果: <エントリー見送り / 押し目待ち / 条件成立>

| # | エントリー条件 | 判定 | 根拠 |
|---|---|---|---|
| 1 | トレンド判定が明確 | ○/△/✗ | |
| 2 | 出来高が当日平均の1.5倍以上 | ○/△/✗ | |
| 3 | 連動銘柄が同方向 | ○/△/✗/保留 | |

### ■ トレンド判定の詳細
<分足の価格・MA配列を数式で / 日足の価格・MA配列を数式で / 乖離があればその意味>

### ■ 出来高
<現在バー vs 通常バー水準 / 構造的スパイクの有無 / 出来高トレンド>

### ■ 追加の警戒シグナル
<RSI過熱・ダイバージェンス / 上ヒゲ・失速 / 値幅の狭さ など。なければ「特になし」>

### ■ イベントフィルタ: <該当あり/なし>
<日付・イベント名・方針>

### ■ エントリーした場合の数値（参考）
<損切り / 利確 / 期限の表 + リスクリワード検証 + 押し目の目安>

### ■ 次に条件が揃う可能性のあるシナリオ
<何がどうなれば条件成立か、具体的な価格と事象で>

---
*本レポートはルールに対する機械的な照合であり、売買推奨ではありません。最終判断はご自身でお願いします。*
```

WebSearch を使った場合は末尾に Sources を付ける。

---

## 判定結果の使い分け

- **条件成立** — 3条件すべて○。イベントフィルタの制約があればサイズ調整を明記
- **押し目待ち** — 分足のトレンドは○だが現在地が高い、または出来高が伴っていない。待機ラインを具体的な価格で示す
- **エントリー見送り** — トレンドが交錯、連動銘柄が逆行、上位足の抵抗が近い、イベントリスクが大きい

---

## 禁止事項

- 投資助言・断定的な「買い」「売り」の推奨をしない
- 読み取れなかった数値を推測で埋めない。「読み取り不可」と書く
- 条件が揃っていないのに「揃った」と丸めない。△ は △ のまま出す
- ルールを銘柄に都合よく読み替えない。セクター判定の根拠は必ず書く
